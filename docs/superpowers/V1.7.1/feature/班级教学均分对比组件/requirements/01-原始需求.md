## 设计稿

[node 9913-46784](https://www.figma.com/design/vmbLwcwclGPoT3fWJWv7de/%E6%98%8E%E7%9D%BF%E5%BC%80%E5%8F%91%E7%A8%BF-%C2%B7%E5%9B%A2%E9%98%9F%E7%89%88?node-id=9913-46784&m=dev)（备课组长页面，835x409 半宽块），渲染截图 `assets/bar-chart@2x.png`。

## 需求描述（用户原文要点）

1. X 个班教学均分与组均评分 Y 的差距（虚线）；红色=低于组均评分的班级，建议听评课与教研帮扶优先覆盖
   - X = 所选校区所选年级对应的行政班级数量
   - Y = 所选校区+年级+科目+学期的课后报告平均分（A 和 B 一起计算），**保留一位小数、无需四舍五入**
2. 班级过多可左右滑动查看
3. 纵轴 = 课后报告分数；每个班级的平均分（A 和 B 一起计算）
4. 柱子 tooltip：班级名称、平均分、报告数、达标率、授课教师（多个用顿号隔开）

## 技术要求

- ECharts 实现；可扩展可维护；先 mock；说明文档 + 对接文档 + README；**注意图表性能**

## P1 补充确认点（2026-10-16 提出，待用户确认）

1. 低于组均的柱色：需求文字「红色」vs 设计稿**橙色 `#FF6F00`**（≥组均为蓝 `#027AFF`）——按哪个？
2. tooltip 第三项：需求文字「报告数」vs 设计稿**「份数」**——按哪个？
3. Y 的「保留一位小数不四舍五入」为后端聚合口径，前端只渲染接口返回字符串、不做截断——确认口径归后端？

## P1 结论（2026-10-16 用户确认）

1. 低于组均柱色：**按设计稿橙色 `#FF6F00`**
2. tooltip 文案：**按设计稿「份数」**
3. Y 精度：后端口径为主，**前端做兜底截断**（保留一位小数、不四舍五入）
4. 无数据：显示空态图表（空态块）
5. mock 场景确认（默认 6 班设计稿同款；不同筛选返回不同班级数演示横向滚动）

**补充记录**：设计稿描述文案「红色=低于组均评分的班级」与橙柱视觉不一致，按设计稿原文保留文案（固定文案不改写）。组件宽度自适应父容器（当前满宽单列；将来同事的右邻块并排时再调布局，文档注明）。
