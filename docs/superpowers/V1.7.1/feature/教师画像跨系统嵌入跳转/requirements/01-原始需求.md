# 教师画像跨系统嵌入跳转 · 原始需求

**版本：** V1.7.1 · **类型：** feature · **提出日期：** 2026-10-20
**性质：** 跨系统跳转契约（dataView → classroom-app 教师画像），含目标页 embed 模式

## 需求原文

当前项目中多个地方点击需要跳转到**其他项目已经写好上线**的教师画像页面。目标项目地址 `E:\code\frontend`，测试环境：

```
https://test.mirayai.com:31594/classroom-app/school/teacher-portrait/teacher-portrait
```

要求：

1. 跳过去都是**具体的某个教师**，需要带参数。
2. **只展示右侧的图表内容**：左边的全局菜单栏不要；页内左侧教学小组 / 教师列表等组件也不要。
3. **教师画像卡要保留**（头像、姓名、标签、性别/主教科目/上课总时长等），并留出间隙、视觉美观。
4. 后面发到生产环境**不需要改地址**。

## P1 方案确认记录（2026-10-20，用户答复）

1. **改动范围：** 可改 `E:\code\frontend` + `apps-development-platform`。
2. **教师标识：** 用 **`tenantUserId`**（目标页 API 口径），不用 data-board 的 mock `teacherId`。
3. **打开方式：** `window.open` 新标签（同域共享 localStorage 鉴权），**不用 iframe**（跨域 localStorage 不共享）。
4. **URL 形态：** 保持原路径不变，query 控制嵌入态（`?tenantUserId=&embed=1`），不另开路由。
5. **保留画像卡：** 首版误隐藏画像卡，按截图纠正——只去全局菜单 + 页内左侧栏，画像卡与右侧图表全保留。

## 边界

- 未带 `embed=1` 时目标页为完整页，历史行为不变。
- `tenantUserId` 必须为画像系统真实 id；mock `tl-teacher-*` 查不到数据。
- 同域跳转；生产同域可用相对路径。
- 不 commit / push（除非用户另行要求）。
