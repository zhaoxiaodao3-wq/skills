## 组件需求（用户原文要点）

### 薄弱教学环节（表格）

- 按「年级同科评分均值 − 班科评分均分」差距降序的最薄弱「班级 × 科目」教学组
- 10 列：# / 班级 / 科目 / 班科评分均分 / 年级同科评分均值 / 差距 / 待改进率 / 报告数 / 责任教师 / 操作
- 责任教师（蓝色）点击 → **教师详情弹窗**（公共弹窗，尚未开发，**先预留打开方法**）
- 操作「下钻」（蓝色）点击 → **班级 × 科目下钻弹窗**（公共弹窗）
- el-table 二次改造；默认显示 5 条，多的滚动展示；平均分前端兜底保留一位小数
- 数据 mock；做成**最通用**的组件

### 下钻弹窗（需求说明图要点）

1. 标题「班级 · 科目（班级 × 科目详情）」+ 右上角 X 关闭
2. 统计该班级在所选校区/学期/科目生成课后报告的数据
3. **任教组合**：一句话说明（学期、科目、教师人数，可能存在替课）；教师列表（授课教师可点击→教师详情弹窗 / 报告数 / 任课时长 / 达标率 / 等级分布）
4. **报告评价变化趋势**：默认「分数趋势」可切「等级趋势」；分数趋势纵轴分数、等级趋势纵轴等级；横轴每份报告一个点，同周多份命名「第X周-N」；hover 浮现教师姓名/报告分数/周数（等级趋势浮现等级和周数）
5. **课堂报告列表**：筛选（姓名=任教组合教师默认全部、周次 1-总周数默认全部、报告类别 A/B 默认全部、等级四档默认全部）；列（报告生成时间 / 周次 / 日期范围 / 上课时长（整数）/ 查看（新窗口打开报告，已有功能）/ 上课教师（点击进教师详情，以人+校区+学期为参数））；分页 20/页、时间倒序

## 技术要求

el-table 二次改造 + echarts 图表；数据 mock；做成最通用的组件；不确定处向用户确认。
