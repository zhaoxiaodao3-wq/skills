## 背景

四个菜单页面分模块开发，用户逐步交付；本模块为页面**顶部第一个模块**，本期接入用户负责的两个页面（`/grade-overview` 年级长概览、`/plan-lessons` 备课组长概览），组件按四种权限设计以支持后续扩展。

四个页面与路由：

| 路由 | 页面 | 负责人 |
|------|------|--------|
| `/principal-cockpit` | 校长驾驶舱 | 同事（已存在占位） |
| `/subject-overview` | 学科组长概览 | 同事（未创建） |
| `/grade-overview` | 年级长概览 | 用户 |
| `/plan-lessons` | 备课组长概览 | 用户 |

## 核心概念：参数处理（用户强调）

页面可能**直接进入**，也可能**从其他页面携带参数跳转**而来，参数处理是本模块设计核心：

- 有 URL 参数 → 作为筛选默认选中值
- 无参数 → 默认选中各下拉列表第一项
- 筛选选中的参数 → 通过跳转按钮组件传递到目标页面

## 1. 筛选组件

- 全部为下拉列表，共五种：校区、学期、年级、科目、学段
- 选项列表通过接口请求返回，**按权限返回不同列表**
- 不同权限页面的筛选项数量：

| 权限（页面） | 筛选项 |
|--------------|--------|
| 校区（校长驾驶舱） | 校区、学期 |
| 备课组长 | 校区、学期、年级、科目 |
| 学科组长 | 校区、学期、学段、科目 |
| 年级长 | 校区、学期、年级（无科目） |

- 默认值：无默认参数选列表第一项；带参跳转时指定选中某项（组件设计必须支持默认值受控）

## 2. 跳转按钮组件

- 按钮共四个：教师列表、年级长概览、学科组长概览、备课组长概览
- 展示数量按权限：**校区权限四个都展示；其他三个权限只展示「教师列表」**
- 点击跳转对应页面，**携带筛选组件当前选择的参数**

## 3. 统计卡片组件

- 最终同一接口，按权限返回不同数据；文案见四张设计截图（assets/）：

| 权限 | 标题卡（主标题/副标题） | 指标 1 | 指标 2 | 指标 3 |
|------|------------------------|--------|--------|--------|
| 校长 | A 校区 / 全科目（截图上副标题有红杠删除标记，待澄清） | 92% 达标率（label 有红杠，待澄清） | 81 覆盖教师数 | 2610 份报告 |
| 年级长 | 初二 / 全科目 | 91% 达标率 | 33 覆盖教师数 | 966 份报告 |
| 学科组长 | 初中 / 语文 | 82 本学科评分均分 | 100% 达标率 | 279 份报告 |
| 备课组长 | 初二 / 语文 | 81 组评分均分 | 100% 达标率 | 115 份报告 |

- 左侧标题卡为紫色边框 + 浅紫底选中态样式；右侧三张白底指标卡（数值 + 文案）

## P1 结论（2026-10-16 用户确认）

1. 红杠 = 不要：校长卡**不显示**副标题「全科目」、第一个指标**不显示**「达标率」label
2. 「教师列表」按钮：目标页面未建，**做预留跳转**（push 预留路径，页面后续需求补上即通）
3. `/subject-overview` 本期不建路由；按钮目标路由不存在时**降级为不跳转**
4. 筛选变化**同步 URL query**（`router.replace`）——已同意
5. 筛选/按钮组件设计稿：Figma MCP 未接入、内置浏览器未登录 Figma（已留登录页标签）；**待用户提供截图或登录后读取**
6. 标题卡紫色边框+浅紫底是 **hover 态**；其余三种权限的设计稿未给 hover 态，由前端**设计补齐**（沿用同一 hover 规范：主题紫边框 + 浅紫底 + 过渡），本期不做点击业务，预留 click emit
