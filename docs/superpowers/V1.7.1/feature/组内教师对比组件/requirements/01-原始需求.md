# 组内教师对比组件 · 原始需求

**版本：** V1.7.1 · **类型：** feature · **提出日期：** 2026-10-16
**页面：** 备课组长概览（`apps/data-board` 的 `plan-lessons`）

## 需求原文

在备课组长概览页面新增「组内教师对比」组件，样式跟已交付的「班级教学均分对比」组件一致：

1、组内 X 位教师，按评分均分排序；红色=低于组均评分，虚线=组均评分 Y

- 1.1、以上为固定文案，但 X 代表所选校区所选科目所选学期所选年级生成课后报告对应的教师数量；Y（保留一位小数，无需四舍五入）代表所选校区所选年级所选科目所选学期的课后报告平均分，A 和 B 一起计算。

2.1、教师过多可左右滑动查看；

3、纵轴：代表课后报告分数；计算每个教师的平均分；

4、鼠标移动至柱子上，浮现平均分、待改进率（保留一位小数，无需四舍五入）、达标率（保留一位小数，无需四舍五入）和授课教师；给了一个截图，是原型中要 hover 展示的内容。

5、注意是跟之前那个组件（班级教学均分对比）在同一行，一人分一半宽度。
