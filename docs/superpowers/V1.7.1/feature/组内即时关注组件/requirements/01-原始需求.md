## 需求内容

「组内即时关注」业务组件，用于**除校区页面外的三个页面**（年级长概览、学科组长概览、备课组长概览；校长驾驶舱不用）。

**组件骨架**（四态共用）：标题行（蓝色竖条 + 「组内即时关注」20px/600 + 描述「基于所选教学周的组内课堂，一句话提示该周需关注事项」16px `#555`）+ 右侧筛选（周次；**年级长多一个科目筛选**）；下方提示条 + 正文。

**四个状态**（由数据决定）：

| 状态 | 提示条 | 正文 |
|------|--------|------|
| 待改进（红） | `#FFF5F5` 底 + 红 `#FF2A2A` 圆图标 + 一句话（如「第 13 周组内待改进课堂偏多（2/6 堂），建议关注课堂组织与讲解」） | 「优秀课堂」表格：班级 / 授课教师 / 评分（评分红色） |
| 优秀（绿） | `#F3FCF5` 底 + 绿 `#00B42A` 圆图标 + 一句话 | 「优秀课堂」表格（评分绿色） |
| 平稳（灰） | `#F2F3F5` 底 + 灰 `#AAAAAA` 圆图标 + 一句话 | 「本周课堂速览」4 统计卡：报告数 7 份 / 评分均分 80 分 / 最高分 85 分 / 最低分 75 分（`#F3F9FF` 底，值 30px/600） |
| 空（灰） | 同平稳灰 + 「暂无记录」 | 「本周课堂速览」+ 空态块（纸飞机图标 + 「本周暂无课堂记录」） |

**筛选要求**：

- 周次：三个页面都有；科目：仅年级长
- 列表通过接口请求；**默认选中值与列表加载的组件设计要做好**
- 切换周次/科目 → 数据重新请求
- 当前 mock，写好组件文档 + 完成情况 + README

## 用户要求补充考虑

「你看看我哪里没考虑到，争取做到最好维护最好扩展的模式」——P1 方案中给出补充设计点清单。

## P1 结论（2026-10-16 用户确认）

1. **周次/科目不考虑页面传参**：纯组件内部状态，默认选第一项（最新的周）
2. 防竞态（请求序号，只采纳最后一次）✅
3. 评分列颜色跟随状态（红态红/绿态绿）✅
4. 空态与平稳由接口 status 区分 ✅
5. 加载态：选项未齐不渲染、数据未到占位防闪跳 ✅
6. **补充：表格默认展示 3 行，超出部分表格内滚动**
