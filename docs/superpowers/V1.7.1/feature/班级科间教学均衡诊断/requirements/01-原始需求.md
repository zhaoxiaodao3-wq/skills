# 班级科间教学均衡诊断 · 原始需求

**版本：** V1.7.1 · **类型：** feature · **提出日期：** 2026-10-16
**页面：** 年级长概览（`apps/data-board` 的 `grade-overview`）· **位置：**「班级教学评价排名」组件同一行的**右半边**（此前预留的空白位）

## 需求原文

上一个组件（班级教学评价排名）右边的**班级科间教学均衡诊断**组件。

- 设计稿：<https://www.figma.com/design/vmbLwcwclGPoT3fWJWv7de/?node-id=9913-48438&m=dev>
- hover 展示的内容**根据三种颜色等级有所区分**（红 / 黄 / 绿），用户提供原型截图（对话附件，未落盘），三态 tooltip 内容示例：
  - **红**：`初二(6)班 • 科间均衡诊断` / `状态判定：严重科间失衡（红）` / `相对偏差极差: 16.1 分（失衡线 5 / 红线 8）` / `评价最高科: 历史（-2.6）` / `评价最低科: 数学（-18.7）` / `建议: 科间落差悬殊，优先干预（定位评价最低科的责任教师）` / `⚠ 全班性偏低: 8 科教师评价低于年级同科评分均值 3 分以上（提示班级课堂环境/管理因素，该找班主任而非单科教师）`
  - **黄**：`状态判定：轻度科间失衡（黄）` / `建议: 纳入教研观察，关注评价最低科`（无 ⚠ 行）
  - **绿**：`状态判定：科间均衡（绿）` / `建议: 各科教师评价水平接近，无需专项动作`（无 ⚠ 行）
- 用户标注：**全班性偏低行的 `N 科` = 符合「低于年级同科评分均值 3 分以上」条件的科目数量**（取接口计数，非固定 8）。
- 要求：**写好组件说明和对接说明**（README 使用说明 + 接口对接指引）。

## P1 方案确认记录（2026-10-16，用户逐条答复）

1. **阈值（失衡线 5 / 红线 8）**：口径**后端给**——契约留 `thresholds: { warn, critical }` 对接通道；**本期 mock 写死 5 / 8**，前端文案与图表线均从该字段渲染（后端改阈值前端零改动）。
2. **文案**：**固定文案**——左侧 label（状态判定/相对偏差极差/评价最高科/评价最低科/建议）与建议句均为前端常量（按 `level` 三档映射）；**右边的值（数值、科目名、计数）通过接口得到**。
3. **⚠ 全班性偏低**：按 Agent 方案——`lowSubjectCount >= 3` 才显示该行，`N` 取 `lowSubjectCount`；**文档（spec/README）写清楚**该条件与计数含义。
4. **三色色值（前端固定，仅三种）**：红 `#FF2A2A`、橙黄 `#FF6F00`、绿 `#00B42A`。
5. **状态与建议**：`level`（red/yellow/green）由接口返回（同 group-focus `status` 先例，组件不猜阈值）；三段状态判定句与三段建议句为前端常量单点。

### 随方案一并默认处理（用户未异议）

- 排序：极差降序、同分 `classNo` 升序（前端稳定排序兜底）。
- 空数据：**空图表**（坐标轴可见、无空态块），沿用「班级教学评价排名」修订后口径。
- 图表高度按班级数动态（`max(180, count*27+36)`），班多则卡片变高、页面滚动，不加滑块。
- 与左侧「班级教学评价排名」的科目单选**不联动**（科间均衡是跨科目指标，不吃单科筛选）。
- 极差 / 偏差数值前端 `truncateOneDecimal` 一位小数截断兜底（不四舍五入）。
- 页面顶部三筛选（campus/semester/grade）变化重拉。
