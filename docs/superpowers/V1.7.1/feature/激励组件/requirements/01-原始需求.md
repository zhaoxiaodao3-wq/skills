# 激励组件 · 原始需求

**版本：** V1.7.1 · **类型：** feature · **提出日期：** 2026-10-19
**页面：** 四个权限页公共，位于**预警组件同行右半留白位**（`__warn-row` 第二列）

## 需求原文

预警组件右边的**激励组件**，标题按权限不同：

- 校区（campus）：**正向激励榜**
- 年级长（campus-grade）：**年级激励榜**
- 学科组长（campus-stage-subject）：**学科激励榜**
- 备课组长（campus-grade-subject）：**本组激励榜**（P1-2 确认）

**设计稿（校区版两态）：**
- <https://www.figma.com/design/vmbLwcwclGPoT3fWJWv7de/?node-id=9913-46182>（tab=标杆态，渲染图 `assets/figma-inspire-benchmark@3x.png`）
- <https://www.figma.com/design/vmbLwcwclGPoT3fWJWv7de/?node-id=9913-58323>（tab=潜力态，渲染图 `assets/figma-inspire-potential@3x.png`）
- 其他权限页与之相似（标题与列差异见下）。

**表格差异：**

1. 所有页面的**标杆教师**表格与设计稿一致（教师 / 报告数 / 评分均分 / 优秀率 / 建议）。
2. 所有页面的**潜力之星**表格与设计稿一致，但**去掉「评分均分」列**（教师 / 报告数 / 优秀率 / 建议）。
3. **备课组长**的两种表格额外在**教师后（第二列）加「年级」列**。

**字段补充说明（用户提供截图）：**

- 优秀率保留**整数百分比**、平均分（评分均分）保留**一位小数**，两者都**无需四舍五入**（截断）。
- **【建议】规则——标杆教师**：优秀率 ≥50% → "示范课候选"；否则 → "优秀稳定"。
- **【建议】规则——潜力之星**：优秀率 ≥25% → "冲线在望"；否则 → "定向培养"。
