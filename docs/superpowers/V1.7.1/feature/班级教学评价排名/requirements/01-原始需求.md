# 班级教学评价排名 · 原始需求

**版本：** V1.7.1 · **类型：** feature · **提出日期：** 2026-10-16
**页面：** 年级长概览（`apps/data-board` 的 `grade-overview`）

## 需求原文

年级长概览的组件：**班级教学评价排名**

1. 排名视角的科目都只能单选，点击就切换科目，并且不能取消选择某个科目；科目列表从接口请求回来，默认选中第一个。
2. 平均分数前端兜底保留一位小数。
3. 班级按分数高低从左至右排序，越高排在越左侧；分数相同，排序按班级序号从小至大排序。
4. 班级过多时，可通过横轴底部横向滑动滑块展示更多班级。
