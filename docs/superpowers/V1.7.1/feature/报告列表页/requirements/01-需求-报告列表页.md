## 1. 需求原文（用户口述）

> 写一个名为报告列表页的二级页面，这个页面是一个公共页面，在任何地方都有可能进来，这个页面会携带不同类型的的参数进来，随之页面上内容会发生变化，主要是影响标题和筛选项的数量内容，默认没参数就是标题只是报告列表。

### 3.1 页面结构（两版一致部分）

- 面包屑：`返回`（左箭头 icon + 文字，16px/400 #777）+ 标题（16px/600 #333），见 §4.1
- 内容白卡（1680×963，#FFFFFF，r8 推测与现有模块卡片一致）：
  1. **统计卡 4 张**：402×87，bg #F3F9FF，左侧 40×40 白圆内 24px 蓝色 icon，label 12px #777，值 18px/600 #027AFF
     - 报告数（mr-general-doc icon）｜达标率（mr-class-aim）｜评分均分（mr-class-trophy）｜覆盖教师（mr-general-teacher）
     - 示例值：30 / 100% / 86.4 / 81人
  2. **区块标题**：3×12 蓝条 #027AFF + 「课堂报告列表」16px/600 #333（固定不随参数变）
  3. **筛选区**（200×30 #F2F3F5 控件，label 14px #333，下拉 suffix 箭头 #777）+ 重置（68×30 #F2F3F5 文字 #555）+ 查询（68×30 #027AFF 白字 600）
  4. **表格**：表头 42px 高 bg #F3F9FF 文字 16px/600 #333（个别列稿内 14px，按 16/600 归一）；数据行 42px 高 16px/400 #555；12 列：
     周次｜日期范围｜报告生成时间｜年级｜班级｜科目｜上课教师｜报告类别｜上课时长｜报告评分｜报告等级｜操作
     - 上课教师：16px/600 #027AFF（蓝色，点击行为待定）
     - 报告等级：14px/600 彩色 chip（优秀 #F3FCF5/#00B42A、良好 #F3F9FF/#027AFF、合格 #FFFBEE/#FF6F00、待改进 #FFF5F5/#FF2A2A —— 与班级×科目下钻弹窗 GRADE_BG 完全一致，可复用常量）
     - 操作：查看，16px/600 #027AFF
  5. **分页**：分页簇水平居中——`共17条`＋上一页/下一页（32×32 方块 r2，箭头 #777，禁用态 #AAA）＋页码（32×32 r2，当前页 **#027AFF 蓝底白字**，其余 #F2F3F5 底 #333 字）＋`前往 [输入框 30×30 #F2F3F5] 页`
- 示例数据 17 行（第18周~第27周+，周次递增、日期范围跨月真实推算、生成时间含秒、评分 76~92）

## 4. 已确认决策（2026-10-19 用户回复）

1. 1.5 = 年级单参数（非重复）；五态 + 无参默认态齐全
2. 筛选项矩阵见 §2.1（携带维度隐藏，其余保留）
3. 标题样例：见 §2（班级+科目为三段：`初三 · 物理 · 3班 · 课堂报告列表`）
4. 无参数默认态：面包屑「报告列表」，筛选器全集显示
5. 筛选点击「查询」才生效；姓名框回车触发查询（拟）；URL 同步：已向用户解释，spec 默认**不同步**（进入参数本身在 URL，避免两套参数混淆；后续如需分享再加）
6. 「查看」不跳转，预留方法 + TODO 标记，后面对接；上课教师点击打开**教师详情弹窗**（复用 teacher-detail-dialog 预留壳）
7. 路由 `/report-list`；**不挂数据权限 guard**（本页对所有进入方开放，权限由入口页面保证）

## 5. 技术方案要点（P1 预案，spec 阶段细化）

- 页面：`src/views/report-list/report-list.vue`，路由 `/report-list`
- 参数契约（query）：`campusId`、`semesterId`（隐含必有）+ `gradeId`/`subjectId`/`classId`/`stageId` 组合，复用 `buildOverviewUrlQuery` 思路
- 标题与筛选项由参数派生：`REPORT_PAGE_MODES` 配置表（参数组合 → 标题片段 + 筛选字段集），公共页面核心抽象
- 表格：el-table 二次定制（沿用 weak-link-table 的 CSS 变量方案）；分页 el-pagination 二次定制（黑色当前页）
- 筛选控件：el-select/el-input 沿用 `el-select-filter.scss` 定制（200×30 #F2F3F5）
- 统计卡：新公共组件 report-stat-card（4 张同构）
- 等级 chip：复用下钻弹窗 GRADE_BG 常量（抽到共享 constants）
- 接口全部 mock：`src/api/report-list.ts`，标记 `TODO(1.7.1-接口替换): [#19~#21]`（#1~#18 已占用）
