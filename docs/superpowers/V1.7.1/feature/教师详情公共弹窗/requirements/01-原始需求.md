# 教师详情公共弹窗 · 原始需求

**版本：** V1.7.1 · **类型：** feature · **提出日期：** 2026-10-19
**性质：** 全局公共组件（多处复用，按最佳模式设计，**一比一还原设计稿**）

## 需求原文

教师详情公共弹窗，项目里很多地方用到，**一定要好好设计**。

- 设计稿：<https://www.figma.com/design/vmbLwcwclGPoT3fWJWv7de/?node-id=9913-55334&m=dev>（渲染图已归档 `assets/figma-teacher-detail-dialog@2x.png`）
- **报告变化趋势**组件下钻组件里已有，是**公共图表，用那个**；有缺的**改造一下下钻**。

说明：

1. 标题显示教师姓名（稿：`王辉 的教师详情`）。右上角【X】点击关闭。
2. 显示**性别**、所选**统计学期**（所选校区**不显示**）。【查看教师画像】按钮：点击打开新窗口展示教师画像，**把教师 id 作参数即可**，与校区/学期无关。教师画像是现有功能，**只需多一个展示页面**。
3. 查看范围：默认选中第一个【年级+科目】（任教组合），可切换其他。
4. 报告列表：
   - 11.1 查询条件：任教组合（默认全部，选项来自第 9 点任教组合，下拉）、周次（默认全部，1~总周数，下拉）、报告类别（默认全部，A 类/B 类）、等级（默认全部，优秀/良好/合格/待改进）
   - 11.2 字段：报告生成时间（A/B 类报告生成时间）、周次（由生成时间推算）、日期范围（由周次得到）、上课时长（由视频得到，**保留整数**）、【查看】（新窗口打开报告，已有功能）
   - 11.2.6 在一定区域内展示列表数据，**每页 10 条**

## P1 方案确认记录（2026-10-19，用户答复）

1. **教师画像 = 新建公共组件**（`teacher-portrait-dialog`）：先写出来；页面中原有 mock 处替换为真实弹窗；**画像先不真实跳转**（内容先 mock，不接外部画像系统）。→ 全局搜索当前 src **无任何「画像」mock 点**，故本弹窗【查看教师画像】按钮直接接入该公共组件；后续页面出现画像入口按同组件替换（README 写接入方式）。
2. **所有原打开教师详情的地方统一换到本弹窗**——既有调用（weak-link-table、class-subject-drill-dialog、teacher-list 已挂桩）零改动生效；**预警组件教师名改为点击打开**（推翻早前「不可点」裁决）。
3. 趋势公共化（按建议）：抽公共组件 `report-trend-chart`（tabs+VChart+option），**下钻改造引用它**，数据各走各接口。
4. 接口编号（按建议）：**#19 概要 / #20 任教组合+等级分布 / #21 教师趋势 / #22 报告列表**（#1~#18 已占，#18 为并行会话教师列表）。
5. 弹窗形态（按建议）：宽 **1000**、body 最大 **85vh 内部滚动**、列表表格限高约 5 行内滚、分页在表下（稿表格 440=表头40+10行×40 恰好整页，实现按区域限高滚动兜底）。
6. 标题格式 `{姓名} 的教师详情`；调用方 `open()` 签名不变。

## 边界

- 不接真实画像/报告后端（报告【查看】沿用已有 `window.open(reportUrl)` 能力；画像不跳转）。
- 下钻组件仅做趋势图引用改造（行为不变）。
- 不 commit / push。
