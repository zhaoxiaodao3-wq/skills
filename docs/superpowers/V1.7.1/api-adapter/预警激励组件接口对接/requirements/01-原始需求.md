## 接口契约摘要

### 预警聚焦 `GET /teaching-overview/warning-focus`

Query：`campusId`、`baseSemesterId`（仅此两项）
data：`WarningFocusResp[]`

| 字段 | 类型 | 说明 |
|------|------|------|
| tenantUserId | string | 教师 id |
| teacherName | string | 教师姓名 |
| hint | string | 提示 |
| needsImprovementCount | int32 | 待改进数量 |
| needsImprovementRate | number | 待改进率 0～1 |

### 标杆教师 `GET /teaching-overview/benchmark-teachers`

Query：`campusId`、`baseSemesterId`
data：`BenchmarkTeacherResp[]`

| 字段 | 类型 | 说明 |
|------|------|------|
| tenantUserId | string | 教师 id |
| teacherName | string | 教师姓名 |
| suggestion | int32 | 建议：1 优秀稳定，2 示范课候选 |
| reportCount | int32 | 报告数 |
| averageScore | number | 评分均分 |
| excellentRate | number | 优秀率 0～1 |

### 潜力之星 `GET /teaching-overview/rising-stars`

Query：`campusId`、`baseSemesterId`
data：`RisingStarResp[]`

| 字段 | 类型 | 说明 |
|------|------|------|
| tenantUserId | string | 教师 id |
| teacherName | string | 教师姓名 |
| suggestion | int32 | 建议：1 定向培养，2 冲线在望 |
| reportCount | int32 | 报告数 |
| excellentRate | number | 优秀率 0～1 |

注意：`RisingStarResp` 当前缺 getter/`@Data`，序列化待后端完善；无 `averageScore`。
