## 接口契约摘要（immediate-focus）

**路径：** `GET /classroom-dashboard/teaching-overview/immediate-focus`

**Query：**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| campusId | string | 是 | 校区 id |
| baseSemesterId | string | 是 | 基础学期 id |
| stageId | string | 否 | 学段 id，与 gradeId 至少一项 |
| gradeId | string | 否 | 年级 id，与 stageId 至少一项 |
| subjectName | string | 是 | 科目名称 |
| weekNo | integer(int32) | 是 | 周次 |

**响应 data（ImmediateFocusResp）：**

| 字段 | 类型 | 说明 |
|------|------|------|
| conclusion | string | 结论 |
| status | string | 状态（未定义固定枚举） |
| classCount | integer | 课堂数量 |
| averageScore | number | 评分均分 |
| maxScore | number | 最高分 |
| minScore | number | 最低分 |
| classInfo | ImmediateFocusClassInfoResp[] | 课堂信息 |

**classInfo 元素：** classId / tenantUserId / teacherName / score

**注意：**

- 后端 `status` 无固定枚举，前端不能据示例推导。
- `classInfo` 文档示例仅有 `classId`；**后端确认将返回 `className`**，前端按 `className` 对接（缺省回退 `classId`）。
- 周次/科目列表接口在文档中**不存在**，本期需自行解决选项来源。
- 比例字段 0～1；`code === 200` 为业务成功。
