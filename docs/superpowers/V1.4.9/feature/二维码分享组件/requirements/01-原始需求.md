# 报告分享功能需求文档
## 一、需求概述
基于页面地址 `https://m-test.mirayai.com:31594/analysis-teaching-b` 开发报告分享能力，提供两种不同视觉样式的分享按钮适配多业务场景，按钮具备完整交互态；点击唤起分享弹窗，弹窗内置分享链接展示区域与二维码区域，前端Mock固定链接，同时预留后端动态生成分享链接接口流程，二维码通过链接实时生成。整体基于Element Plus开发，遵循项目前端Skill工程化规范，代码组件化、注释完善。

### 2. 按钮交互状态
- 默认常态：严格对齐Figma尺寸、配色、圆角、文字、图标
- hover悬浮态：增加过渡动画，变换背景/文字颜色，过渡丝滑无卡顿
- click点击态：按下缩小/变色反馈，添加短时间transition过渡效果
- 过渡统一配置：`transition: all 0.2s ease;`

## 三、分享弹窗规范
弹窗视觉参考Figma：https://www.figma.com/design/vmbLwcwclGPoT3fWJWv7de/%E6%98%8E%E7%9D%BF%E5%BC%80%E5%8F%91%E7%A8%BF-%C2%B7%E5%9B%A2%E9%98%9F%E7%89%88?node-id=7490-20801&m=dev
### 弹窗内部模块
1. 分享链接区域
    - 输入框/文本框展示分享地址，配套**复制链接按钮**，点击复制后弹出成功提示
    - 开发阶段固定链接：`https://m-test.mirayai.com:31594/analysis-teaching-b`
    - 预留接口逻辑：正式环境调用后端接口动态获取临时分享链接，替换固定地址
2. 二维码扫码区域
    - 根据当前分享链接，使用qrcode工具库实时生成对应二维码图片
    - 链接更新时，二维码自动重新渲染
    - 增加提示文字：扫码在手机端打开报告
3. 弹窗基础功能
    - 右上角关闭按钮，点击关闭弹窗
    - 点击弹窗遮罩层可关闭弹窗
    - 弹窗居中弹出，弹出/关闭增加淡入淡出动画

## 四、完整业务流程
### 开发Mock流程（当前阶段）
1. 页面渲染分享按钮组件，传入type参数切换两种样式
2. 用户点击分享按钮 → 弹出分享弹窗
3. 弹窗加载固定分享链接 `https://m-test.mirayai.com:31594/analysis-teaching-b`
4. 前端读取链接，调用qrcode生成二维码并渲染
5. 用户操作：复制链接 / 扫码查看 / 关闭弹窗

### 正式线上接口流程（预留，后续对接）
1. 点击分享按钮，前端请求后端生成分享链接接口
2. 后端返回临时分享URL（带时效/权限参数）
3. 前端将接口返回链接赋值给展示框，重新生成二维码
4. 其余交互逻辑不变，仅替换链接来源

## 五、技术实现约束
1. 技术栈：Vue3 + Element Plus，引入qrcode第三方库生成二维码
2. 组件化拆分
    - ShareBtn 分享按钮通用组件（支持两种样式切换）
    - ShareDialog 分享弹窗独立组件，全局可复用
3. 前端Skill规范落地
    - 复用项目通用弹窗、复制工具方法、消息提示skill能力
    - 样式统一抽入scss变量，对齐全局主题
    - 接口请求逻辑抽离api文件，Mock/正式环境做分支区分
    - 关键逻辑、接口预留位置、二维码生成逻辑增加业务注释
4. 兼容性
    - 复制功能兼容PC端主流浏览器，复制失败给出错误提示
    - 二维码自适应弹窗宽度，不会溢出容器
