# 课堂教学内容评价 · 评分趋势图表

## 一、需求概述

在教师画像页「课堂教学内容评价」模块底部，与「评分维度得分」**同行排布**新增 **评分趋势** 折线图：展示该教师 A/B 类课后报告综合评分随时间的变化；本期 **Mock 数据**，预留真实接口。原有环形图、等级汇总、雷达图功能与数据逻辑保持不变，仅微调底部行宽度比例以容纳新图表。

## 五、评分趋势图表规则

### 5.1 卡片结构（对齐 Figma 7485:12649）

1. 顶部居中标题条：「评分趋势」
2. 图例（可点击显隐系列，默认全开）：
   - A类【基于教案与上课】— 色 `#027AFF`（与现网 A 类一致）
   - B类【基于教材与上课】— 色 `#00BCBC`（与现网 B 类一致；设计稿偶发缺字「于」，以现网文案为准）
3. 图表区：圆角边框容器；Y 轴 0–100，间隔 20；X 轴**不显示**报告名文本
4. 底部：`dataZoom` **slider**（可含左右箭头样式或 ECharts 默认手柄），支持拖拽查看更多历史点；点数少时可隐藏 slider

### 5.2 数据与坐标

1. **样本范围**：该教师全部**成功生成**的 A/B 课后报告（Mock ≥15 条，覆盖近 1–2 月，曲线有波动）
2. **横轴排序**：**生成时间越晚越靠左**（时间倒序）
3. **对齐方式（项目优化约定）**：横轴为「报告序列」统一 category；每条系列仅在本类型报告点有数值，异类型位置为 `null`（断点不连线，`connectNulls: false`）
4. **纵轴**：综合评分 0–100
5. **系列**：两条 `line`，`smooth: true`，带浅色面积填充（对齐设计稿）

### 5.3 Tooltip（hover 数据点）

深色半透明浮层（Figma：`rgba(0,0,0,0.36)`），字段：

| 字段 | 说明 |
|------|------|
| 评分 | 数值 |
| 评级 | 色点 + 等级文案（优秀/良好/合格/待改进，色值复用 `CLASSROOM_CONTENT_EVAL_LEVEL_DEFS`） |
| 课例名称 | 文本 |
| 生成时间 | 如 `2026年3月2日 13:00:07` |

> 与页面默认白底 `CHART_TOOLTIP_BASE` 不同，本图以 Figma 深色 tooltip 为准。

### 5.4 交互与性能

1. 复用 `useTeacherPortraitChart` + `CHART_ANIMATION_BASE`（入场/更新动画）
2. hover：系列高亮、数据点强调
3. 图例点击显隐两条曲线
4. slider 拖拽跟手；resize 走现有 composable（已有 ResizeObserver，无需另造节流除非实测卡顿）
5. 大数据：可对 series 开 ECharts `sampling`；首版 Mock 量级下以正确性优先

### 5.5 空态 / 加载

1. 模块整体 `v-loading` 行为保持
2. 无趋势数据：图表区空态（不白屏、不抛错）；与模块 `isEmpty` 策略对齐（可与雷达空态一致：骨架轴或占位文案，实现时在 spec 定一种）

## 六、Mock 与接口预留（项目优化）

### 字段（与后续接口对齐建议）

```ts
type ScoreTrendReportItem = {
  reportType: 'A' | 'B'
  score: number          // 0–100
  gradeKey: 'excellent' | 'good' | 'pass' | 'needsImprovement'
  gradeLabel: string
  lessonName: string
  generatedAt: string    // ISO 或可解析时间戳
}
```

### 数据策略

1. 本期：独立 Mock（建议 `classroom-content-eval` 目录下 mock 文件，或挂到现有 teacher-portrait mock，由 debug 开关/`isTeacherPortraitMockEnabled` 控制）
2. Container 组装 ViewModel 时注入 `scoreTrend`；正式接口只换数据源，不改图表 option 构建
3. **不**改动现有环图/雷达已有聚合字段契约，趋势数据可并行扩展 slice / 独立请求

## 七、技术实现约束

1. Vue3 + ECharts；**不**引入新图表库
2. 组件化：评分趋势可落在同目录子组件（如 `ScoreTrendPanel.vue` + `score-trend-chart-options.ts`），由 `ClassroomContentEvalView` 嵌入，避免 View 文件过度膨胀
3. 配色、字号对齐 Figma 与现网 A/B 色
4. 禁止破坏：等级环图、汇总卡片、双雷达交互与现有 adapter/normalize

## 八、非目标

1. 本期不接真实后端列表接口
2. 不改上区环图/汇总布局与业务逻辑
3. 不做跨模块（如教学风格趋势）的图表抽象重构
4. 不实现点击跳转报告详情（需求未要求）

## 九、验收要点

- [ ] 底部左「评分维度得分」右「评分趋势」同行；窄屏可堆叠
- [ ] 双折线 A/B 色正确；Y 0–100；X 无报告名；时间倒序（新在左）
- [ ] 底部 slider 可拖；图例可显隐
- [ ] Tooltip 含评分/评级/课例/时间
- [ ] Mock ≥15 条；空态与 loading 无异常
- [ ] 原环图、汇总、雷达行为无回归

## 十、相对用户原稿的项目侧优化摘要

1. **复用** `useTeacherPortraitChart` / 动画基线 / A·B 现网色，避免另起一套图表生命周期
2. **布局**明确为「雷达整块 + 趋势卡片」两栏，而非拆散原雷达结构
3. **横轴对齐**约定为统一报告序列 + 异类型 `null`，避免两条曲线强行同索引错位
4. **图例文案**以现网「基于教材与上课」为准
5. **Tooltip**按 Figma 深色样式，不强制套用页面白底 tooltip 基线
6. **dataZoom**采用设计稿可见的 **slider**（教学风格趋势目前多为 inside，本需求不照搬）
7. 性能项落地为「先正确再优化」，避免首版过度工程

## 十一、用户原话摘要

> 在课堂教学内容评价中新增评分趋势折线，与评分维度得分同行；ECharts；A/B 趋势；横轴滑块；Mock + 预留接口；不破坏原模块。
