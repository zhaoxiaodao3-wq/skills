# V1.4.9 `/v2/teachingDiagnosis/teachingDiagnosisPage` 接口调整文档

## 基本信息

| 项目 | 内容 |
|------|------|
| 版本号 | V1.4.9 |
| 接口路径 | `POST /v2/teachingDiagnosis/teachingDiagnosisPage` |
| 接口说明 | 获取教学诊断分析分页列表 |
| 文档作者 | liangfeng |
| 更新日期 | 2026-07-17 |

## 一、变更摘要

| 变更项 | 变更类型 | 说明 |
|--------|----------|------|
| 新增排序参数 `sortType` | 🆕 新增 | 支持 3 种排序方式 |
| 移除报告类型 `G` 选项 | ⚠️ 变更 | `reportType` 仅接受 `A` / `B` |
| 列表不再返回 G 类数据 | ⚠️ 变更 | 历史 G 类记录从列表移除 |
| 响应 `bcti` 字段说明变更 | ⚠️ 变更 | 总分来源改为 `case_basic_info`，细节见下方 |
| 详情接口 `bcti` 对象 | ⚠️ 变更 | 不再返回 CSMS 九维度雷达图数据 |

## 二、请求参数

### 2.1 请求体（JSON）

```
POST /v2/teachingDiagnosis/teachingDiagnosisPage
Content-Type: application/json
```

### 2.2 完整参数表

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| `page` | Integer | 是 | 页码，从 1 开始 |
| `size` | Integer | 是 | 每页条数，最大 500 |
| `createTimeStart` | Long | 否 | 创建时间范围-起始（毫秒时间戳） |
| `createTimeEnd` | Long | 否 | 创建时间范围-结束（毫秒时间戳） |
| `analysisState` | String | 否 | 分析状态：`analyzing` / `success` / `failed` |
| `subjectName` | String | 否 | 学科名称 |
| `gradeName` | String | 否 | 年级名称 |
| `keyword` | String | 否 | 关键词（模糊搜索授课老师或课堂名称） |
| `recordingClassroomName` | String | 否 | 录播课堂名称（模糊搜索） |
| `recordingDate` | String | 否 | 录播日期，格式 `yyyy-MM-dd` |
| `reportType` | String | 否 | 🆕 报告类型：`A` / `B`（**不再支持 `G`**） |
| `scoreLevel` | String | 否 | 评分等级：`EXCELLENT` / `GOOD` / `QUALIFIED` / `NEED_IMPROVEMENT` / `""`（`""` 表示无评分） |
| `resourceType` | String | 否 | 资源类型：`1`-视频 / `2`-音频 |
| `sortType` | String | 否 | 🆕 排序类型（见 2.3） |

### 2.3 🆕 新增 `sortType` 排序参数

| 值 | 说明 | 排序规则 |
|----|------|----------|
| 不传 / `"default"` | **默认排序**（默认选中） | 按创建时间降序（保持原有行为） |
| `"score_asc"` | **评分升序** | 按评分等级从低到高（待改进→合格→良好→优秀），分析中排最前，同等级按时间降序 |
| `"score_desc"` | **评分降序** | 按评分等级从高到低（优秀→良好→合格→待改进），分析中排最后，同等级按时间降序 |

### 2.4 ⚠️ `reportType` 变更说明

**V1.4.7（旧）：**

| 值 | 说明 |
|----|------|
| `A` | A 类课后报告 |
| `B` | B 类课后报告 |
| `G` | G 类（历史遗留数据） |

**V1.4.9（新）：**

| 值 | 说明 |
|----|------|
| `A` | A 类课后报告 |
| `B` | B 类课后报告 |

> ⚠️ **前端需同步调整**：报告类型下拉框去掉"G类"选项。若仍传入 `reportType=G`，后端将按 A/B 类精确匹配，不会报错但也不会匹配到任何结果（因为 G 类数据已全局过滤）。

### 2.5 请求示例

```json
{
    "page": 1,
    "size": 20,
    "reportType": "A",
    "scoreLevel": "EXCELLENT",
    "sortType": "score_desc",
    "keyword": "张老师"
}
```

### 3.3 ⚠️ `bcti` 字段变更说明

**V1.4.7（旧）**：

- G 类记录：`bcti` = 从 AI BCTI 九维度评分（`ai_bcti.indices[].score`）累加得到
- A/B 类记录：`bcti` = 从 `case_basic_info.scoring.totalScore` 取值

**V1.4.9（新）**：

- G 类记录：**不再返回**（已全局过滤）
- A/B 类记录：`bcti` = 从 `case_basic_info.scoring.totalScore` 取值（**数据来源不变**）
- 分析中（`reportType = "-"`）记录：`bcti` = 空

> 💡 **提示**：`bcti` 字段仍保留字符串类型，前端直接展示即可。该字段在未来版本中将重命名为更语义化的名称（如 `totalScore`），当前版本保持兼容。

## 五、前端适配清单

### 5.1 必须调整

- [ ] **报告类型下拉框**：去掉"G类"选项，仅保留"A类"和"B类"
- [ ] **排序下拉框**：新增排序组件，选项为"默认排序"、"评分升序"、"评分降序"，默认选中"默认排序"
- [ ] **排序参数传递**：请求时传入 `sortType` 字段（值为 `"default"` / `"score_asc"` / `"score_desc"`）
- [ ] **列表 bcti 展示**：确认当前展示逻辑无需调整（字段名和类型不变）
- [ ] **详情页 bcti 雷达图**：移除 CSMS 九维度雷达图模块，或做 null 安全兜底（`bcti` 为 null 时隐藏整个区块）

### 5.2 建议调整

- [ ] **列表空态文案**：如果筛选后列表为空，提示文案可从"暂无诊断记录"调整为更明确的引导语
- [ ] **报告类型标签颜色**：G 类标签样式可以移除

### 5.3 兼容性注意事项

- `bcti` 字段类型为 `String`，值可能为 `"87.5"` 或空字符串 `""`，前端做数值展示时建议 `parseFloat` 并判 `NaN`
- 详情接口中 `response.data.bcti` 现在为 `null`，建议使用可选链 `response?.data?.bcti?.bcti4?.score` 并做好 null 兜底
- 排序参数 `sortType` 为可选字段，不传时行为与 V1.4.7 完全一致（向后兼容）
