# V1.4.9 caseBasicInfo 新增教师全景视频URL 前端对接

## 接口信息

| 项目 | 说明 |
|------|------|
| 所属接口 | `GET /v2/teachingDiagnosis/getDiagnosisResult` |
| 请求参数 | `diagnosisId` — 诊断记录ID |
| 响应格式 | `ResponseData<SelfDiagnosisResponseVO>` |
| 新增字段路径 | `data.caseBasicInfo.teacherPanoramaVideoUrl` |

---

## 新增字段

| 字段 | 类型 | 说明 |
|------|------|------|
| `teacherPanoramaVideoUrl` | `String` | 教师全景视频的 OSS 签名地址 |

---

## 数据来源

- 取值逻辑：从录播服务（recording-service）查询课堂视频资源表 `t_recording_classroom_video`，筛选 `videoType=2`（教师全景）的视频，通过 OSS 签名后返回
- 可空性：当录播课堂无教师全景视频或无录播数据时，字段值为 `null`

---

## 响应示例

```json
{
  "code": 200,
  "msg": "ok",
  "data": {
    "caseBasicInfo": {
      "id": "2001234567890123456",
      "reportType": "B",
      "scoreLevel": "C",
      "teacherPanoramaVideoUrl": "https://oss-cn-hangzhou.aliyuncs.com/classroom/recording/1909521987334656002/teacher_panorama.mp4?Expires=1762501880&OSSAccessKeyId=LTAI5tSTywcdEN3gpiFesLDs&Signature=xxxxx",
      "bReport": { "...": "..." }
    }
  }
}
```

---

## 前端使用建议

- 非空时（`teacherPanoramaVideoUrl != null`），可直接作为 `<video>` 标签的 `src` 属性播放
- 为空时，前端可根据场景隐藏教师全景视频入口或展示空状态占位
