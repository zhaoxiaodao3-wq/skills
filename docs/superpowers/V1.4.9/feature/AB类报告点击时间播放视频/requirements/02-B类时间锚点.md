# B 类报告时间锚点 + 视频弹窗 · 补充需求

**版本：** V1.4.9  
**分类：** feature  
**模块：** AB类报告点击时间播放视频  
**生效范围：** **B 类报告**（`reportType === 'B'`）  
**复用：** 与 A 类相同的时间识别规则、`.time-anchor` 样式、单例可拖拽弹窗、无 URL Toast「暂无课堂视频」、`assets(teacherPanoramaVideoUrl)`、播放失败仅提示不自动续签

---

## 一、需求概述

在 B 类「课堂教学内容分析」报告中，对下列指定位置内符合时间格式的文本提供可点击能力；点击后行为与 A 类一致：

| 条件 | 行为 |
|------|------|
| `caseBasicInfo.teacherPanoramaVideoUrl` 非空 | 打开/复用单例弹窗，经 `assets()` 解析后播放，并 seek 到对应时刻 |
| URL 为空 | 不弹窗；Toast「暂无课堂视频」；时间仍为可点链接样式 |

本期**不**改视频弹窗视觉与拖拽规范，**不**引入 Mock 视频。

## 三、时间识别与跳转（继承 + 待确认）

### 3.1 与 A 类一致的规则

1. 支持时间单独成字段，也支持嵌入整段文字  
2. 时间段（如 `01:20-03:45` / `00:12:01-00:14:19`）点击跳转至**起始时刻**  
3. 只改样式与点击，不改原文其他字符  
4. 样式沿用 `.time-anchor`（色 `#027AFF`、字重 600、下划线、pointer）

### 3.2 时间格式确认项（写需求时待产品确认）

B 类报告真实/Mock 数据中常见 **`时:分:秒`**（如 `00:02:06`、`00:12:01-00:14:19`），与需求原文中的「分:秒」示例并存。

| 选项 | 说明 |
|------|------|
| **A（推荐）** | 解析升级为同时支持 `分:秒` 与 `时:分:秒`（及对应时间段）；A/B 共用同一解析，避免 B 跳错点 |
| B | B 仅按现有 A 解析（`分:秒`）；若数据为 `时:分:秒` 则可能误匹配或跳错，不推荐 |

**默认按 A 写入后续 spec，除非确认选 B。**

## 四、实现约束（产品侧）

1. **挂载：** 仅在 B 类视图树（`ReportTypeBView`）注入与 A 相同的时间视频能力（`provide` + 单例弹窗）；复用已有 `TimeAnchorText` / `useReportTimeVideo` / `ReportTimeVideoDialog`  
2. **视频 URL：** 仍取自页内 `caseBasicInfo.teacherPanoramaVideoUrl`，经 `assets()` 处理  
3. **表格列：** 通过列 `prop` / 列名映射接入（如 `evidence`、`method`、`reaction`、`content`、`timing`、`handling`、`timestamp`、`basis` 等，以实现时与 mapper/mock 对齐为准）  
4. **5.3 卡片时间段：** 卡片标题右侧 `headerBadge` 整段作为时间锚点文本解析  
5. **3.3 典型学生输出摘录：** 列表项字符串内嵌时间可点（与 A 类卡片列表接入方式一致）  
6. **性能：** 仅在上述模块渲染路径启用，避免 B 报告全页扫描
