# A 类报告时间锚点 + 视频弹窗功能需求文档

**版本：** V1.4.9  
**分类：** feature  
**生效范围：** **A 类报告**（B 类见 [02-B类时间锚点.md](./02-B类时间锚点.md)）

## 一、需求概述

在 A 类报告页面中，对指定模块内所有符合「分:秒」格式的时间文本进行自动识别，统一设置为可点击的链接样式；用户点击时间文本后：

- 若诊断结果中存在教师全景视频地址，则弹出可拖拽的视频播放弹窗，并自动跳转到对应时间点开始播放；
- 若不存在视频地址，则 Toast 提示「暂无课堂视频」，不打开弹窗。

视频播放源取自诊断结果接口字段 `caseBasicInfo.teacherPanoramaVideoUrl`，**不再使用 Mock 视频**。

## 二、时间生效范围

需识别并添加点击能力的模块如下：

1. 第三大点「依据摘录」模块内的所有时间文本
2. 4.1 模块表格中「时间戳」列对应的时间文本
3. 5.3 卡片内「可识别突破方法」「学生显性理解反应」两个区域中的时间文本
4. 5.6 模块「典型学生输出摘录」内的时间文本
5. 6.1 模块表格「依据」列内的时间文本
6. 6.2 模块表格「依据」列内的时间文本

## 三、时间识别规则

1. **匹配格式**：统一识别 `分:秒` 格式文本，兼容以下写法：
   - 两位数分钟：如 `08:01`
   - 一位数分钟：如 `8:12`、`8:01`
2. **场景支持**：支持时间单独成字段展示，也支持时间嵌入在整段文字之中
3. **时间段处理**：如遇 `01:20-03:45` 形式的时间段，点击后跳转至**起始时间**（即 01:20）
4. **识别原则**：仅对符合格式的时间文本做样式与点击改造，不修改原文其他内容

## 四、时间文本样式规范

统一使用以下样式；**无论是否存在视频 URL**，符合规则的时间文本均为**可点击态**（链接样式不变）：

```css
.time-anchor {
  color: #027AFF;
  font-family: "PingFang SC";
  font-size: 16px;
  font-style: normal;
  font-weight: 600;
  line-height: normal;
  text-decoration-line: underline;
  text-decoration-style: solid;
  text-decoration-skip-ink: none;
  text-decoration-thickness: auto;
  text-underline-offset: auto;
  text-underline-position: from-font;
  cursor: pointer;
}
```

## 五、核心交互逻辑

1. 点击任意时间文本时，先判断当前诊断结果中的教师全景视频 URL：
   - **有 URL**（非 `null`、非空串）：立即打开视频弹窗，并从点击对应的时间点开始播放
   - **无 URL**：不打开弹窗；Toast 提示「暂无课堂视频」
2. 同一页面仅保留一个视频弹窗实例；点击新时间时，弹窗内视频直接跳转至新时间点，不重复弹窗
3. 关闭弹窗时视频自动暂停，下次打开保留上次播放位置（可配置）
4. 时间点击功能与页面其他滚动、展开收起操作无冲突

## 六、视频弹窗功能规范

### 1. 基础能力

- 弹窗包含：视频播放区域、关闭按钮、播放/暂停控制、进度条、音量控制
- 弹窗支持**鼠标拖拽自由移动**，拖拽边界限制在浏览器可视区域内，不可拖出视口
- 弹窗默认居中展示，拖拽后位置保留，关闭再打开恢复默认居中

## 七、真实视频源（接口）

### 1. 接口与字段

| 项目 | 说明 |
|------|------|
| 所属接口 | `GET /v2/teachingDiagnosis/getDiagnosisResult`（请求参数：`diagnosisId`） |
| 字段路径 | `data.caseBasicInfo.teacherPanoramaVideoUrl` |
| 类型 | `String`，教师全景视频的 OSS 签名地址 |
| 可空 | 无教师全景视频或无录播数据时为 `null` |

详细说明见：[V1.4.9_caseBasicInfo_教师全景视频URL.md](../docs/V1.4.9_caseBasicInfo_教师全景视频URL.md)

### 2. 前端取值方式

- 复用 A 类报告页**已加载**的诊断结果，从 `caseBasicInfo.teacherPanoramaVideoUrl` 读取
- **不**为点击播放单独再请求诊断接口
- 非空时经 `assets()`（`@/utils/assets`）解析后作为 `<video>` 的 `src`：相对路径会拼 `VITE_REQUEST_ASSETS_BASE_URL`，与视频管理预览一致；为空时走第五节「无 URL」分支（Toast，不弹窗）
- **不提供 Mock 视频兜底**（开发/联调同样只认该字段或空态）

### 3. 播放失败 / 签名过期

- OSS 签名地址可能过期，导致加载失败或播放中断
- 前端仅做失败提示（Toast 或弹窗内错误态），**不自动重拉** `getDiagnosisResult` 续签续播
- 用户需刷新页面、重新进入诊断结果后再播放

## 八、技术实现要求

1. **技术栈**：基于 Vue3 + Element Plus 实现，复用项目现有组件与工程规范
2. **实现方式**：通过正则表达式自动匹配目标模块内的时间文本，动态渲染为可点击节点
3. **组件化**：视频弹窗封装为独立通用组件，支持多页面复用
4. **视频源绑定**：弹窗 `src` 绑定诊断结果中的 `teacherPanoramaVideoUrl`；通过统一变量/注入管理，与时间跳转逻辑解耦
5. **工程规范**：遵循项目前端规范，核心逻辑添加清晰注释，变量命名对齐项目标准
6. **性能**：文本匹配仅在对应模块渲染时执行，避免全页面扫描造成性能损耗

## 九、验收要点

- [ ] 仅 A 类报告生效；指定模块内 `分:秒` 时间均为可点击链接样式
- [ ] 有 `teacherPanoramaVideoUrl`：点击打开弹窗并从对应时刻播放；同页单例，再点只 seek
- [ ] 无 URL：点击 Toast「暂无课堂视频」，不打开弹窗；时间样式仍为可点击态
- [ ] 无 Mock 视频；视频地址仅来自诊断结果字段
- [ ] 播放/签名失败仅提示，不自动重拉接口
- [ ] 弹窗拖拽、控件与 Figma 参考一致（在既有规范内）
