## 一期确认

| 项 | 结论 |
|----|------|
| 路由 | `/teacher-profile`，`noAuth` |
| 链接参数 | **`token`**（query）：业务数据拉取凭证 |
| 打开方式 | ① 链接直接打开 ② 扫码打开（二维码内容 = 同一落地 URL，含 `token`） |
| 有效内容 | `status === 0` → 内容空壳 |
| 无效态 | `status` 为 1/2/3 → **同路由内组件** `ShareInvalidState`（不另开路由） |
| status | 接口返回（一期 mock）；请求时带上 `token` |
| 分享 | title=`教师画像`，desc 空，封面约定 OSS |
| 导航 | 左上角关闭 → 回微信 |

## 链接示例

```
https://{h5-host}/teacher-profile?token={shareToken}
```

自测覆盖 status（可选，仅开发）：

```
/teacher-profile?token=mock-token&mockStatus=3
```

## status 约定

| 码 | 含义 | 展示 |
|----|------|------|
| 0 | 有效 | 内容空壳 |
| 1 | 不存在 | 无效态组件 |
| 2 | 已撤销 | 无效态组件 |
| 3 | 已过期 | 无效态组件 |
