# H5 教师画像统计图标 rem 适配

## 项目

代码仓库：`E:\code\H5`（教师画像分享页）

## 问题

分享页中以下两个组件底部「综合得分 / 综合等级」旁的图标，在任意屏幕宽度下尺寸固定，不随 rem 缩放：

1. 课堂结构清晰度 — `ClassroomClarityPanel.vue`
2. 语言可理解度 — `LanguageComprehensibilityPanel.vue`

## 原因（探索结论）

两处均使用 `<MrIcon :size="16">`。`MrIcon` 对 number 类型会设置内联 `--x-icon-size: 16px`，不经过 `postcss-pxtorem`，故视口变化时图标不缩放。外层 wrap（30px）等 CSS 会 rem 化，图标本体不会。

## 期望

图标按设计稿 16px 随 `getRemScale()` / `designPx` 与页面其它元素同步缩放；resize 时更新。
