# 教师画像分享链接 token 改 code

## 需求

本仓库（PC）教师画像页分享组件拼接的 H5 链接查询参数，由 `token` 改为 `code`。

## 现状

`buildTeacherProfileShareUrl` 生成：

`.../teacher-profile?token=<值>`

## 期望

`.../teacher-profile?code=<值>`

## 关联路径

- `src/pages/school/teacher-portrait/utils/build-teacher-profile-share-url.ts`
- `src/pages/school/teacher-portrait/utils/build-teacher-profile-share-url.spec.ts`
- （下游）H5 `useTeacherProfileShare.ts` 当前读 `route.query.token`，改 query 名后需同步读 `code`，否则分享页打不开

## 说明

接口 `createShare` 返回字段名是否仍叫 `token`：仅改 URL 拼接参数名；若后端返回也改为 `code`，需另说。
