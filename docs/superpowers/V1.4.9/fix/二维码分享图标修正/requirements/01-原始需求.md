# 二维码分享图标修正

## 问题

`AppShareLink` 内所有图标（分享按钮、弹窗链接区、复制按钮、扫码区）与 Figma 不符，当前为手写近似 SVG。

## 设计稿图标（Miray）

| 位置 | Figma 组件名 |
|------|----------------|
| 分享按钮 | `mr-general-launch` |
| 弹窗「分享链接」标题 | `mr-general-link` |
| 「复制链接」按钮 | `mr-edit-copy` |
| 弹窗「扫码打开」标题 | `mr-general-qrcode` |

Figma：
- 按钮样式1：`7485:12338`
- 弹窗：`7490:20801`

## 期望

严格使用设计稿对应图标资源，颜色与尺寸对齐 Figma。
