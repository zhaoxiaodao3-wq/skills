# 教师画像分享动态 token · 原始需求

**来源：** 用户 `/harness`  
**日期：** 2026-07-21  
**分类：** api-adapter

## 诉求

教师画像分享链接改为 H5 教师画像落地页格式，且 **token 动态获取**：

1. 链接格式：`https://m-test.mirayai.com:31594/teacher-profile?token=abc123`（host 按环境，路径与 query 固定为 `/teacher-profile?token=`）
2. 每次点击「分享」按钮，先请求：
   - `POST /api/analysis/v2/teachingDiagnosis/share/create`
   - 参数：`shareType: 3`，`businessId: <当前选中人的 tenantUserId>`
3. 拿到 token 后拼进链接，再打开分享弹窗
4. token 为空或请求失败 → 提示「分享失败」，**不打开弹窗**

## 关联

- 校端：`src/pages/school/teacher-portrait` 画像卡片分享入口（`AppShareLink`）
- H5 落地：`/teacher-profile?token=...`（已有调研/需求）
- 环境变量：`VITE_SHARE_URL`（如 test：`https://m-test.mirayai.com:31594/`）
