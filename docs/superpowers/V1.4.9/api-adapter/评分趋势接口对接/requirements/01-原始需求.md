# 评分趋势 · 真实接口对接

## 一、需求概述

将「课堂教学内容评价」模块底部「评分趋势」从前端 Mock 替换为真实接口；接口字段与现有 ViewModel 不一致，需在前端做 VO → ViewModel 转换。图表样式与布局不改。

## 二、接口文档

| 项 | 内容 |
|----|------|
| 文档 | [../../feature/课堂教学内容评价评分趋势/docs/scoreTrend接口文档.md](../../feature/课堂教学内容评价评分趋势/docs/scoreTrend接口文档.md) |
| 路径 | `GET /analysis/v2/teachingDiagnosis/scoreTrend` |
| 参数 | `tenantUserId`（必填） |

### 响应 data 单项（ScoreTrendVO）

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | Long | 课例记录 ID |
| `name` | String | 分析名称 |
| `scoreLevel` | String \| null | `EXCELLENT` / `GOOD` / `QUALIFIED` / `NEED_IMPROVEMENT` |
| `score` | number \| null | 总分 |
| `reportType` | String | `A` / `B` |
| `genTime` | String | 生成时间，通常 `yyyy-MM-dd HH:mm:ss` |

## 三、与现有前端差异

前端 `ScoreTrendReportItem`：

| ViewModel | 接口 | 转换 |
|-----------|------|------|
| `reportType` | `reportType` | 校验为 `A`/`B`，非法丢弃整条 |
| `score` | `score` | 可空；空则保留条目，展示 `--`，折线该点不画 Y |
| `lessonName` | `name` | 直接映射；空串兜底 `--` |
| `generatedAt` | `genTime` | 规范化为可解析时间串 |
| `gradeKey` / `gradeLabel` | `scoreLevel` | 见下表；空/未知保留条目，文案 `--` |
| （可选）`id` | `id` | 本期图表未用，adapter 可忽略 |

### 等级映射（已确认）

| 接口 `scoreLevel` | `gradeKey` | `gradeLabel` |
|-------------------|------------|--------------|
| `EXCELLENT` | `excellent` | 优秀 |
| `GOOD` | `good` | 良好 |
| `QUALIFIED` | `pass` | 合格 |
| `NEED_IMPROVEMENT` | `needsImprovement` | 待改进 |
| `null` / 空 / 未知 | `null` | `--` |

## 四、涉及路径

| 路径 | 说明 |
|------|------|
| `src/pages/school/teacher-portrait/api/` | 新增 scoreTrend 请求与 VO 类型 |
| `src/pages/school/teacher-portrait/adapters/` | 新增 score-trend adapter |
| `src/pages/school/teacher-portrait/components/classroom-content-eval/` | Container 接真接口；类型/tooltip 兼容空值 `--` |
| `score-trend.mock.ts` | 可保留供 debug，默认不再作为生产数据源 |

## 五、约束

1. 不改图表样式、布局比例（除数据源与空值展示）
2. `data: []` 或失败时走空态（空坐标系），不阻断环图/雷达
3. 评分趋势与画像聚合接口解耦：按 `activeTeacherId` 独立请求
4. 切换教师时重新拉取；无 `tenantUserId` 时不请求
5. `score` / `scoreLevel` 为空时**保留数据**，文案展示 `--`

## 六、验收要点

- [ ] 有数据时展示真实 A/B 折线，tooltip 课例名/分数/评级/时间正确
- [ ] 等级 `EXCELLENT/GOOD/QUALIFIED/NEED_IMPROVEMENT` 正确映射为优秀/良好/合格/待改进及对应色点
- [ ] `score` / `scoreLevel` 为空时保留点位，文案为 `--`
- [ ] 空列表 / 接口失败 → 趋势空态，其他子模块不受影响
- [ ] 切换教师后趋势数据随之更新
- [ ] 默认不再使用 Mock 作为生产数据源
