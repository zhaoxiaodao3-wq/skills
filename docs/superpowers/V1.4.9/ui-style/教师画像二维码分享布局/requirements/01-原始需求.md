## 四、当前实现 vs Figma 差异（布局）

### 现状（代码）

1. 姓名行：`姓名` + `主导/辅助风格徽章` 同一行（`justify-between`），底部有分割线
2. 元信息行：性别 / 主教科目 / 上课总时长
3. 个人特征标签区
4. **无**分享按钮；姓名旁**无**性别短标签

### 目标（Figma 7485:12328）

1. **姓名行**（左右两端对齐）
   - 左侧：姓名（30px Semibold）+ 性别短标签（如「男」+ 性别图标，品牌蓝 `#027aff`）
   - 右侧：**分享链接**按钮（实心蓝，高约 32px，图标 `mr-general-launch` + 文案「分享链接」）
2. **风格徽章行**（姓名行下方，仍在分割线上方）
   - `主导风格` 胶囊 + 中间 `×` 图标 + `辅助风格` 胶囊
3. **分割线**（`0.5px #e5e6eb`）位于姓名区 + 风格徽章区整体底部
4. **元信息行**：性别 / 主要科目 / 上课总时长（分钟）
5. **个人特征标签区**：圆角边框容器内多色标签（保持现有数据与主题逻辑）

## 五、功能要求

### 5.1 分享入口

1. 在姓名行右侧接入 `AppShareLink`（默认 `variant="solid"`，`label` 默认「分享链接」）
2. 点击后行为与现有分享组件一致：打开弹窗 → 展示分享链接 + 二维码（含 loading / success / error）
3. 本阶段分享链接来源：沿用 `AppShareLink` 内置 Mock；若后续有教师画像专用分享 URL，通过 `resolveShareUrl` 注入，**本次可不对接新接口**
4. 空态（`isEmpty`）下分享按钮：**常显示**（本期不做隐藏逻辑；已确认）

### 5.2 布局结构调整（不得破坏既有逻辑）

1. 将「主导/辅助风格徽章」从姓名行拆到独立一行，对齐 Figma
2. 姓名左侧增加性别短标签（有性别数据时展示；无数据时不展示短标签，元信息行仍按现有 `--` / `-` 规则）
3. 元信息文案：设计稿为「主要科目」，现网为「主教科目」——**以设计稿「主要科目」为准**（仅改展示文案，不改字段）
4. 风格徽章圆角：设计稿为全圆角胶囊（`border-radius: 999px`，左右 padding 约 15px）；与现网 `4px` 不一致时**以 Figma 为准**
5. 左侧 300×300 画像区、渐进加载、空图、主题色映射、特征标签选色逻辑**保持不变**

### 5.3 兼容与回归

1. loading（`v-loading`）行为不变
2. 无主导/辅助风格时不渲染徽章行（与现网一致）
3. 无特征标签时仍显示「暂无个人特征数据」
4. 响应式：右侧内容区 `min-width: 0`、换行策略保持可用；窄宽下姓名行与分享按钮不互相遮挡（允许换行）
5. **禁止**改动画像聚合数据拉取、Container 映射、其他教师画像子模块

## 六、非目标（本次不做）

1. 不重写 / 不改 `AppShareLink` 弹窗与二维码生成逻辑（除非发现接入时的纯类型/导出问题）
2. 不新增后端分享接口对接（预留 `resolveShareUrl` 即可）
3. 不改教师列表、教学风格趋势等其他模块布局
4. 不做与本卡片无关的视觉重构
