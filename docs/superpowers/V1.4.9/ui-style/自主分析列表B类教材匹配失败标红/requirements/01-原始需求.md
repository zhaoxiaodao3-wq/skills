# AI 自主分析列表 · B 类报告类型条件标红

## 一、需求概述

页面：`/classroom-app/school/analysis-management/ai-autonomous-analysis`  
（`src/pages/school/analysis-management/ai-autonomous-analysis/index.vue`）

在列表「报告类型」列：当同时满足以下条件时，**报告类型文案标红**：

1. `reportType == "B"`
2. `textbookAsrMatchStatus == 3`

其它情况保持现有黑色/默认样式。报告类型展示文案逻辑（含 revising 时显示 `-`）不变。

## 二、现状

- 「报告类型」列：`<span>{{ getReportTypeDisplay(row) }}</span>`，无条件样式
- 列表行需能读到 `row.reportType`、`row.textbookAsrMatchStatus`（若接口未返回该字段则无法标红，需确认列表接口已带出）

## 三、改动范围（预估）

| 路径 | 说明 |
|------|------|
| `ai-autonomous-analysis/index.vue` | 报告类型列按条件加红色 class/style |

## 四、验收

- [ ] `reportType=B` 且 `textbookAsrMatchStatus=3` → 报告类型文案为红色
- [ ] 仅 B、或仅 status=3、或其它类型 → 不标红
- [ ] revising 等仍显示 `-` 时不标红（或按产品：无文案则无红色）
