**组件：** 课堂教学内容评价 →「评价维度得分」

## 背景

评价维度得分因新增 A2/B2 报告类型需更新：原已完成能力归为 A1/B1；接口将一并返回各子类型数据，但同一大类（A / B）同一时刻只展示一个子类型，需轮播与可点指示条。

## 需求条目

1. **A1/B1 兼容**：原有维度标题、满分、雷达样式不变；按设计稿新增类型标签（A1 / B1 等）。
2. **轮播**：同一大类下子类型轮播；未 hover 累计满 5s 自动切下一子类型并无限循环；hover 图表区暂停累计（不重置），移出后继续累计剩余时间。例：已过 3s → hover → 移出后再过 2s 切换。
3. **A / B 计时独立**：工程化抽可复用轮播逻辑，A、B 各一实例。
4. **切换动画**：图表与标签切换需丝滑；建议 GSAP。
5. **指示条**：可点击切换；选中 / 未选中 / hover 三态按设计区分；切换时滑块宜有「水滴」morph 感（GSAP）。
6. **A2/B2 维度**（二者相同，**五维五边形**，不以稿面六维占位为准）：

   | 维度 | 满分 |
   |------|------|
   | 知识落实度 | 35 |
   | 逻辑清晰度 | 25 |
   | 导入设计 | 20 |
   | 学生参与度 | 10 |
   | 小结设计 | 10 |

7. **Mock**：接口暂无 2 类数据，前端 mock A2/B2 以便验收。

## P1 确认记录

- 档位：全量
- A2/B2：实际五维五边形（用户确认）
- B 类大标题文案：保持线上「基于教材与上课」，不跟稿缺字「基教材」
