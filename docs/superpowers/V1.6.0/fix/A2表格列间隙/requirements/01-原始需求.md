# A2表格列间隙 · 原始需求

**日期：** 2026-09-15  
**模块：** `fix/A2表格列间隙`  
**档位：** 标准  
**类型：** fix（PDF 表格样式）

---

## 背景

A2 PDF 正文表（`ClassroomContentAnalysisReportA.html`）目前主要靠 `<colgroup>` 百分比定列宽，单元格左右 padding 为 `0`。相邻列内容都撑满时视觉拥挤。

## P1 已确认

- **方案 A**：仅 PDF（不做 Web）
- 屏显 HTML 与 **打印 / `page.pdf`** 用**同一套**单元格左右间距规则
- 间距提取为 **`:root` 全局 CSS 变量**，改一处即可统一生效（打印侧通过现有 space 缩放或同名变量覆盖，避免两套硬编码）

## 范围

### 必做

1. `src/report/report/A2/ClassroomContentAnalysisReportA.html`
   - `:root` 增加表格横向内边距变量（建议绑定已有 `--ccar-space-md`，屏显 8px；`@media print` 已缩 space，打印自动约 5px）
   - `.ccar-table th/td` 与 `.ccar-a2-highlight-table th/td` 使用该变量作左右 padding
   - 不在 print 块再写死另一套 px（除非变量本身在 print `:root` 覆盖）
2. 同步 `scripts/gen-ccar-a2-static-html.mts` 同源 CSS，避免下次 `gen:ccar:a2` 冲掉

### 不做

- Web `ReportDataTable` / `a2-table-columns.ts`
- 改 colgroup 百分比、用空列伪装间隙、改 `border-collapse`

## 验收要点

1. 列间有稳定视觉间隙，长文案相邻列不再贴死
2. 浏览器预览与打印 / PDF 行为一致（均走同一变量）
3. 只改 `:root` 变量即可调整全表列间隙
4. 亮点表与通用 `.ccar-table` 一致
