## 背景

A2 报告（课堂教学内容分析）中，多处「蓝色序号框 + 旁侧正文」行在**仅一行正文**时，相对 36×36 序号框顶对齐，视觉上不居中。用户希望：

- **单行**：正文相对序号 **垂直居中**（`align-items: center`）
- **多行**：正文整块仍顶对齐序号（`align-items: flex-start`）

页面入口示例：  
`/classroom-app/analysis-web/.../classroom-content-analysis` → 板块三「思维跨度合理性评估」等。

## 范围（P1 已确认 · 方案 A′ · PDF 暂不改）

### 必做（Web）

1. `ReportA2NumberedPanel.vue`  
   覆盖板块一～四、教案重难点参考信息等全部 `a2NumberedPanel` 序号行。
2. `ReportA2BloomStatsPanel.vue`  
   **维度三 高低阶结构合理性** 的 `.cca-a2-bloom-dimension-item` 序号行。

### 不做

- PDF / Thymeleaf（`ClassroomContentAnalysisReportA.html`）本次不改
- 知识卡片、缺失网格、评分弹窗等非「蓝序号框 + 旁侧正文」结构
- H5（本仓无同源组件）

## 验收要点

1. 单行正文时，文字相对蓝色序号框垂直居中。
2. 换行后，序号顶对齐，正文块 `flex-start`。
3. 编号面板与 Bloom 维度三行为一致。
4. 窗口缩放导致单行↔多行切换时，对齐能随之更新。

## 范围补充（2026-09-14 · PDF 预览）

用户确认后补改 PDF 模板 `src/report/report/A2/ClassroomContentAnalysisReportA.html`：与 Web 同逻辑（单行 center / 多行 flex-start），CSS 默认 center + class `ccar-a2-index-align--multiline`，页尾脚本按内容高度相对序号框高度判定。
