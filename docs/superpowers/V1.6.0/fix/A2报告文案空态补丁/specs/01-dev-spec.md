# A2 报告文案空态补丁 · 开发规格

**Requirement:** [requirements/01-原始需求.md](../requirements/01-原始需求.md)

## 1. 目标

修正 A2 报告若干文案/表头/mock 结构，并统一空态兜底规则（字段 `--` / 整块「暂无数据」），Web 与 H5 分享页 mock 保持语义同步。

## 2. 文案与结构变更

| ID | 位置 | 变更 |
|----|------|------|
| C1 | Hero / 总览「课堂时长」 | 仅展示时长本体，去掉 `（…）` 及括号内区间；例 `36分01秒（00:00:00 - 00:36:01）` → `36分01秒` |
| C2 | 3.4.1 表 | 列：`分析项`、`观察内容`、`评价`、`理由`；mock 将原知识类型+推荐方式合并写入「分析项」 |
| C3 | 3.4.2 / 3.4.3 表 | 「观察内容」→「观察内容（从音转文提取）」 |
| C4 | 3.6.1 维度二 | 标题去掉括号后缀，如 `维度二 目标-问题一致性` |
| C5 | 3.6.1 维度三 | 三项均为「标题 + 内容」：①低阶思维（记忆+理解+应用）占比 ②结构判断 ③核心发现；调整 mock 与渲染契约 |
| C6 | 3.6.2（三）目标指向分析 | 列表三项：目标指向、与重难点的关联、目标达成效果（可「标题：内容」或等价分段） |

## 3. 空态规则

| 粒度 | 展示 | 说明 |
|------|------|------|
| 标量 / 表单元格 / 列表字段 | `--` | 空串 / null / 空白 |
| 整块 / 整节无业务内容 | 保留标题结构 +「暂无数据」 | 与 flags「不适用」文案区分：不适用用既有 emptyNote/不适用句；无数据用「暂无数据」 |
| flags 关闭 | 既有 requireFlag + emptyNote / 不适用 | 不强制改成「暂无数据」，除非与上表冲突时以产品清单为准 |

### 3.1 空态开关

- **Web：** 保留/完善 A2 flags 探针（或等价 mock 空态开关），可切换验收  
- **H5：** 保留右下角 Empty Probe；补齐章一～十探针覆盖，使字段空 → `--`、关键整块可验「暂无数据」

### 3.2 空态清单（实现时勾选）

实现阶段按下列区块核对并补齐（Web 渲染 + H5 `displayValue` / 整块占位）：

| 区块 | 字段 `--` | 整块「暂无数据」/既有 empty |
|------|-----------|---------------------------|
| Cover / Hero 元信息 | ✓ | N/A（壳保留） |
| 总览评分/等级 | ✓（空分不带「分」） | N/A |
| 章一 总结/亮点/不足 | ✓ | 列表空 → 暂无数据或单卡占位 |
| 章二～三 各 FieldCard / 表 / 面板 | ✓ | requireFlag 块沿用 emptyNote |
| 3.4 表 | ✓ 单元格 | 无行且非 flag → 暂无数据 |
| 3.5 / 3.6 Bloom / 问题链 | ✓ | flag 关 → 不适用；数据空 → 暂无数据 |
| 章四～十 | ✓ | 同规则；章五无小结教学行为沿用既有门控 |
