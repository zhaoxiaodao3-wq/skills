# Spec：A2 报告文案（报告模板与档位）

**Requirement:** [requirements/01-原始需求.md](../requirements/01-原始需求.md)

## 行为

1. Web A2 头部展示「报告模板：{value}」。  
2. PDF A2 正文头部展示「报告模板：A2」（或绑定值）。  
3. A2 报告用户可见文案中不得出现「挡位」（应为「档位」）；探查若已全部为「档位」则本项验收为扫描通过。

## 非目标

- H5 头部文案  
- B2 / A1 其它报告类型（除非同文件误伤）

## 验收

- [x] Web A2 头为「报告模板」  
- [x] PDF A2 头为「报告模板」  
- [x] `rg 挡位` 在 A2 相关路径为 0
