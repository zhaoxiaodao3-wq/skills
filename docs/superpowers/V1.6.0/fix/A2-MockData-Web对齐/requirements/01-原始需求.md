## 背景

A2 PDF 生成器（`E:\code\a2-pdf-generator`）的 mock 数据工厂 `A2MockDataFactory.java` 写得过于"直接"——直接把 VO 字段映射到字符串，**没有按 web 端的方式做数据裁剪/格式化**。导致 PDF 渲染出的内容与 web 端不一致。

## 关联文件

- **改动**：`E:\code\a2-pdf-generator\src\main\java\com\mirayai\tools\A2MockDataFactory.java`
- **对照**（web 端 A2 组件，`E:\code\frontend\src\pages\analysis-web\ai-teaching-diagnosis\classroom-diagnosis\components\`）：
  - `ReportA2NumberedPanel.vue`（3.2 知识呈现逻辑 - 4 板块）
  - `ReportA2KnowledgeMatrix.vue`（3.1 知识点教学 + 3.3 教案重难点参考）
  - `ReportA2BloomStatsPanel.vue`（3.6.1 Bloom + 高低阶结构）
  - `ReportA2ProblemChainStack.vue`（3.6.2 问题链）
  - `ReportA2ScoreSummary.vue`（10.1 评分汇总）
