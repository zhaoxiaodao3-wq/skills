## 1. 目标

3.3「教案重难点参考信息」两条展示与 mock 同构：`leadLabel`（加粗）+ `leadContent`；从接口 `string[]` 整串解析拆出。

## 2. 范围

**做：**

- 新增（或内联）解析函数，将 `planReference` 每条拆为：
  - `leadLabel`：固定前缀，含冒号，如 `教案中标注的教学重点：` / `教案中标注的教学难点：`
  - `leadContent`：冒号后正文；无匹配时整行作 `leadContent`，`leadLabel` 可按槽位回填固定前缀或留空（见下方规则）
- 替换 `mapNewKnowledgeChapter` 中对该块的 `mapNumberedFromStrings(...)` 调用
- 单测覆盖：标准两行前缀、中英文冒号、缺前缀/乱序/空数组

**不做：**

- 维度三布局/换行
- 改 `ReportA2NumberedPanel` 样式（已有 `__lead-label` 加粗）
- 改 3.3 其它 blocks
- 本期不强制改 H5（H5 接口对齐模块复用同一拆条规则即可；本 fix 交付以 Web 为准）

## 3. 解析规则

| 规则 | 说明 |
|------|------|
| 固定前缀 | `教案中标注的教学重点` / `教案中标注的教学难点`（后接 `：` 或 `:`） |
| 匹配 | 行首可选序号（如 `01` / `1.`）后匹配前缀；拆出 label（前缀+冒号）与 content |
| 槽位 | 优先按前缀语义落到 01=重点、02=难点；缺一条则该槽 `leadContent='--'` 或仅渲染有数据条（与现 numbered 空态一致即可） |
| 无前缀 | 若无法识别前缀：按数组下标 0→重点、1→难点 **回填固定 leadLabel**，全文作 leadContent（兜底，避免再丢加粗） |
| index | `01` / `02`，与 mock 一致 |

推荐正则形态（实现可微调）：

```text
/^(?:0?1[.、\s]*)?(教案中标注的教学重点)[：:]\s*(.*)$/s
/^(?:0?2[.、\s]*)?(教案中标注的教学难点)[：:]\s*(.*)$/s
```

## 4. 验收

- [x] 中文/英文冒号均可拆
- [x] 无前缀时仍显示固定加粗标题 + 正文（下标兜底）
- [x] 维度三展示无改动
- [x] mapper 单测覆盖上述分支
