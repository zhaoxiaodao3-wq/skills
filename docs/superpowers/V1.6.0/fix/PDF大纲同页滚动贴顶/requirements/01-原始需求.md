# PDF大纲同页滚动贴顶 · 原始需求

**日期：** 2026-09-17  
**分类：** fix  
**档位：** 标准

## 需求原文

网页 PDF 预览（`ai-teaching-analysis-report`）右侧大纲：

1. 点击一大点跳转后，若 1.1 / 1.2 已显示在当前视口内，再点 1.2 无反应；只有目标不在当前可见区时才有反应。
2. 点击后目标内容应滚到视口**顶部**（可留小 padding），现在常停在页面中部。

## 根因（探查）

`AppViewerAnalysis` 大纲跳转只取书签 `dest` 的**页码**再 `jumpPage(页码)`：

- 同页子节（一大点与 1.2 同页）→ 目标页不变 → 看起来没反应。
- 未使用 `dest` 页内 Y / 文本行 Y → 只能整页顶对齐，标题在页中则视觉上像停在中间。

## 范围

- 改：`src/components/AppViewerAnalysis/AppViewerAnalysis.vue`
- 不改：muban PDF 模板（本问题非锚点缺失）
