# A1/B1/B2 报告模板显示与字段统一 · 原始需求

> **模块：** `docs/superpowers/V1.6.0/fix/A1B1B2报告模板显示/`  
> **日期：** 2026-09-14  
> **页面：** `src/pages/analysis-web/ai-teaching-diagnosis/classroom-diagnosis/classroom-content-analysis.vue`

## 1. 现象

访问以下 URL 打开 A1 报告：

```
http://localhost:5174/classroom-app/analysis-web/ai-teaching-diagnosis/classroom-diagnosis/classroom-content-analysis?id=2099361925371019266&resourceType=AI自主分析
```

- **A2 报告**：顶栏右上角「报告模板：xxx」能正常显示（如 A2）
- **A1 报告**：同一位置显示 `--`
- **B1 / B2 报告**：未实际验证，预判为同样问题

## 2. 期望

不管后端下发的是 `reportType = A` 还是 `B`，只要 `reportVersion`（或回退 `reportSubType`）给到 A1/A2/B1/B2，顶栏「报告模板：xxx」就**显示该子类型**；若两个字段都缺失，则按当前 mapper 自身身份默认显示自身子类型（A1 页显示 A1，A2 页显示 A2，B1 页显示 B1，B2 页显示 B2）。

## 3. 接口契约

`CaseBasicInfo`（已在 `src/types/teaching-diagnosis-case-basic-info.ts`）：

| 字段 | 类型 | 来源 | 用途 |
|------|------|------|------|
| `reportType` | `'A' \| 'B' \| 'G'` | 后端 | 大类 |
| `reportSubType` | `'A1' \| 'A2' \| 'B1' \| 'B2' \| null` | 后端暂未下发（前端预留） | 子类型备选 |
| `reportVersion` | `string \| null` | **后端实际下发** | 子类型权威字段 |

## 4. 范围

### 4.1 必须改

1. **A1 / B1 / B2 mapper** 读取 `caseBasicInfo.reportVersion ?? caseBasicInfo.reportSubType`，并在两个字段都缺失时按 mapper 自身默认。
2. **A2 mapper** 沿用 `reportVersion ?? reportSubType` 的读取方式（已正确），并对齐默认值。
3. **4 个 mapper** 输出的顶栏字段统一为 `reportTemplate`（当前 A2 mapper 输出的是 `templateStyle`，命名分歧）。
4. **A2 hero header 组件** (`ReportA2HeroHeader.vue`) 与 A1/B1/B2 通用 header 组件 (`ReportHeroHeader.vue`) 都读 `header.reportTemplate`。
5. **A2 顶栏类型** `TypeA2HeaderMeta` 的 `templateStyle` 字段同步改名为 `reportTemplate`。

### 4.2 不改

- 不改 `parseReportVariant` / `getClassroomContentReportConfigByType` / `classroom-content-report-registry` 的路由逻辑（这些已经正确）。
- 不改 `ReportTypeAView` / `ReportTypeBView` / `ReportTypeA2View` / `ReportTypeB2View` 的 UI 主体结构。
- 不改 mock 主业务数据。
- 不动 `api-adapter/课堂教学内容报告子类型` 模块的已交付 spec/plan/archive（视为前置依赖，本模块独立 fix）。
