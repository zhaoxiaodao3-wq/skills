## 1. A1/B1 功能与样式回归结论

### 1.1 总论

在**不带** `?reportSubType=A2`（或 B2）的正常访问路径下，A2 改动**不会**改变 A1、B1 的功能与样式。

A2 采用**独立 View / Renderer / mock / 类型**，与 A1/B1 **并行而非替换**。

### 1.2 渲染路径隔离

| 版本 | View | Renderer | Mock / Mapper |
|------|------|----------|---------------|
| **A1** | `ReportTypeAView` | `ReportBlockRenderer` | `classroom-content-analysis-a.mock` + `a.mapper` |
| **A2** | `ReportTypeA2View` | `ReportA2BlockRenderer` | `classroom-content-analysis-a2.mock` + `a2.mapper` |
| **B1** | `ReportTypeBView` | `ReportBlockRenderer` | `classroom-content-analysis-b.mock` + `b.mapper` |

Registry 仅**新增** `A2` 条目；A1/B1 仍指向原 View 与原 mapper。  
A2 专用组件（`ReportA2*`、`cca-grid-mixins.scss` 等）**仅**在 A2 路径加载。

### 1.3 共享文件改动评估

| 共享点 | 改动性质 | 对 A1/B1 影响 |
|--------|----------|---------------|
| `cca-report-tokens.scss` | **新增** A2 间距变量；保留 `$cca-sub-section-spacing: 55px` | A1 仍用 `gap: 20px` + 原 `$cca-sub-section-spacing`，**样式不变** |
| `ReportBlockRenderer` | `equalHeightCards` 的 `title` 改为 `v-if="block.title"` | A1 mock 该 block 本无 title，不再渲染空标题，**无负面回归** |
| `resolve-classroom-content-report-context.ts` | query `reportSubType` 优先 | **仅**带 `?reportSubType=` 时生效 |
| `classroom-content-analysis-status.ts` | `subTypeFromQuery` 时跨 family 读 post 状态 | **仅**本地验 A2 mock |
| `classroom-content-static-payload.ts` | 增加 A2 分支 | A1/B 仍返回原 mock |
| `classroom-content-analysis-report.ts` | 类型联合增加 `TypeA2AnalysisPayload` | **编译期**，不影响运行时 |
| `classroom-content-analysis.vue` | 统一走 `reportRouteContext` | 默认无 subType 时行为与改前一致 |

**未改动：** `ReportTypeAView.vue`、`ReportTypeBView.vue`、`ReportHeroHeader.vue`、`ReportDataTable.vue`、`EqualHeightCardGrid.vue` 等 A1/B1 核心展示组件。

### 1.4 边界场景（非回归，属 A2 验收入口）

| 场景 | 行为 |
|------|------|
| 正常生产：`reportType=A`，无 `reportSubType` | **A1**，与改前一致 |
| 正常生产：`reportType=B`，无 `reportSubType` | **B1**，与改前一致 |
| 开发验 A2：`?reportSubType=A2` | **刻意**切到 A2 View/mock |
| B 课例 + `?reportSubType=A2` | 页态放宽（`postClassReportBStatus=7` 可进成功态），便于本地看 A2 mock |

### 1.5 自动化回归（审查时已通过）

- `report-compat-regression.spec.ts` — A 无 subType → A1，B 无 subType → B1
- `resolve-classroom-content-report-context.spec.ts` — 无 query 仍为 A1
- `classroom-content-analysis-status.spec.ts` — 无 query override 时 B 课例逻辑不变

### 1.6 建议手工冒烟

1. 打开 A 类课例，**不带** `reportSubType` → 确认仍是 A1（含「八、特别声明」等 A1 独有块）。
2. 打开 B 类课例，**不带** `reportSubType` → 确认 B1 布局与改前一致。
3. 仅当 URL 带 `?reportSubType=A2` 时才应看到 A2 页面与标题旁 Switch 探针。

## 2. 状态组件对齐审查

### 2.1 总论

**页面级「状态组件」链路 A2 与 A1 已对齐**；**数据空态判断尚未对齐**（A2 Phase 1 mock 故意放宽）。

A1 / A2 **共用同一页面壳**，无 A2 专用页面级状态组件。

### 2.2 已对齐项

| 层级 | 组件 / 逻辑 | A1 | A2 |
|------|-------------|----|----|
| 页面 | `classroom-content-analysis.vue` | ✅ 同一文件 | ✅ |
| 状态 UI | `AnalysisStatusDisplay` | ✅ | ✅ |
| 卡片容器 | `SectorCard`（loading / 居中） | ✅ 同一 props | ✅ |
| 页态解析 | `resolveClassroomContentAnalysisPageStatus` | ✅ A 类逻辑 | ✅ A 类逻辑 |
| 重试 | `useReportReanalyze` | ✅ | ✅ |
| 成功态 | `analysis-success` → 隐藏状态组件、展示报告 | ✅ | ✅ |

A 类页态映射（两者相同）：

```
planTeachingMatchStatus → plan-content-analyzing / plan-content-match-failed / not-started-analysis
postClassReportAStatus  → analysis-success / analyzing / analysis-failed
```

Registry 中 A2 的 `resolvePageStatus: resolvePageStatusA` 与 A1 一致。  
页面实际调用 `resolveClassroomContentAnalysisPageStatus`（非 registry 内 `resolvePageStatus`），A1/A2 在**无 query 覆盖**时行为相同。

> **说明：** `ReportA2NotApplicableFallback`、`ReportA2FlagSwitch` 属于报告内条件占位/开发探针，**不是**页面级 `AnalysisStatusDisplay`。

### 2.3 未对齐项

| 项 | A1 | A2 | 说明 |
|----|----|----|------|
| `hasReportData` | `hasAReportData()`：校验 `aReport` 各字段 | `hasA2ReportData()`：**恒为 `true`** | Phase 1 全 mock |
| 成功但无数据 | 显示 `ElEmpty`「暂无数据」 | 不进空态，直接展示 mock | 接口接入前预期 |
| 本地验 A2 | 无 query 时与 A1 相同 | `?reportSubType=A2` 可跨 family 读 B 的 post 状态 | 仅开发验 mock |

### 2.4 对齐结论表

| 维度 | 是否对齐 | 说明 |
|------|----------|------|
| `AnalysisStatusDisplay` 组件 | ✅ | 同一组件、同一 `STATUS_CONFIG` |
| 分析中 / 失败 / 未开始等页态 | ✅ | 共用 `classroom-content-analysis-status.ts` |
| SectorCard loading | ✅ | `analysisResultLoading && displayStatus === 'analysis-success'` |
| 重新分析交互 | ✅ | 同一 `useReportReanalyze` |
| 成功但无报告数据 → 空态 | ❌ | A2 mock 阶段 `hasA2ReportData` 恒 true |
| Registry `resolvePageStatus` | ⚠️ 冗余 | 页面未调用；A1/A2 均已注册但未使用 |

### 2.5 接口接入后待办

在 `classroom-content-analysis-a2.mapper.ts` 中：

1. 将 `hasA2ReportData` 改为校验 A2 接口字段是否有内容（对齐 A1 `hasAReportData` 思路）。
2. 无数据时在 `analysis-success` 下仍走 `ElEmpty`，与 A1 一致。
3. 视需要决定是否保留 `subTypeFromQuery` 跨 family 页态（仅开发用可移除或加环境开关）。
