## 3. TypeA2ReportFlags

```ts
interface TypeA2ReportFlags {
  hasKnowledgeRelationTypes: boolean
  hasThinkingSpanEvaluation: boolean
  hasGradeCognitionFit: boolean
  hasExperimentActivity: boolean
  hasProblemChain: boolean
  hasSummaryTeaching: boolean
  importHasCoreQuestion: boolean
}
```

### 渲染契约

| 机制 | 字段 | 行为 |
|------|------|------|
| `a2NumberedPanel.data.requireFlag` + `emptyMessage` | 3.2 板块 | flag false → 仅 emptyMessage |
| `table.requireFlag` + `emptyNote` | 3.4.2 | flag false → 无表，仅 emptyNote |
| `a2ProblemChainStack.data.requireFlag` | 3.6.2 | flag false → 表常显；逻辑区不适用文案 |
| `subSection.showWhenFlagTrue` | 5.1–5.3 | `hasSummaryTeaching` |
| `subSection.requireFlag` + `notApplicableMessage` | 5.3 | `importHasCoreQuestion` |
| `cs-5-0` + 章级 fallback | 五、课堂小结 | `hasSummaryTeaching` false → 章末文案 |

**Context：** `composables/a2-report-flags-context.ts`（`provideA2ReportFlags` / `mergeA2ReportFlags`）  
**探针：** `components/ReportA2FlagSwitch.vue`  
**不适用样式：** `ReportA2NotApplicableFallback`（subsection 16px / chapter 20px semibold）
