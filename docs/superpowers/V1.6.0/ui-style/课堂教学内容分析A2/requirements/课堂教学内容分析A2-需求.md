## 1. 原始需求（初版）

1. 独立 View / mapper / mock / 章节数据；Registry `A2 → ReportTypeA2View`；A1 零回归。
2. **目录与 A1 不同**：按权威 TOC 建树，禁止套用 A1 章节。
