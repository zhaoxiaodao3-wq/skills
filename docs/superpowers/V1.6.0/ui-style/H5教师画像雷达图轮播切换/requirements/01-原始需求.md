# H5 教师画像雷达图轮播切换 · 原始需求

## 需求来源

H5 端教师画像分享页（`teacher-profile`）的 A 类、B 类雷达图已经实现，但只有单雷达图（基于教案与上课 / 基于教参与上课），没有子类型（教案组 vs 教参组）切换能力。web 端（`teacher-portrait`）已实现 A1/A2、B1/B2 四种子类型轮播切换 + 子类型标签 + 圆点指示器 + 自动切换动画。本次需求是把同样的能力适配到 H5 端，**不改变 H5 端的主要竖排样式**。

## 原始需求文本

> Figma（明睿开发稿·团队版，节点 `8785-61536`）是 web 版本的两个雷达图，主要加了动画切换轮播和子类型标签，参考 [web 已实现页面](https://test.mirayai.com:31594/classroom-app/school/teacher-portrait/teacher-portrait) 这个页面。H5 项目（`E:/code/H5`）的教师画像分享页 `http://localhost:8989/teacher-profile?code=...` 已经有 A1 和 B1 的雷达图，现在加上切换：逻辑和样式交互都跟 web 版本对齐。由于 H5 是竖着排列的，不要改变 H5 的主要样式。三件事：
>
> 1. **新增轮播切换的效果和动画**
> 2. **加上子类型的标签**
> 3. **对接接口**：接口字段跟 web 一致（参考 web 即可）

## 范围

**做：**

- A 类、B 类雷达图各加子类型轮播（A1↔A2、B1↔B2）
- 子类型标签（type-tag）：位于雷达图标题左侧
- dots 圆点指示器：子类型 ≥2 时显示，可点击切换
- 自动切换：5s 间隔
- hover 暂停（PC）：鼠标进入雷达图区域暂停，离开恢复
- touch 切换：移动端滑动 / 点击 dots
- 切换动画：crossfade（淡入淡出 0.3-0.4s）+ dots 缩放（active 圆点变长 20px / 静止 10px / 颜色为对应类别色）
- 接口字段对接：`a2DimensionScore` / `b2DimensionScore` / `dimensionScoreBySubtype.A2` / `dimensionScoreBySubtype.B2`
- 类型定义新增：`ContentEvalSubtypeVm` / `ContentEvalSubtypeKey` 等

**不做：**

- 不改变 H5 端面板的竖排整体布局（A 在上、B 在下）
- 不改变 A/B 大类别的标题文案、颜色、卡片样式
- 不改 donut 图、legend、grade-card 区域
- 不改 score-trend 区域
- 不改分享链接 / 微信 JSSDK / OG meta 等非雷达图相关逻辑
- 不修改 H5 项目外的内容（web 端不动、Thymeleaf 后端模板不动）
- 不引入 GSAP（H5 用 CSS transition + Vue `<Transition>` 即可，更轻量）
- 不引入新依赖
