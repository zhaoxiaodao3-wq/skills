# 原始需求：课堂教学内容报告子类型拆分

**页面：** [课堂教学内容分析](https://test.mirayai.com:31594/classroom-app/analysis-web/ai-teaching-diagnosis/classroom-diagnosis/classroom-content-analysis?id=2089919762697629698&resourceType=AI%E8%87%AA%E4%B8%BB%E5%88%86%E6%9E%90)

## 背景

- 初版：`reportType` 只区分 A / B 两大类
- 第二版：曾把 A1/A2/B1/B2 塞进 `reportType`
- 现需：大类与子类型分离

## 需求（已确认）

1. **`reportType` 只有三类：`A` / `B` / `G`**
2. **新增 `reportSubType`**（`A1` / `A2` / `B1` / `B2`）
3. **后端暂未下发 `reportSubType`**：前端按可选字段接入；当前靠 mock / 缺省逻辑
4. **`reportSubType` 为空时默认：**
   - `reportType=A` → **A1**（即现 A 类页面）
   - `reportType=B` → **B1**（即现 B 类页面）
5. 其它内容不变；最小侵入；不得影响原功能

## 字段名

- `reportSubType`（camelCase；snake 入参经现有 camelize 可得）
