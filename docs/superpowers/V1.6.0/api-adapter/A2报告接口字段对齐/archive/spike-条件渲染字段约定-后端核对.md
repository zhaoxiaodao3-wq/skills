## 1. 3.4.2 实验/活动设计有效性

| 项 | 说明 |
|----|------|
| **字段** | `aReport.newKnowledgeTeaching.teachingMethod.activityDesign` |
| **类型** | 数组 |

**约定：**

| 后端返回 | 前端展示 |
|----------|----------|
| `null` 或 `[]` | 「【无实验/活动】」 |
| 有数据 | 按表格正常渲染 |

## 2. 3.6.2 问题链设计与追问分析（逻辑分析区）

| 项 | 说明 |
|----|------|
| **字段路径** | `aReport.newKnowledgeTeaching.teacherQuestioning.questionChainAnalysis.dimensions[]` |
| **判定行** | 仅看 **分析维度（`dimension`）= `问题链设计与追问质量`** 的那一行 |
| **判定字段** | 该行的 `evaluation`（评价） |

**约定：**

| `evaluation` 取值 | 「问题链设计逻辑分析」下方内容 |
|-------------------|--------------------------------|
| 含 **「有效」** 或 **「不足」** | 正常展示（基本情况 + 分节分析 + 整体评价等） |
| **「缺失」**，或找不到该维度行 | 不展示逻辑分析正文，改为：「不存在问题链，本模块不适用」 |

**说明：**

- 上方 `dimensions` 表格仍会展示，不受上述开关影响。
- 请保证存在一行 `dimension` 精确为：`问题链设计与追问质量`。

## 3. 5.0 前置判断 → 控制 5.1 / 5.2 / 5.3

| 项 | 说明 |
|----|------|
| **字段** | `aReport.classSummary.preJudgment` |
| **类型** | `string[]`，**按固定顺序只传值，不要带标题** |
| **标题** | 由前端固定拼出，后端不要返回「标题：」前缀 |

**数组顺序（固定）：**

| 下标 | 对应标题（前端展示） | 后端只传值示例 |
|------|----------------------|----------------|
| `[0]` | 是否存在总结性教学行为 | `是。` / `否。` |
| `[1]` | 小结类型 | `分散式。` |
| `[2]` | 小结功能完整性 | `部分。` |
| `[3]` | 判断依据 | `①39:38-39:55: ……` |

**约定：**

| 后端返回 | 前端行为 |
|----------|----------|
| 有数组，按上表顺序只填**值** | 5.0 展示「标题：值」四条；再根据 `[0]` 决定是否展示 5.1–5.3 |
| `[0]` 值为 **「否」**（或等价「无」，可带句号） | **隐藏 5.1 / 5.2 / 5.3**，并展示：「本节课无总结性教学行为」 |
| `null` 或 `[]` | **隐藏 5.1 / 5.2 / 5.3**，并展示：「本节课无总结性教学行为」 |

**示例（有总结）：**

```json
"preJudgment": [
  "是。",
  "分散式。",
  "部分。",
  "①39:38-39:55: 老师：所以这节课……"
]
```

**示例（无总结）：**

```json
"preJudgment": [
  "否。",
  "——",
  "——",
  "——"
]
```

或：

```json
"preJudgment": null
```

## 4. 5.3 回扣核心问题分析

| 项 | 说明 |
|----|------|
| **字段** | `aReport.classSummary.coreQuestionReturn` |
| **前提** | 仅当 5.0 判定「有总结性教学」（`preJudgment[0]` 不是「否」，且数组非空）时，5.3 才可能出现 |

**约定：**

| 后端返回 | 前端展示 |
|----------|----------|
| `null` 或 `[]` | 不展示表格，改为：「导入环节未提出核心问题，本模块不适用」 |
| 有数据 | 正常出表 |

## 后端自查清单

- [ ] `activityDesign`：无实验/活动时是否稳定返回 `null` 或 `[]`
- [ ] `dimensions[]` 是否始终包含 `dimension = "问题链设计与追问质量"` 这一行
- [ ] 该行 `evaluation` 取值是否仅为约定语义：**有效 / 不足 / 缺失**（或明确包含这些关键字）
- [ ] `preJudgment` 是否固定 4 项顺序且**仅传值不含标题**；无总结时 `[0]` 是否为「否」；无数据时是否为 `null`/`[]`
- [ ] 无回扣核心问题时，`coreQuestionReturn` 是否为 `null`/`[]`
