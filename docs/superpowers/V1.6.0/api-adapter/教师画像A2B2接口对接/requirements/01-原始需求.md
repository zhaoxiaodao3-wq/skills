# 教师画像 A2/B2 接口对接 · 原始需求

**模块：** `api-adapter/教师画像A2B2接口对接`  
**页面：** `/classroom-app/school/teacher-portrait/teacher-portrait`  
**接口文档：** `getTeacherProfile-A2B2前端接口对接文档.md`（企微缓存，2026-09）  
**P1 确认：** 2026-09-04 — 推荐方案：接真实 `a2DimensionScore` / `b2DimensionScore`，五维 key 与接口对齐为 `knowledgeMastery` 等

## 用户原话（摘要）

教师画像页面 A2B2 接口已提供，参考对接文档，帮我对接到评价维度得分。

## 目标

`GET /v2/teachingDiagnosis/getTeacherProfile` 的 `postClassReport` 新增 A2/B2 五维平均分后，前端「评价维度得分」雷达在关 Mock、走真实 HTTP 时能正确展示 A2/B2（与已有 A1/B1 轮播并存）。

## 范围

1. VO 增加可空 `aReport.a2DimensionScore`、`bReport.b2DimensionScore`
2. Adapter 优先读新字段；兼容旧假想 `dimensionScoreBySubtype`；仍缺且开关开启时才 mock 补齐
3. `CATEGORY_2_DIMENSION_DEFS` / mock / 单测与接口 key 对齐（知识落实度 → `knowledgeMastery`）
4. 本地 API fixture 补真实路径字段，便于对照

## 空态规则（P1 修订 · 选项 B · 2026-09-04）

接入真接口后：

1. **关闭**假分补齐：`FILL_MISSING_DIMENSION_SUBTYPE_2_MOCK = false`（不再注入 MOCK_A2/B2 假分数）
2. `a2DimensionScore` / `b2DimensionScore` **缺失、null、或不含任何有效分值**时：
   - **仍生成** A2 / B2 子类型项（标签可见，可轮播）
   - 五维分按空态处理（分值为 0 / 与面板空态雷达一致），**不**用假数据
3. 有真数字段时：展示真实分值
4. 整块「评价维度得分」空态：仍仅在整模块无有效数据时触发；**不**因缺 A2/B2 而清空已有 A1/B1

## 非目标 / 不破坏范围（P2 补充确认）

- 不改雷达 UI、轮播交互、等级环形图
- 不改驾驶舱旁路工程（除非另开需求）
- 不删除 A1/B1 旧字段 `dimensionScore` 兼容逻辑
- **不影响**其它 `getTeacherProfile` 顶层模块数据路径（教案/提问/清晰度/说话/标签/风格等）：本需求只扩展 `postClassReport` 维度子类型读取
- **不影响** A1/B1 六维与等级统计：仅新增可读字段，不重命名/删除既有 JSON 字段

## 验收意向

- Mock 关 + 接口返回 `a2DimensionScore`/`b2DimensionScore` 时，A/B 侧出现 A2/B2 标签与五维雷达分值正确
- 仅有 A1/B1、无 2 类字段时行为与现网一致（含 mock 补齐开关语义）
- A1/B1 六维不受影响
