# 教学小组默认排序与选中 · 原始需求

**版本：** v1.4.8  
**分类：** feature  
**关联组件：** `src/pages/school/teacher-portrait/components/teaching-group/`

## 背景

教师画像页「教学小组」组件（小组管理员视角）当前加载小组列表后：

- 不按人数排序
- 不自动选中任何小组/成员，右侧画像保持空态，需用户手动点击

## 需求描述

1. **未选择小组时先排序**：当当前没有选中小组时，对**当前页**小组列表按人数从多到少排序。
2. **相同人数随机**：人数相同的小组之间顺序随机。
3. **初始化选中（仅首次进入）**：排序完成后，若满足条件，自动选中排序后**第一小组里的第一个人**（驱动右侧教师画像）。**仅组件初始化第一次进入时触发**，之后翻页、返回、用户手动操作均不再自动选中。
4. **不进入成员列表视图**：初始化选中时**不切换**到成员列表视图（`members`），始终停留在小组列表视图；通过**高亮对应小组**让用户知道当前选中的是哪个小组的成员。
5. **全页无人时不选中**：若排序后第一组人数为 0，说明当前页最大人数为 0，即当前页所有小组均无成员——只展示小组列表，**不进行任何成员选中**。

## 补充约束（用户确认）

| 项 | 结论 |
|----|------|
| 是否进入成员列表 | 否，保持小组列表视图，高亮小组即可 |
| 第一组人数为 0 | 当前页全无人，只展示小组，不选中成员 |
| 翻页/返回是否自动选中 | 否，仅初始化第一次进入时自动选中 |
| 选中成员后翻页/切换小组是否取消选中 | 否，一旦用户选中了成员，翻页、切换小组均保留当前选中，直到用户主动选择新成员 |
| 选中高亮是否跨小组 | 否，成员高亮仅在其被选中的小组内生效，切换至其他小组后该成员不高亮（即使同一成员存在于多个小组） |

## 验收要点

- [ ] 无选中小组时，当前页小组按 `memberCount` 降序展示
- [ ] 相同人数的小组相对顺序随机
- [ ] 初始化首次进入：当前页有小组且第一组人数 > 0 时，自动选中第一组第一名成员，小组列表高亮该组，**不进入成员列表**
- [ ] 初始化首次进入：当前页第一组人数为 0 时，只展示小组列表，不选中成员
- [ ] 翻页、返回小组列表、debug 模式切换后，不再次自动选中
- [ ] 用户手动点击小组/成员后，按用户选择行为正常运作
- [ ] 选中成员后，切换小组不取消选中，仅更新左侧列表，右侧画像保持当前成员
- [ ] 选中成员后，翻页（小组翻页/成员翻页）不取消选中
- [ ] 无小组时空态不变
- [ ] 选中成员高亮仅在当前所属小组内生效，切换至其他小组后该成员不高亮（即使该成员同时存在于多个小组）
