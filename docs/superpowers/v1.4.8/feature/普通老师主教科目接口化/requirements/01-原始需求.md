# 普通老师主教科目接口化 · 原始需求

**版本：** V1.4.9
**分类：** feature
**关联组件：** `src/pages/school/teacher-portrait/`

## 需求描述

1. **科目获取路径变更**：当前身份是普通老师时，「我的信息」组件里的科目信息和教师画像卡里的主要科目，改为通过 `backstage/schoolUser/facultyList` 接口获取（传 `tenantUserIds` 和 `tenantId`）。
2. **文案变更**：教师画像卡中「主要科目」文案改为「主教科目」。

## 用户确认项

| 项 | 结论 |
|----|------|
| 科目字段 | 接口返回项的 `mainSubjectName`（与教学小组成员取法一致） |
| 接口失败 / 科目为空的兜底 | 不兜底，显示 `-`；whoami 本地字段不再参与，接口是唯一可信源 |
| 文案修改范围 | 全局生效（所有身份的教师画像卡统一显示「主教科目」） |

## 现状

- 普通老师身份下，`index.vue#initTeacherProfileForRole` 调 `resolveWhoamiProfile()` 从本地 whoami 缓存字段（`subject`/`subjectName`/`mainSubjectName`）取科目
- 「我的信息」（MyInfoContainer）与教师画像卡（TeacherPortraitCardContainer）共同消费页面级 `activeTeacherProfile`
- `service.quotaNew.facultyList` 已封装目标接口；教学小组 `mapFacultyMember` 已有 `mainSubjectName` 取数先例

## 验收要点

- [ ] 普通老师身份：科目来自 facultyList 接口的 `mainSubjectName`，「我的信息」与教师画像卡同步展示
- [ ] 接口失败或科目为空：两处均显示 `-`，无 whoami 回退
- [ ] 管理员 / 组管理员身份行为不变（科目仍来自列表项 / 小组成员）
- [ ] 教师画像卡文案显示「主教科目」
