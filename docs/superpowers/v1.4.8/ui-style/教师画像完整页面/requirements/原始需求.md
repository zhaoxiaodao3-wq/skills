# 教师画像完整页面开发需求文档

## 一、需求概述
本页面为教师画像聚合总页面，采用左右分栏布局结构，左侧为角色权限差异化组件区，根据当前登录用户的身份权限展示对应组件；右侧为通用数据展示区，聚合展示全部教师画像相关业务组件。页面整体复用已定义的各原子组件能力，遵循项目统一的工程化、组件化开发规范，保障权限控制准确、布局交互合理、组件可复用可扩展。

## 二、设计稿资源
所属项目：明餐开发稿 · 团队星版
页面整体布局参考设计稿：https://www.figma.com/design/vmbLwcwclGPoT3fWJWv7de/%E6%98%8E%E7%9D%BF%E5%BC%80%E5%8F%91%E7%A8%BF-%C2%B7%E5%9B%A2%E9%98%9F%E7%89%88?node-id=6696-12844&m=dev
所有子组件的视觉样式、交互细节、业务规则均遵循对应子组件的专项设计稿与需求规范。

## 三、页面整体布局架构
页面采用左右并排的分栏布局，整体宽度占满页面容器，分栏比例、间距、分割样式严格对齐设计稿。左右区域独立控制高度与滚动逻辑，互不影响。

### 1. 左侧区域：角色权限差异化组件区
- 区域定位：页面左侧功能栏，承载对应用户身份的列表、导航或信息组件。
- 高度规则：最大高度等于当前屏幕可视高度，不随内部内容撑开页面整体高度。
- 滚动规则：若内部组件内容超出视口高度，左侧区域内部独立滚动，不影响右侧区域与页面整体布局。

#### 权限匹配规则
按优先级从高到低进行角色身份判断，命中高优先级角色后不再向下匹配：
1.  用户身份为**校级管理员**或**管理员**：展示「教师列表组件」
2.  用户身份为**小组管理员**：展示「教学小组组件」
3.  用户身份为**普通教师**：展示「我的信息组件」

权限判断逻辑复用项目现有用户角色工具能力，遵循项目统一的权限校验规范。

### 2. 右侧区域：通用数据组件展示区
- 区域定位：页面右侧主内容区，聚合展示全部教师画像相关的业务数据组件。
- 高度规则：最大高度等于当前屏幕可视高度。
- 滚动规则：因组件数量较多，单屏无法完整展示全部内容，右侧区域支持上下滚动查看全部组件内容。

#### 组件排布顺序
右侧区域从上到下依次排布以下组件，各组件间距、排版严格对齐设计稿：
1.  教师画像组件
2.  我的教案组件
3.  课堂教学内容评价组件
4.  教学风格与弹性特征组件
5.  教学风格变化趋势组件
6.  课堂结构清晰度组件
7.  个人标签云组件
8.  提问类型组件
9.  课堂语言行为组件
10. 语言可理解度组件

所有子组件均复用已定义的组件能力，包括数据处理规则、图表规范、缺省逻辑、样式标准等，无需重复开发。

## 四、通用开发规范
1.  **组件复用原则**：页面内所有基础控件优先复用 Element Plus 组件库，业务模块复用已封装的子组件，避免重复开发，保证交互与样式统一。
2.  **样式隔离要求**：页面级样式与各组件样式严格执行作用域隔离，仅对当前范围生效，不得污染全局样式，不得影响项目内其他页面与组件。
3.  **图表规范**：页面内所有统计图表统一使用 ECharts 实现，遵循项目统一的图表开发规范。
4.  **响应式适配**：页面整体布局支持响应式适配，兼容项目覆盖的主流屏幕尺寸；不同视口下左右栏宽度、组件排版合理调整，无溢出、错位、遮挡、文字截断等视觉异常。
5.  **架构设计**：页面层仅负责布局组装、权限判断与数据分发，不侵入各子组件的内部业务逻辑；子组件保持独立可复用，严格遵循业务逻辑与视图分离的架构。
6.  **目录规范**：所有文件的目录划分、存放路径遵循项目现有前端工程规范与团队约定，本需求不做强制指定。

## 五、Mock数据方案
开发阶段先行使用Mock数据联调，不依赖真实后端接口：
1.  各子组件复用自身对应的Mock数据与测试场景，无需页面层重复定义。
2.  页面级补充角色权限Mock场景，覆盖校级管理员、管理员、小组管理员、普通教师四类身份的切换调试。

## 六、开发要求
1.  页面布局严格对齐Figma设计稿的分栏比例、尺寸、间距、样式细节，保证1:1还原效果；
2.  角色权限判断逻辑准确，优先级顺序正确，不同身份精准展示对应组件，无权限错配、漏判；
3.  左右区域的高度控制与滚动交互实现准确，滚动流畅无卡顿，滚动范围与样式符合设计稿规范；
4.  所有子组件无缝接入，各自的数据处理、缺省状态、图表交互等能力完整生效，无功能异常；
5.  样式严格执行隔离规范，避免全局样式污染与组件间样式冲突；
6.  完成多屏幕响应式适配验证，覆盖项目主流分辨率；
7.  整体架构遵循工程化、组件化规范，职责边界清晰，便于后续组件新增与页面迭代。
