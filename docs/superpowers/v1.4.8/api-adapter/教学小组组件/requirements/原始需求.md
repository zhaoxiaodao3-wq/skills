# 教学小组组件 — 接口适配需求文档

> **状态**：✅ 已对接完成（2026-07-06）
>
> **实现入口**：`src/pages/school/teacher-portrait/components/teaching-group/`

## 一、需求概述

本需求属于 **api-adapter** 阶段：在 **UI 已实现** 的前提下，将教师画像页左栏「教学小组」组件的数据源由 Mock 切换为真实后端接口。

- **UI 与交互**：以 [ui-style 教学小组组件需求](../../ui-style/教学小组组件/requirements/原始需求.md) 及已交付实现为准，**本阶段不改动视觉与交互**。
- **代码位置**：
  - 容器层：`TeachingGroupContainer.vue`（数据请求、状态机、分页、页面联动）
  - 展示层：`TeachingGroupView.vue`（纯展示，未改动）
  - 适配层：`teaching-group-api.ts`（接口调用、字段映射、前端分页 helper）
  - 类型：`types.ts`
- **适配目标**：
  - 小组列表走 **服务端分页**（`POST /quota/group/page`）
  - 点击小组后通过 **教职工接口**拉取含学科的成员详情（`POST /backstage/schoolUser/facultyList`）
  - 成员列表 **前端自行分页**（每页 10 条）
  - 选中成员后继续驱动页面 `activeTeacherId` 与右侧聚合数据联动

## 二、权限与可见性

1. 仅 **小组管理员**（`UserRole.GroupAdmin`）可见本组件；页面层 `teacher-portrait/index.vue` 已通过 `showTeachingGroup` 控制，适配层无需重复实现权限 UI。
2. 身份判定复用项目现有能力：`@/utils/user-role`（`resolveUserRole` / `getUserRoleFlags`）。
3. 接口请求身份上下文取自 `useUserSession().userInfo`（`/auth/user/myInfo`），实际使用字段：

| 字段 | 用途 |
|------|------|
| `tenantUserId` | 查询当前身份管理的小组（`/quota/group/page`） |
| `tenantId` | 查询教职工详情（`/backstage/schoolUser/facultyList`） |
| `schoolId`（来自 `useApplicationState().schoolInfo.id`） | 小组分页查询 |

## 三、接口方案

### 3.1 小组列表接口

| 项 | 说明 |
|----|------|
| 路径 | `POST /quota/group/page` |
| 项目封装 | `service.schoolNew.getQuotaGroupPage`（`src/service/schoolNew.ts`） |
| 用途 | 查询**当前身份作为小组管理员**所管理的小组分页列表 |
| 触发时机 | 组件挂载、切换小组页码、`debugDataMode` 切换 |

**请求参数：**

| 参数 | 来源 | 说明 |
|------|------|------|
| `page` | 组件内 `groupPage` | 从 1 开始 |
| `size` | 固定 `10` | `TEACHING_GROUP_PAGE_SIZE` |
| `schoolId` | `schoolInfo.id` | 当前学校 ID |
| `tenantUserId` | `userInfo.tenantUserId` | 当前登录单位用户 ID |

**响应结构：** `{ list: Record<string, any>[], total: number }`

### 3.2 成员详情接口（含学科）

| 项 | 说明 |
|----|------|
| 路径 | `POST /backstage/schoolUser/facultyList` |
| 项目封装 | `service.quotaNew.facultyList`（`src/service/quotaNew.ts`） |
| 用途 | 点击某一小组后，按该组成员 ID 批量查询教职工详情（含姓名、学科） |
| 触发时机 | 用户**首次**点击某一小组进入成员视图时调用一次；同组再次进入复用缓存 |

**请求参数：**

| 参数 | 来源 | 说明 |
|------|------|------|
| `tenantId` | `userInfo.tenantId` | 当前登录单位 ID |
| `tenantUserIds` | 小组分页接口返回的嵌套成员 ID 数组 | 当前点击小组的全部成员 `tenantUserId` 列表 |

> `/quota/group/page` 嵌套成员**不含学科信息**，仅用于提取成员 ID；展示用成员列表必须走 `facultyList`。

### 3.3 字段映射（已实现）

#### 小组列表项 → `TeachingGroupItem`

| 组件字段 | 接口字段 | 映射逻辑 |
|----------|----------|----------|
| `id` | `id` | `String(id).trim()`，空则丢弃 |
| `name` | `groupName` / `name` | 优先 `groupName` |
| `memberCount` | `memberCount` / `number` / 成员 ID 数 | 优先接口统计字段，缺失时用 `memberIds.length` |

#### 小组成员 ID 提取（嵌套在小组项内）

适配层 `extractMemberList` 按以下顺序取成员数组（取到即用）：

1. `memberList`（**联调主字段**，参考 `instanceTeacherDialog.vue`）
2. `members`
3. `initialMemberList`
4. `tenantUserList`
5. `groupMemberList`

单条成员 ID 提取优先级：`tenantUserId` → `userId` → `id` → `orgId`

#### 成员展示项 → `TeachingGroupMemberItem`（`facultyList` 响应）

| 组件字段 | 接口字段 | 说明 |
|----------|----------|------|
| `teacherId` | `tenantUserId` | 选中后作为 `activeTeacherId` 传给页面聚合接口 |
| `name` | `tenantUser.userName` | 成员姓名 |
| `subject` | `mainSubjectName` | 可为空，空值展示 `--` |

成员顺序：按 `tenantUserIds` 入参顺序排列（`orderMembersByIds`）；`facultyList` 未返回的 ID 不展示。

### 3.4 暂不使用的接口

适配本组件时 **不调用** `/quota/group/members`（`groupTenantUserList`）拉取成员；该接口仍供「小组权限分配」等其他业务使用。

## 四、分页与数据流

### 4.1 小组列表（服务端分页）

- 每页 **10 条**，切换页码时重新请求 `/quota/group/page`。
- 返回 `total === 0` 时进入 **小组空态**（`groups-empty`）。
- `total > 10` 显示分页器；≤ 10 显示「共 N 条」。

### 4.2 成员列表（facultyList 一次拉全 + 前端分页）

> **与小组列表的区别**：小组列表翻页走服务端；成员列表 `facultyList` 一次返回全量，翻页只在本地切片。

| 维度 | 小组列表 | 成员列表 |
|------|----------|----------|
| 数据来源 | `POST /quota/group/page` | `POST /backstage/schoolUser/facultyList` |
| 分页方式 | **服务端分页** | **前端分页**（`paginateTeachingGroupMembers`） |
| 翻页是否请求接口 | 是 | **否** |
| 每页条数 | 10（`TEACHING_GROUP_PAGE_SIZE`） | 10（同上） |
| 分页器显示条件 | `groupTotal > 10` | `memberTotal > 10` |

**点击小组后的流程：**

```
/quota/group/page（已加载）
  └─ 读取 memberIdsByGroupId[groupId]
       └─ tenantUserIds 为空 → members-empty
       └─ tenantUserIds 非空
            └─ membersByGroupId 无缓存 → facultyList（一次）
            └─ membersByGroupId 有缓存 → 复用
                 └─ paginateTeachingGroupMembers → 当前页 members
```

- 切换成员页码（`handleMemberPageChange`）：仅更新 `memberPage` + 本地切片 + `emit('selectMember', null)`。
- 返回小组列表：清空成员选中与成员页码。

### 4.3 与教师画像页联动

| 用户操作 | 组件行为 | 页面行为 |
|----------|----------|----------|
| 进入组件 / 切换小组页 | 请求小组分页 | — |
| 点击小组、未点成员 | 请求 `facultyList`（首次）并展示成员列表或成员空态 | `activeTeacherId = null`，不请求聚合数据 |
| 切换成员页 | 本地切片，不请求接口 | `activeTeacherId = null` |
| 点击某一成员 | 成员选中态 | `emit('selectMember', teacherId)`，触发聚合接口 |
| 返回小组列表 | 清空成员选中 | `emit('selectMember', null)` |

状态机与 [ui-style dev-spec](../../ui-style/教学小组组件/specs/原始需求-dev-spec.md) 保持一致。

## 五、展示与异常规则

1. **空值占位**：姓名、科目等展示字段无值时统一 `--`（`TeachingGroupView` 复用 `formatEmptyDisplay`）。
2. **加载态**：小组列表请求、首次进入成员视图时展示组件内 `v-loading`，不阻塞整页。
3. **接口失败**：
   - 小组列表失败 → 空列表 + `groups-empty`，不导致页面崩溃
   - 成员列表失败 → `members-empty`，清空该组缓存
4. **字段缺失**：映射层做兜底（多字段名兼容、空 ID 过滤），避免单字段缺失导致整表无法渲染。

**原始输入摘要：**

> 教学小组组件首先是身份为小组管理员能看到的；判断身份是小组管理员之后，通过 `/quota/group/page` 接口查询当前身份管理的小组分页列表，列表中需要包含小组名称、小组人数、以及小组具体成员列表；具体成员列表需要前端自行分页。
