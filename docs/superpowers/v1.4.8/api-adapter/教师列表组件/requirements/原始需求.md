# 教师列表组件 — 接口适配需求文档

> **状态**：✅ 已对接完成（2026-07-07）
>
> **实现入口**：`src/pages/school/teacher-portrait/components/teacher-list/`

## 一、需求概述

本需求属于 **api-adapter** 阶段：在 **UI 已实现** 的前提下，将教师画像页左栏「教师列表」组件的数据源由 Mock 切换为真实后端接口。

- **UI 与交互**：以 [ui-style 教师列表组件需求](../../ui-style/教师列表组件/requirements/原始需求.md) 及已交付实现为准，**本阶段不改动视觉与交互**。
- **代码位置**：`src/pages/school/teacher-portrait/components/teacher-list/`（`TeacherListContainer.vue` / `TeacherListView.vue`）。
- **适配目标**：教师列表走服务端分页与搜索；选中教师后继续驱动页面 `activeTeacherId` 与右侧聚合数据联动。

**原始输入摘要：**

> 本组件是校级管理员身份和管理员身份能进行查看；通过 `backstage/schoolGroup/schoolUserPage` 查询分页列表即可。

## 二、权限与可见性

1. 仅 **校级管理员**（`UserRole.SchoolAdmin`）与 **管理员**（`UserRole.Admin`）可见本组件；页面层 `teacher-portrait/index.vue` 已通过 `showTeacherList` 控制，适配层无需重复实现权限 UI。
2. 身份判定复用项目现有能力：`@/utils/user-role`（`resolveUserRole` / `getUserRoleFlags`）。
3. 接口请求身份上下文取自 `useUserSession().userInfo`（`/auth/user/myInfo`），至少使用：
   - `tenantId`：当前登录单位 ID（与项目内部门用户查询模块保持一致）；
   - 其他扩展参数见下文接口方案。

## 三、接口方案

### 3.1 主接口

| 项 | 说明 |
|----|------|
| 路径 | `POST /backstage/schoolGroup/schoolUserPage` |
| 项目封装 | `service.schoolNew.querySchoolUserPage`（`src/service/schoolNew.ts`） |
| 用途 | 分页查询学校教职工列表，供左栏教师列表展示与搜索 |

> 本组件 **不使用** `/quota/quotaOrg/schoolUserPage`（`querySchoolUserPageByGroup`），后者按小组维度查询，供成员选择弹窗等场景使用。

### 3.2 请求参数（已确认）

与 `SelectTenantUserDialog.vue` 等现有页面保持一致，**不额外传** `facultyType`、`identityId`、`groupId` 等筛选参数：

| 参数 | 来源 | 说明 |
|------|------|------|
| `page` | 组件内 `page` | 从 1 开始 |
| `size` | 固定 `10` | `TEACHER_LIST_PAGE_SIZE` |
| `tenantId` | `userInfo.tenantId` | 当前登录单位 ID |
| `userName` | 搜索框关键词（可选） | 有内容时传入；空关键词 / 重置时不传 |

### 3.3 响应与字段映射（已确认）

接口返回结构：`{ list: Record<string, any>[], total: number }`。

**列表项 → `TeacherListItem`**（对齐 `SelectTenantUserDialog` 表格列）：

| 组件字段 | 接口字段 | UI 展示 | 说明 |
|----------|----------|---------|------|
| `id` | `id` | — | 选中后作为 `activeTeacherId` |
| `name` | `userName` | 姓名 | 空值 `--` |
| `subject` | `mainSubjectName` | 科目 | 空值 `--` |
| `grade` | — | 未展示 | 类型保留，本阶段不映射 |

### 3.4 与 Mock 行为的对应关系

| Mock 行为 | 真实接口行为 |
|-----------|--------------|
| `fetchTeacherListMock({ page, pageSize, keyword })` | `querySchoolUserPage({ page, size, userName?, tenantId })` |
| 前端 Mock 内按姓名 `includes` 过滤 | **服务端搜索**（关键词通过请求参数传递） |
| `debugDataMode === 'empty'` 返回空列表 | 同教学小组，`isTeacherPortraitDebugEmpty()` 短路，不发起请求 |

## 四、分页、搜索与数据流

### 4.1 列表（服务端分页 + 服务端搜索）

- 每页 **10 条**，切换页码或触发搜索/重置时重新请求 `/backstage/schoolGroup/schoolUserPage`。
- 返回 `total === 0` 时进入 **查无此人空态**（与 ui-style 一致）。
- `total > 10` 显示分页器；≤ 10 显示「共 N 条」。

### 4.2 搜索与重置

| 用户操作 | 组件行为 | 接口请求 |
|----------|----------|----------|
| 点击查询 / 搜索图标 / 回车 | `appliedKeyword = trim(keyword)`，`page = 1`，`loadList()` | 有关键词带 `userName`；无关键词不带 |
| 空关键词查询 | 同重置为全量第一页 | 不带 `userName` |
| 点击重置 | 清空搜索、`page = 1`、`loadList({ selectFirst: true })` | 不带 `userName` |
| 切换页码 | `page` 更新，`loadList()` | 保留当前 `appliedKeyword` |

### 4.3 与教师画像页联动

| 用户操作 | 组件行为 | 页面行为 |
|----------|----------|----------|
| 进入组件 / 搜索 / 重置 / 翻页 | 请求教师分页列表 | — |
| 列表有数据且未选中教师 | 默认选中第一条 | `emit('select', firstTeacherId)`，触发聚合接口 |
| 重置 | 选中第一条 | 同上 |
| 点击某一教师 | 选中态 | `emit('select', teacherId)` |
| 列表为空 | 空态 | `emit('listEmpty')`，`activeTeacherId = null`，不请求聚合 |

状态机与 [ui-style dev-spec](../../ui-style/教师列表组件/specs/原始需求-dev-spec.md) 保持一致。

## 五、展示与异常规则

1. **空值占位**：姓名、科目无值时统一 `--`（`TeacherListView` 复用 `formatEmptyDisplay`）。
2. **加载态**：列表请求期间展示组件内 `v-loading`，不阻塞整页。
3. **接口失败**：展示空列表或错误提示（与项目 request 层一致），不导致页面崩溃。
4. **字段缺失**：映射层做兜底，避免因单字段缺失导致整表无法渲染。

  - 搜索、分页、重置走真实接口；
  - 保留 `debugDataMode` 联动与默认选中首条逻辑。

### 6.2 明确不改

- `TeacherListView.vue` 模板与样式（除非映射后字段导致必须微调，应优先在 Container / api 层消化）。
- 教师画像页布局、权限分支、右侧聚合请求逻辑。
- Figma 视觉规格与空态交互定义。

### 6.3 Mock 策略

- 保留 `mock/teacher-list.mock.ts` 供本地/UI 调试；
- 真实接口联调通过后，Container 默认走真实接口；
- `debugDataMode === 'empty'` 时返回空列表，与教师画像页 `RoleDebugBar` 策略对齐。
