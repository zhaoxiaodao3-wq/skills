## 一、变更摘要（两条独立链路）

> **用户澄清**：`teachingStyleElasticity` 是**已有弹性模块的字段替换**；`personalFeature` 是**补全教师画像卡片**在 04 之后仍缺失的主导/辅助风格与个人特征标签。二者职责不同，不应混为一谈。

### 1.1 链路 A — `teachingStyleElasticity` 字段替换（r2）

**作用范围**：仅「教学风格与弹性特征」模块（`TeachingStyleFlexibilityContainer`）

| 操作 | 字段 | 前端影响 |
|------|------|----------|
| **移除** | `sciLevel` | 删除 HTTP 标题 `课中教学稳定性：{sciLevel}` |
| **移除** | `elasticitySummary` | 删除 HTTP 底部描述 |
| **新增** | `stability` | 标题 + 背景色 |
| **新增** | `stabilityDescription` | 底部固定话术 |

**不变**：雷达图、情境列表、`styleCounts`、`situationStats` 等 03 已对接逻辑。

### 1.2 链路 B — `personalFeature` 补全画像卡片（r3）

**作用范围**：仅「教师画像卡片」风格区（`TeacherPortraitCardContainer`）

04 已对接：姓名 / 性别 / 科目 / 上课时长（Context + `teachingStatistics`）  
04 **刻意留空**：主导风格、辅助风格、画像图、个人特征标签（`merge` 时 `teacherPortrait: null`）

`personalFeature` 专门填补这块缺口：

| 接口字段 | 卡片展示 |
|----------|----------|
| `dominantStyle` | 主导风格文案 + 画像 URL 计算 |
| `auxiliaryStyle` | 辅助风格文案 + 画像 URL 计算 |
| `speechFeature` | 特征标签 1 |
| `emotionFeature` | 特征标签 2 |
| `powerFeature` | 特征标签 3 |
| `subjectFeature` | 特征标签 4 |

> 后端已从 `personalTagCloud` + `teachingStyleTrend` 聚合产出，**前端卡片只读 `personalFeature`**，不从标签云/趋势模块二次拼装。

### 1.3 不受影响

- `personalTagCloud`、`teachingStyleTrend` 各自模块展示（03 已对接）
- 我的信息 / 基本信息 / 教学统计（04 已对接）
- Mock ON 全页 mock 行为

## 二、目标

### 链路 A（字段替换）

1. 弹性模块 HTTP 分支改用 `stability` + `stabilityDescription`
2. 移除对 `sciLevel` / `elasticitySummary` 的类型、Adapter、Container 依赖
3. 更新 mock fixture 与单测

### 链路 B（画像补全）

1. 新增 `PersonalFeatureVO` + `adaptPersonalFeature` → **部分** `TeacherPortraitSlice`（仅风格/标签字段）
2. HTTP 路径 `merge` 注入 `teacherPortrait`，不再恒为 `null`
3. 卡片 Container：Mock OFF 用 adapter 产出补全主导/辅助/标签；基本信息仍走 04 Context，**不重复对接**
4. Mock ON 仍用 `FULL_MOCK_BASE.teacherPortrait`

---

## 三、数据流（澄清后）

```
getTeacherProfile
  ├─ teachingStyleElasticity ──→ adaptTeachingStyleElasticity ──→ 弹性特征模块（链路 A）
  └─ personalFeature         ──→ adaptPersonalFeature         ──→ teacherPortrait slice（链路 B）
                                                                        ↓
                                                              TeacherPortraitCardContainer
                                                              + Context 姓名/性别/科目
                                                              + teachingStatistics 时长
```

**链路 A 与 B 无交叉**：弹性模块不读 `personalFeature`；卡片不读 `teachingStyleElasticity`。

## 四、已确认产品决策（待 P1 用户确认）

| 议题 | 建议 |
|------|------|
| 交付方式 | 两条链路一次交付（A 修破坏性变更 + B 补卡片缺口） |
| 弹性 HTTP 标题 | `课中教学稳定性：{stability}` |
| 弹性 HTTP 描述 | 直出 `stabilityDescription` |
| 卡片 featureTags | `[speechFeature, emotionFeature, powerFeature, subjectFeature]` 过滤空值 |
| 卡片空态 | 仍要求 `dominantStyle` + `auxiliaryStyle` 均有值；标签可部分缺失 |
| Mock 双轨 | ON → 全 mock；OFF → HTTP，缺失不回退 mock |
