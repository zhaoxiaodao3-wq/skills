# V1.4.8 教师画像 — 教师风格分析模块字段变更记录

> 版本：V1.4.8-r2 | 日期：2026-07-13 | 作者：liangfeng
>
> 所属接口：`GET /v2/teachingDiagnosis/getTeacherProfile?tenantUserId=xxx`
>
> 响应类：`TeacherProfileRspVO` → `TeachingStyleElasticityVO`

---

## 一、移除字段

### 1.1 `teachingStyleElasticity.sciLevel`

| 属性 | 值 |
|------|-----|
| 字段路径 | `teachingStyleElasticity.sciLevel` |
| 类型 | `String` |
| 原值示例 | `"高弹性"` / `"中等弹性"` / `"低弹性"` |
| 移除原因 | 产品文档未定义 SCI 综合等级的跨报告聚合映射，该字段为自行设计，不在原型图需求中 |
| 前端适配 | **删除**该字段的展示逻辑 |

### 1.2 `teachingStyleElasticity.elasticitySummary`

| 属性 | 值 |
|------|-----|
| 字段路径 | `teachingStyleElasticity.elasticitySummary` |
| 类型 | `String` |
| 原值示例 | `"教师能根据教学情境灵活切换风格..."` |
| 移除原因 | 产品文档无此字段，原取自单份报告 AI 生成的总结语，不属于画像聚合层输出 |
| 前端适配 | **删除**该字段的展示逻辑 |

## 二、新增字段

### 2.1 `teachingStyleElasticity.stability`

| 属性 | 值 |
|------|-----|
| 字段路径 | `teachingStyleElasticity.stability` |
| 类型 | `String` |
| 可选值 | `"高稳定性"` / `"中等稳定性"` / `"低稳定性"` |
| 产品对应 | 产品文档《教师画像课中风格弹性特征计算规则》第三步 |

**判定规则**：统计 5 个情境中 "中" 等级的个数（`mediumCount` 合计）：

| "中" 的数量 | stability |
|:---------:|-----------|
| 0 个 | `"高稳定性"` |
| 1 个 | `"中等稳定性"` |
| ≥ 2 个 | `"低稳定性"` |

### 2.2 `teachingStyleElasticity.stabilityDescription`

| 属性 | 值 |
|------|-----|
| 字段路径 | `teachingStyleElasticity.stabilityDescription` |
| 类型 | `String` |
| 格式 | ≤30 字，通俗易懂的固定话术 |
| 产品对应 | 产品文档《教师画像课中风格弹性特征计算规则》- 弹性稳定性固定总结话术 |

**取值为以下固定话术之一**：

| stability | stabilityDescription |
|-----------|---------------------|
| `"高稳定性"` | 每次上课表现高度一致，优势短板都很固定，风格稳定可预测。 |
| `"中等稳定性"` | 整体表现稳定，但有一个情境时好时坏，不太稳定。 |
| `"低稳定性"` | 多个情境表现飘忽不定，还没形成稳定的教学风格。 |
