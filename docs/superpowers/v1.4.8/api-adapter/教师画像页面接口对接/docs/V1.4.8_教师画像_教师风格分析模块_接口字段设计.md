## 一、字段结构总览

在 `TeacherProfileRspVO` 顶层新增 3 个字段：

```java
// 教师画像 VO（3个新增模块）
@Schema(description = "个人标签云（课堂展示）")
private PersonalTagCloudVO personalTagCloud;

@Schema(description = "教学风格变化趋势")
private TeachingStyleTrendVO teachingStyleTrend;

@Schema(description = "教学风格与弹性特征")
private TeachingStyleElasticityVO teachingStyleElasticity;
```

### 2.3 字段定义

#### `PersonalTagCloudVO` 顶层

| 字段 | 类型 | 说明 |
|------|------|------|
| `totalReportCount` | Integer | 分析报告总数 |
| `tagCategories` | List\<TagCategoryVO\> | 标签分类列表（原型图固定可见4类，可滑动查看更多） |

#### `TagCategoryVO` 标签分类

| 字段 | 类型 | 说明 |
|------|------|------|
| `categoryName` | String | 分类名："话语特色"/"情感风格"/"权力关系"/"学科适配(数学)" |
| `categoryType` | String | 分类类型：speech/emotion/power/subject |
| `tags` | List\<TagItemVO\> | 该分类下的标签列表 |

#### `TagItemVO` 标签项

| 字段 | 类型 | 说明 |
|------|------|------|
| `tagValue` | String | 标签值，如 "提问达人" |
| `count` | Integer | 出现次数 |
| `rank` | Integer | 在该分类内的排序（1=最多） |

## 三、模块二：教学风格变化趋势 `TeachingStyleTrendVO`



### 

|      |      |
|------|------|
|      |      |
|      |      |
|      |      |
|      |      |

### 3.3 字段定义

#### `TeachingStyleTrendVO` 顶层

| 字段 | 类型 | 说明 |
|------|------|------|
| `dominantStyle` | String | 画像主导风格（出现最多的风格） |
| `auxiliaryStyle` | String | 画像辅助风格（出现次多的风格） |
| `styleCounts` | List\<StyleCountItemVO\> | 五种风格的出现次数统计 |
| `trendPoints` | List\<TrendPointVO\> | 双曲线图数据点，按报告时间升序 |

#### `StyleCountItemVO` 风格数量统计

| 字段 | 类型 | 说明 |
|------|------|------|
| `styleName` | String | 风格名："温暖引导型"/"理性启发型"/"权威传授型"/"激情讲授型"/"严厉规训型" |
| `count` | Integer | 出现次数（主导+辅助合计） |
| `dominateCount` | Integer | 作为主导风格出现次数 |
| `auxiliaryCount` | Integer | 作为辅助风格出现次数 |

#### `TrendPointVO` 曲线数据点（每份报告一个点）

| 字段 | 类型 | 说明 |
|------|------|------|
| `reportLabel` | String | 报告编号："A1", "A2", ..., "B1", ... |
| `reportTime` | Long | 报告生成时间（毫秒时间戳） |
| `reportTopic` | String | 课题（AI 提取），如 "复数" |
| `dominantStyle` | String | 该报告的主导风格 |
| `auxiliaryStyle` | String | 该报告的辅助风格 |
| `stylePosition` | Integer | 主导风格在纵轴上的位置（0-4） |

> **纵轴位置映射**：
>
> | 风格 | position |
> |------|----------|
> | 温暖引导型 | 0 |
> | 理性启发型 | 1 |
> | 权威传授型 | 2 |
> | 激情讲授型 | 3 |
> | 严厉规训型 | 4 |

### 3.4 JSON 示例

###

|------|------|
|      |      |
|      |      |
|      |      |
|      |      |
|      |      |

### 4.3 字段定义

#### `TeachingStyleElasticityVO` 顶层

| 字段 | 类型 | 说明 |
|------|------|------|
| `dominantStyle` | String | 画像主导风格 |
| `auxiliaryStyle` | String | 画像辅助风格 |
| `sciAverage` | Integer | SCI 平均值（0-100，步长 20） |
| `sciLevel` | String | SCI 等级："高弹性"/"中等弹性"/"低弹性" |
| `styleCounts` | List\<StyleCountItemVO\> | 五种风格的出现次数统计（主导+辅助合计） |
| `situationStats` | List\<SituationStatVO\> | 五情境弹性分布 |
| `elasticitySummary` | String | 弹性特征总结语 |

> `StyleCountItemVO` 与模块二共用，定义见 3.3 节。

#### `SituationStatVO` 情境弹性分布

| 字段 | 类型 | 说明 |
|------|------|------|
| `situationName` | String | 情境名："导入新知时"/"讲授核心概念时"/"学生回答错误时"/"课堂气氛低落时"/"总结拓展时" |
| `strongCount` | Integer | "强"等级出现次数 |
| `mediumCount` | Integer | "中"等级出现次数 |
| `weakCount` | Integer | "弱"等级出现次数 |
| `dominantLevel` | String | 该情境的主要弹性等级（出现最多的等级）："强"/"中"/"弱" |
| `summary` | String | 概括（根据 dominantLevel 查表）："引人入胜"/"偶有亮点"/"有待提高" 等 |
| `description` | String | 固定话术（≤30字，根据 dominantLevel 查表）："每节课开头都很有吸引力..." |

>

|-----------|-------|------|
