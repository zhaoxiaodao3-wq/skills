### 3.3 字段定义

#### `TeachingStyleTrendVO` 顶层

| 字段 | 类型 | 说明 |

| `auxiliaryCount` | Integer | 作为辅助风格出现次数 |

| 字段 | 类型 | 说明 |
|------|------|------|
| `reportLabel` | String | 报告编号："A1", "A2", ..., "B1", ... |
| `reportTime` | Long | 报告生成时间（毫秒时间戳） |
| `reportTopic` | String | 课题（AI 提取），如 "复数" |

| `auxiliaryStyle` | String | 该报告的辅助风格 |
| `stylePosition` | Integer | 主导风格在纵轴上的位置（0-4） |

> **纵轴位置映射**：
>
> | 风格 | position |
> |------|----------|
> | 温暖引导型 | 0 |
> | 理性启发型 | 1 |

> | 激情讲授型 | 3 |

## 四、模块三：教学风格与弹性特征 `TeachingStyleElasticityVO`

### 

### 4.3 字段定义

#### `TeachingStyleElasticityVO` 顶层

| 字段 | 类型 | 说明 |
|------|------|------|
| `dominantStyle` | String | 画像主导风格 |
| `auxiliaryStyle` | String | 画像辅助风格 |
| `sciAverage` | Integer | SCI 平均值（0-100，步长 20） |
| `styleCounts` | List\<StyleCountItemVO\> | 五种风格的出现次数统计（主导+辅助合计） |
| `situationStats` | List\<SituationStatVO\> | 五情境弹性分布 |
| `stability` | String | 弹性稳定性："高稳定性"/"中等稳定性"/"低稳定性" |
| `stabilityDescription` | String | 稳定性固定话术（≤30字） |

> `StyleCountItemVO` 与模块二共用，定义见 3.3 节。

## 五、模块四：个人特征 `PersonalFeatureVO`

### 5.1 数据来源

从其他三个模块的计算结果中取排名第一的特征值。

| 特征 | 来源 |
|------|------|
| 话语特色 | `personalTagCloud` → 话语特色分类 → 排第一的标签 |
| 情感风格 | `personalTagCloud` → 情感风格分类 → 排第一的标签 |
| 权力关系 | `personalTagCloud` → 权力关系分类 → 排第一的标签 |
| 学科适配 | `personalTagCloud` → 学科适配分类 → 取排名第一；多学科时优先与主科目（`user-service`）相同的学科，否则取数量最多的 |
| 主导风格 | `teachingStyleTrend.dominantStyle` |
| 辅助风格 | `teachingStyleTrend.auxiliaryStyle` |

### 5.2 字段定义

#### `PersonalFeatureVO` 顶层

| 字段 | 类型 | 说明 |
|------|------|------|
| `speechFeature` | String | 话语特色标签，取话语特色分类中排第一的标签值，如 "提问达人" |
| `emotionFeature` | String | 情感风格标签，取情感风格分类中排第一的标签值，如 "高亲和力型" |
| `powerFeature` | String | 权力关系标签，取权力关系分类中排第一的标签值，如 "平等协作型" |
| `subjectFeature` | String | 学科适配标签，取学科适配分类中排第一的标签值，如 "高度适配" |
| `dominantStyle` | String | 主导风格 |
| `auxiliaryStyle` | String | 辅助风格 |

### 5.3 JSON 示例

```json
{
  "personalFeature": {
    "speechFeature": "提问达人",
    "emotionFeature": "高亲和力型",
    "powerFeature": "平等协作型",
    "subjectFeature": "高度适配",
    "dominantStyle": "温暖引导型",
    "auxiliaryStyle": "权威传授型"
  }
}
```

## 七、变更记录

### V1.4.8-r3（2026-07-13）

#### 新增模块

| 模块 | VO 类 | 说明 |
|------|-------|------|
| `personalFeature` | `PersonalFeatureVO` | 个人特征摘要，从其他三个模块取排名第一的特征值汇总 |

**6 个字段**：`speechFeature`（话语特色 TOP1）、`emotionFeature`（情感风格 TOP1）、`powerFeature`（权力关系 TOP1）、`subjectFeature`（学科适配 TOP1）、`dominantStyle`、`auxiliaryStyle`。

> 无额外 DB 查询，全部从已计算的 `personalTagCloud` + `teachingStyleTrend` 中取值。

### V1.4.8-r2（2026-07-13）

#### 移除字段

| 模块 | 字段 | 原因 |
|------|------|------|
| `TeachingStyleElasticityVO` | `sciLevel` | 产品文档未定义 SCI 综合等级的跨报告聚合映射，不在原型图需求中 |
| `TeachingStyleElasticityVO` | `elasticitySummary` | 产品文档无此字段，原取自单份报告 AI 生成总结语，不属于画像聚合层输出 |

#### 新增字段

| 模块 | 字段 | 类型 | 说明 |
|------|------|------|------|
| `TeachingStyleElasticityVO` | `stability` | String | 弹性稳定性："高稳定性"/"中等稳定性"/"低稳定性" |
| `TeachingStyleElasticityVO` | `stabilityDescription` | String | 稳定性固定话术（≤30字） |

**稳定性判定规则**：统计 5 个情境中"中"等级的个数（`mediumCount`），0 个→高稳定性，1 个→中等稳定性，≥2 个→低稳定性。

| 稳定性 | 固定话术 |
|--------|---------|
| 高稳定性 | 每次上课表现高度一致，优势短板都很固定，风格稳定可预测。 |
| 中等稳定性 | 整体表现稳定，但有一个情境时好时坏，不太稳定。 |
| 低稳定性 | 多个情境表现飘忽不定，还没形成稳定的教学风格。 |

#### Bug 修复

| 问题 | 修复 |
|------|------|
| 话语特色标签输出超过 3 个 | `limit(Math.max())` → `limit(maxTags)`，按优先级截断前 3 个 |
| fastjson v1 类型标记导致 `getJSONArray` 解析异常 | 新增 `getArraySafe()` 自动剥离标记 |
| `catch (NumberFormatException)` 无法兜底 fastjson 异常 | 改为 `catch (Exception)`，异常日志级别升为 `ERROR` |
