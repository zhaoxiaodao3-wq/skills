# 教师画像高清渐进加载 — 原始需求

标清 OSS 图片在 300×300 展示区域不够清晰。用户提供高清版 PNG，要求：

1. 默认仍用现有标清 OSS 路径
2. 高清版上传 OSS `hd/` 子目录，文件名与标清一致
3. 页面后台预加载高清，成功则替换；失败则保持标清
4. 本地高清源文件按 `01-教师风格画像OSS命名对照.md` 重命名
