# B类5.5综合判定字段收敛

## 需求描述

审查 B 类报告 5.5「综合判定」为何多出内容。产品要求：**只展示** `comprehensiveJudgment` 数组；其他字段不要塞进该卡片。

## 现象 / 根因（审查）

`buildObjectiveCalcItems` 把同对象下多个字段拼进了标题为「综合判定」的列表：

- `totalObjectives` → 「预设教学目标总数：…」
- `achievedCount` → 「达成目标数（高/中程度）：…」
- `notAchievedCount` → 「未达成目标数：…」
- `reasonAnalysis`
- `comprehensiveJudgment`（真正需要的）

另：同节还会用 `sectionSummary` 追加「大节总结说明」卡片（与「综合判定」并列，字段不同）。

## 来源

用户 `/harness`：只需要 comprehensiveJudgment 数组，其他内容不需要。
