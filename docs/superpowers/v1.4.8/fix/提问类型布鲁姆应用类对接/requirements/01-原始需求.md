# 教师画像 · 提问类型布鲁姆「应用类」字段对接修复

## 一、问题

教师画像页「提问类型」组件中，布鲁姆分类图表的**应用类**数量未正确对接接口字段，界面常显示为 0（或与真实 `applicationCount` 不一致）。

## 二、根因（已定位）

`adapters/question-type.adapter.ts` 中布鲁姆映射标签写成了 **`应用类为`**，而 UI 常量 `BLOOM_GROUP.chartItems` 使用的是 **`应用类`**。  
adapter 用 label 作 `counts` 的 key，图表按 `应用类` 取值 → 取不到数据，回落为 0。

接口字段本身正确：`bloomTaxonomy.applicationCount`（见 TeacherProfileRspVO）。

## 三、修复要求

1. 将 adapter 中应用类 label 改为与 `BLOOM_GROUP` 一致的 **`应用类`**
2. 同步修正单测期望
3. 不改图表 UI、不改其它分类字段映射（除非同类 typo）

## 四、验收

- [ ] 有 `applicationCount` 时，布鲁姆饼图与图例「应用类」显示正确数量
- [ ] `adaptQuestionType` 单测：`bloom.counts['应用类']` 等于接口值
- [ ] 记忆/理解、分析/评价/创造类行为不变
