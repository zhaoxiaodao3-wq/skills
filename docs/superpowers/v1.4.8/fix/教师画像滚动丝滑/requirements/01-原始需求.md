# 教师画像滚动丝滑

## 需求描述

个人标签云滚动卡顿，需要丝滑；整页（右侧 main）滚动一并检查并做到丝滑。

## 初步根因

上一期「滚轮穿透」在无溢出时用 `wheel` + `scrollTop += deltaY` 手动转发，**打断浏览器原生惯性滚动**，手感发涩/卡顿。有溢出时自身 `overflow:auto` 虽可原生滚，但与整页体验不一致时需统一策略。

## 期望

- 标签云有/无溢出时滚轮均尽量走**原生滚动**（保留穿透逻辑）
- 页面 main 滚动同样基于原生，避免 JS 逐帧改 scrollTop

## 来源

用户 `/harness`：标签云滚动卡顿要丝滑，页面滚动也要检查。
