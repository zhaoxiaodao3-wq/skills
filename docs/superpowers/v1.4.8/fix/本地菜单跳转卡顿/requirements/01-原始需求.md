# 本地菜单跳转卡顿

## 背景

本地开发（`pnpm dev` / `pnpm dev:test`）时，点击侧边栏菜单偶发以下问题：

1. **卡顿很久**才完成路由跳转
2. **页面像被刷新了一样**，但目标页面没有打开
3. 需要**多点几次**菜单才能成功跳转

## 期望

- 点击菜单后应稳定、及时跳转到目标路由
- 不应出现整页刷新打断 SPA 导航的情况
- 本地开发与测试/生产环境行为一致（在合理范围内）

## 范围

- 重点排查：菜单导航逻辑、开发态 Token 同步触发的整页刷新、路由竞态
- 不涉及恢复已撤回的本地 nginx 反代方案

## 关联代码（初步）

- `src/components/AppLayout/components/AppMenu.vue`
- `src/composables/useRouteMenu.ts`
- `src/App.vue`（`checkAndReloadOnTokenChange` / `router.go(0)`）
- `src/composables/useApplicationState.ts`（`applicationMenu` 异步加载）
