# 首次访问路由触发整页刷新

## 背景

在上一轮修复（Token 快路径 + AppMenu 竞态）之后，本地开发仍有问题：

- **刚启动** dev server 后
- **每次点击从未打开过的菜单/路由**，都会触发**整页刷新**（浏览器重新加载，非 SPA 软跳转）
- 已打开过的路由再次点击则正常

## 期望

- 首次访问新路由时应为 SPA 懒加载跳转，不应整页刷新
- 可接受 dev server 启动时多预扫描一点时间

## 复现条件（用户描述）

- `pnpm dev` / `pnpm dev:test` 本地开发
- 刚启动后逐个点击不同侧边栏菜单
- 每个「第一次打开」的路由都会刷新一次

## 初步分析方向

1. `vite-plugin-pages` 使用 `importMode: "async"`，首次访问懒加载 chunk 时 Vite 发现新依赖 → 触发 optimizeDeps 重优化 → **full reload**
2. `optimizeDeps.entries` 默认只扫描 `index.html`，未覆盖 `src/pages/**` 中的依赖

## 范围

- 仅 DEV 构建配置优化，不改生产构建行为
- 不恢复本地 nginx 反代
