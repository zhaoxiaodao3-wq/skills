# 课堂教学内容评价雷达图统一

## 问题

`buildEmptyViewModel()` 中空状态雷达图维度使用了一套硬编码值，与有数据时的维度名称、maxScore 不一致：

1. **A 类空状态维度错乱**：
   - 「教案落实度」maxScore 为 25（正确值 20）
   - 「节奏合理度」出现两次（位置 1 和 5），缺少「练习有效度」
   - 维度顺序与有数据时不一致

2. **B 类空状态维度完全错误**：直接复用了 A 类的 hardcode 值，未区分 A/B 类。B 类应为：知识落实度、思维启发度、学生参与度、逻辑清晰度、练习与反馈有效性、节奏把控度

3. B 类雷达图第 5 维标题应为「练习与反馈有效性」

## 改动范围

`ClassroomContentEvalContainer.vue` — `buildEmptyViewModel()` 函数

## 验收标准

- [ ] 空状态下 A 类雷达图维度和 maxScore 与有数据时一致
- [ ] 空状态下 B 类雷达图维度和 maxScore 与有数据时一致
- [ ] B 类雷达图显示「练习与反馈有效性」
- [ ] 有数据时行为不变
