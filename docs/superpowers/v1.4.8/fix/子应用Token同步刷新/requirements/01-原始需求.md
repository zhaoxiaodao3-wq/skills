# 子应用 Token 同步刷新

## 背景

本应用作为子应用运行，登录发生在主应用（工作台）。Token 由主应用写入 localStorage / Cookie，子应用启动时从 `AUTH_INFO`（localStorage）读取。

## 问题

在主应用切换账号后回到子应用，子应用仍使用旧的 localStorage Token，接口鉴权失败；需手动删除子应用 localStorage 中的 Token 才能恢复。

## 期望

主应用切换账号后，子应用自动感知 Token 变化并刷新页面/session，无需用户手动清缓存。

## 关联代码

- `src/main.ts` — 启动时 AUTH_INFO 初始化
- `src/App.vue` — visibilitychange 检测
- `src/utils/user-session.ts` — getToken / Cookie
