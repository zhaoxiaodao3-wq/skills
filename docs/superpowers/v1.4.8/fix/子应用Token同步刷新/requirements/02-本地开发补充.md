# 子应用 Token 同步刷新 — 补充需求（本地开发）

## 纠正

问题**主要出现在本地开发**，测试/生产环境目前正常。

## 本地开发场景

- 使用 `pnpm dev:test`，配置在 `env/.env.test.local`
- 从主应用复制最新 Token 到 `VITE_DEBUG_TOKEN`
- 需要**实时生效**，不应被浏览器 localStorage 中旧 `AUTH_INFO` 覆盖

## 期望

1. 本地开发时 `VITE_DEBUG_TOKEN`（或 `.env.test.local` 最新值）优先于 localStorage
2. 修改 `.env.test.local` 保存后，开发服务器触发刷新并应用新 Token
3. 不影响非 DEV 环境的 Cookie 同步逻辑
