# 课堂评分点击事件 fix — 原始需求

## 背景

AI 自主分析列表页（`/classroom-app/school/analysis-management/ai-autonomous-analysis`）中，「课堂评分」列当前以可点击链接展示，点击后会弹出 BCTI 指数详情弹窗。

## 需求

去掉该列表页「课堂评分」列的点击事件，评分仅作只读展示。

## 范围

| 项 | 说明 |
|----|------|
| 涉及页面 | `src/pages/school/analysis-management/ai-autonomous-analysis/index.vue` |
| 不涉及 | `ai-teaching-diagnosis-analysis`、`ai-csms-teaching-analysis` 等同名列（保持现状） |
| 不涉及 | `BctiScoreDialog` 组件本身及其他引用页 |

## 验收标准

1. 列表「课堂评分」列在有数据时显示数值，无数据时显示 `-`，样式为普通文本（非链接）。
2. 点击评分不会触发任何弹窗或路由跳转。
3. 本页移除仅服务于该点击的 BCTI 弹窗相关代码（组件引用、状态、`handleShowBcti`）。
4. 其他列（名称跳转详情、重新分析等）交互不受影响。
