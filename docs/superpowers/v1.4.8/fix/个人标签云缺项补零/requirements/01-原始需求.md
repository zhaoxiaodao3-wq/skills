# 原始需求

## 摘要

个人标签云对接真实接口后，展示不正确：后端每个分类只返回有数量的标签，前端未按 mock 原始需求补齐固定枚举。

## 期望（对齐 mock 原始需求）

参考 `ui-style/个人标签云组件/requirements/原始需求.md`：

- 每个模块内标签为固定枚举，数量固定
- **即使 count 为 0 也必须展示**
- 排序：先按 count 降序，再按枚举等级（rank）升序

## 现状

- Mock 路径：`buildModuleTags(defs, counts)`，缺项补 0
- API 路径：`buildModulesFromApiTags` 仅排序后端返回的 `tags`，缺项不补

## 改动方向

后端少返回的标签，前端按模块固定枚举自行拼接，缺失项 `count = 0`。
