# 个人标签云滚轮穿透

## 需求描述

教师画像页：鼠标在个人标签云上时，若标签云**尚未出现滚动条**，滚轮应正常滚动整页（右侧 main）；若标签云**已有滚动条**，滚轮应只滚动标签云内部。

当前现象：标签云无滚动条时，整页滚轮也无法滚动。

## 初步根因

`PersonalTagCloudView.vue` 中 `.personal-tag-cloud-view__modules` 使用 `overflow-y: auto` + `overscroll-behavior: contain`，无溢出时仍拦截滚轮链式滚动到父级 `.teacher-portrait-main`。

## 来源

用户 `/harness` 反馈滚轮行为不符合预期。
