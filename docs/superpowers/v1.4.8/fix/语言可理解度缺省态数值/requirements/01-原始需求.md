# 语言可理解度缺省态数值 — 原始需求

教师画像页「语言可理解度」组件三个 gauge 图表，在**缺省态**（未选教师或无 slice 数据）中心分数当前显示 `0.0`，应显示整数 `0`。

有真实数据时，展示以接口分值为准：

- 整数分值（如 `20`）显示 `20`，不补 `.0`
- 小数分值（如 `20.56`）保留一位小数并截断（如 `20.5`）
