# 原始需求：AI课堂配置录播重复诊断接口对接

**日期：** 2026-08-06
**分类：** api-adapter
**实现仓：** `E:\code\two\frontend`
**前置模块：** `feature/AI课堂配置录播重复诊断`（mock 态已 DELIVERED）

## 用户原话

> 目前该项目中的 AI课堂配置录播重复诊断功能完成了 mock 态，现在后端提供了接口，即将要对接接口。

## 接口

### 1. 查询是否支持重复诊断分析

- `GET /api/backstage/school/getAiClassroomRepeatDiagnosis`
- 参数：`schoolId`（string，必需，示例 `1920062619731116034`）
- 响应：`{ "code": 200, "msg": "ok", "data": 0 | 1 }`
- 规则：`data=1` 支持；`data=0` 或其他值均按不支持处理

### 2. 设置是否支持重复分析

- `POST /api/backstage/school/updateAiClassroomRepeatDiagnosis`
- 参数：`{ "schoolId": "...", "aiClassroomRepeatDiagnosis": 0 | 1 }`

## 上下文梳理（已确认）

- `schoolId` 来自学校配置页 `route.query.id`，已由 `aiLoginConfig.vue` 传给 `SchoolRepeatDiagnoseCard`，页面层无需改动。
- `service/baseData.ts` 的 `getSchoolRepeatDiagnoseConfig / updateSchoolRepeatDiagnoseConfig` 是唯一 mock 门面，注释已预留“对接真接口时只改此处”。
- 项目 `defineRequest` 会校验 `code=200` 并返回响应 `data` 字段，因此 GET 直接得到 `0 | 1`。
- 页面 composable 只认 `{ enabled: boolean }`，保存失败会自动回滚，无需改 UI。
