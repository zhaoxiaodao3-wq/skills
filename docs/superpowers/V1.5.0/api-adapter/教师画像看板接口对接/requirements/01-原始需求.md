## 文档分析结论（已确认满足）

接口文档 `教师风格画像看板` 提供两个接口：

| 接口 | 覆盖模块 |
|------|----------|
| `POST /cockpit/classroomCmpnt/teacherStyleDashboard/statistics` | KPI、风格分布、语言/情绪/力量标签、学科×风格热力 |
| `POST /cockpit/classroomCmpnt/teacherStyleDashboard/teachers` | 教师列表、科目下拉、教师筛选（姓名/科目/性别/风格组合） |

逐项与页面 mock（`kpi/style-distribution/tag-panel/teacher-list/heatmap`）比对，字段可完整映射；教师详情跳转沿用现有 `GET /analysis/v2/teachingDiagnosis/getTeacherProfile?tenantUserId=`。

## 目标

- 看板组件从 mock 切换为接口数据。
- 页面加载时请求 `/statistics` 一次；筛选条件变化时请求 `/teachers`。
- 保留 DEV 数据态开关：空态预览仍走 mock 空态，不依赖接口。
