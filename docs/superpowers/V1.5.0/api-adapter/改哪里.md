# 新增报告子类型 · 改哪里

产品上只有 **A / B** 两大类。新增的是同大类下的子版本（如 A3、B3）。

---

## 当前结构（参考）

| 子版本 | mapper 文件 | View |
|--------|-------------|------|
| A1 | `classroom-content-analysis-a.mapper.ts` | `ReportTypeAView` |
| A2 | `classroom-content-analysis-a2.mapper.ts` | `ReportTypeAView` |
| B1 | `classroom-content-analysis-b.mapper.ts` | `ReportTypeBView` |
| B2 | `classroom-content-analysis-b2.mapper.ts` | `ReportTypeBView` |

registry 里每个 variant **显式注册一块**，不用 version 参数。

---

## 必改（按顺序）

### 1. `utils/report-variant.ts`

- `CLASSROOM_CONTENT_REPORT_RAW_TYPES` 追加 `'A3'`
- `ReportVariant` / `KNOWN_VARIANTS` / `VARIANT_META` 同步

### 2. 新建 mapper

**新建** `mappers/classroom-content-analysis-a3.mapper.ts`：

```ts
export function mapA3ReportToClassroomContentPayload(...) { }
export function hasA3ReportData(...) { }
```

**禁止**在 `a.mapper.ts` 里加 version 分支。

### 3. `registry/classroom-content-report-registry.ts`

复制 `A2` 注册块，改 import 和函数名：

```ts
A3: {
  variant: 'A3',
  view: ReportTypeA3View,              // 布局同 A1 时用 ReportTypeAView
  resolveReportData: (info) => info?.aReport,
  mapPayload: (info, diagnosis, raw) => mapA3ReportToClassroomContentPayload(info, diagnosis, raw),
  hasReportData: hasA3ReportData,
  resolvePageStatus: resolvePageStatusA,
  share: { ...FAMILY_SHARE.A },
},
```

### 4. View（布局不同时）

新建 `ReportTypeA3View.vue`，registry 改 `view`。

### 5. 单测

`report-variant.spec.ts` 补 `parseReportVariant('A3')`。

---

## 不用改

| 项 | 说明 |
|----|------|
| `a.mapper.ts` / `b.mapper.ts` | 只服务 A1/B1 |
| 列表筛选 | 仍 A类 / B类 |
| 重难点对比等页 | 只认大类 |
| 状态机 | 跟大类走 |
| 类型白名单 | 只改 `report-variant.ts` |

---

## registry 可独立覆盖

| 要改什么 | 改哪项 |
|----------|--------|
| UI 布局 | `view` |
| 数据 key | `resolveReportData` |
| 章节映射 | `mapPayload` → 独立 mapper |
| 判空 | `hasReportData` |
| 分享 | `share` |
