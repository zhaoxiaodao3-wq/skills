# 原始需求

## 页面

`/classroom-app/analysis-web/ai-teaching-diagnosis/classroom-diagnosis/classroom-content-analysis`（含 `resourceType=AI自主分析`）

## 现状

报告页时间戳点击后弹出 `ReportTimeVideoDialog`：已支持顶部拖拽移动、按视频宽高比自动适配尺寸、关闭按钮与原生 controls 联动显隐。**尚不支持用户手动拖拽缩放弹窗大小。**

## 目标

1. 给视频弹窗增加**拖拽缩放大小**能力
2. 体验要求：好用、丝滑
3. **不影响原有功能**（拖拽移动、seek 播放、chrome 显隐、无视频提示等）
4. **组件化 / 工程化**实现，逻辑闭环（可测、边界清晰、可复用）

## 关联代码

- `src/pages/analysis-web/ai-teaching-diagnosis/classroom-diagnosis/components/ReportTimeVideoDialog.vue`
- `src/pages/analysis-web/ai-teaching-diagnosis/classroom-diagnosis/composables/useReportTimeVideo.ts`
- 使用方：`ReportTypeAView.vue` / `ReportTypeBView.vue`

## 验收意向（待方案确认后写入 spec）

- 用户可通过边缘/角点拖拽改变弹窗尺寸
- 缩放过程流畅，松手后尺寸稳定
- 缩放后仍可拖拽移动；播放、seek、关闭行为不变
- 缩放逻辑与弹窗业务解耦，便于复用与单测
