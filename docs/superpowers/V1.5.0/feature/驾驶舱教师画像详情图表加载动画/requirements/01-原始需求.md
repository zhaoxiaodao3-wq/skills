**预览：** `http://localhost:8100/data-cockpit-app/preview/teacher-portrait-detail?...`

## 需求摘要

1. 详情页图表在有数据加载时增加**生长 / 入场动画**。
2. **ECharts** 图表：使用自身 animation（统一时长/缓动；空态关闭；resize 不重播）。
3. **非 ECharts**（CSS/SVG）组件：需补齐等价生长动画（如标签云进度条、语言可理解度 gauge 已有 rAF 则对齐参数）。
4. 参考：校端 `teacher-portrait` 的 `CHART_ANIMATION_BASE`（800ms / cubicOut）；列表页「风格类型分布」入场动画规范。
