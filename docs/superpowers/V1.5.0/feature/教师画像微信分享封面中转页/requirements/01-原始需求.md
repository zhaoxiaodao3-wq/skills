# 原始需求

## 现象（已澄清）

1. 链接**直接分享到微信聊天**
2. 在微信内**打开该链接**
3. 再通过右上角分享给**朋友 / 朋友圈**时，**自定义封面图加载失败**
4. 怀疑此时 **JSSDK 未生效**（回退成微信默认抓取，SPA 无静态封面）

## 产品约束（用户指定）

- 使用 **Vue 中转页**（不要固定纯静态 HTML 文件方案）
- **参数透传**（code/token 等 query 原样带到目标页）
- **三个类型**，分别跳转：
  - 教师画像 → `/teacher-profile`
  - A 报告 → `/analysis-teaching-a`
  - B 报告 → `/analysis-teaching-b`
- **其他业务页逻辑尽量不动**（在中转层收敛）

## 实现落点

- 主改：`E:\code\H5`
- 分享链接生成（若仍指向直链则中转页不会被打开）：classroom `frontend` 中 `buildTeacherProfileShareUrl` / 报告 `buildShareUrl` 等需改为中转 URL（最小改动）
- Harness 文档：本模块

## 技术注意（方案阶段）

仅「进中转再 redirect」不够：用户最终在**目标页**点分享时，仍须目标页（或约定的分享 link）能配上 JSSDK 封面；中转页应负责统一入口、先配卡片、再跳转，且二次分享的 `link` 建议仍指向中转页以闭环。
