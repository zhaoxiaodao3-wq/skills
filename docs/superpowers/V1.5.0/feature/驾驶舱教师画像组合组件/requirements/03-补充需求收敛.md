## 子组件清单

1. **数据汇总** `kpi-strip`：5 项（已分析教师总人数、风格类型数、男、女、科目种类）；空态用 `--` / `-/20`
2. **风格类型分布** `style-distribution-panel`：ECharts 横向堆叠条；20 组合全量；排序=人数↓→主导等级↓→辅助等级↓；tooltip 男/女/合计/占比（一位小数**截断**非四舍五入）
3. **教师列表** `teacher-list-panel`：筛选 + 卡片；hover 放大描边；空态星球图；头像优先接口，否则 OSS 规则（见教师画像映射）
4. **个人标签** `tag-panel`：三 Tab；**条目标题枚举与个人标签云一致**（无学科适配）；**不用 ECharts**，自定义条形+头像；每标签展示 **3** 位教师头像姓名；hover 高亮；进度条 **0→目标值** 入场动画，数据变更时进度平滑过渡；**数量为 0 仍展示该条**；仅当接口**不返回任何内容**（空 payload / 无列表）时展示 Figma 空态；Mock 须覆盖「有数据含 0 值」与「整模块空态」
5. **学科风格人次** `subject-style-heatmap`：ECharts heatmap；交互参考 HTML demo（tooltip、emphasis 光晕、visualMap）

中三栏：**限制高度**，溢出各自内部滚动。
