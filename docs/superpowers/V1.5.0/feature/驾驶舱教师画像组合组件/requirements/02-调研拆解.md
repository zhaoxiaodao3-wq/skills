## 4. 底区（E）

- 标题：**学科风格类型人次分布**
- 形态：热力图（风格组合 × 学科），图例 0→max，右上「共 N 位」
- 实现倾向：ECharts `heatmap` 或表格+色阶；与左栏风格维度应对齐

## 5. 与现有 `mr-*` 的关系

| 已有组件 | 是否可直接当子块复用 | 说明 |
|----------|----------------------|------|
| `mr-teacher-teaching-style-chart` | ❌ 否 | 四维柱/风格占比，不是「风格组合双色条 + 人数」 |
| `mr-number-chart*` | ❌ 否 | 翻牌数字，不是 KPI 图标卡 |
| `mr-student-*` / 课堂分析图 | ❌ 否 | 业务域不同（课堂诊断 vs 教师画像运营） |
| `board-chart.skin` 标题条/角标 | △ 可参考 | 左/右/底面板标题条视觉可对齐 skin token，但布局是组合页不是单图框 |
| Element Plus `el-select` / `el-input` / `el-button` | ✅ 筛选区优先 | 宪法：基础 UI 优先 EP，用 SCSS 覆盖成驾驶舱皮 |

**结论**：子 UI 需在 `mr-teacher-portrait-1/components/` 内新建；全局复用仅限 skin token、request、工具函数。
