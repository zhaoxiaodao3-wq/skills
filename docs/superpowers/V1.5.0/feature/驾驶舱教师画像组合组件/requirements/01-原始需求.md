# 原始需求：驾驶舱教师画像组合组件

## 背景

在 `apps-development-platform/apps/data-cockpit` 新建大屏组件。运营后台 identifier 已定为 **`teacher-portrait-1`**（代码目录应对齐为 `mr-teacher-portrait-1/`）。

与现有多数 `mr-*` **单图表**不同：本组件是由**多个子区块/子组件拼接**而成的**大组合组件**，仍按三主题（风格）交付；本期先落地**第一种样式（model-1 / 风格 1）**。

## 已确认信息

| 字段 | 值 |
|------|-----|
| 应用 | `data-cockpit` |
| identifier | `teacher-portrait-1` |
| 目录约定 | `src/views/preview/mr-teacher-portrait-1/` |
| 形态 | 多组件拼接的大组件（非单一 ECharts 图） |
| 主题 | 三种风格；本期先做第一种 |
| Figma（风格 1） | https://www.figma.com/design/vmbLwcwclGPoT3fWJWv7de/明睿开发稿-·团队版?node-id=8048-37563&m=dev |

## 调研结论摘要（详见 02-调研拆解.md）

整页由 **KPI 五卡 + 主三栏（风格分布 / 教师列表 / 标签）+ 底热力图** 组成；**不能**直接拼现有课堂 `mr-*`，需新建组合壳 + 私有子组件。
