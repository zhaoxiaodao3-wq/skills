## 需求描述

给教师画像详情页（`/preview/teacher-portrait-detail`，`detail/index.vue`）增加丝滑的进入页面动画。

### 已确认方案（B · 区块错峰浮现）

1. 页面数据就绪、区块渲染后，页头与 S1～S6 区块依次淡入 + 轻微上移
2. 错峰节奏：页头 0ms → S1 80ms → S2 160ms → S3 240ms → S4 320ms → S5 400ms → S6 480ms
3. 单个区块时长约 500ms，`ease-out` 缓动，总时长约 1s
4. 动画仅使用 `opacity` + `transform: translateY`（GPU 友好，不触发重排）
5. 尊重 `prefers-reduced-motion: reduce`，降级为直接显示
6. loading / error 分支不做浮现动画（保持简单稳定）

### 约束

- 落盘 Vue + SCSS（`tailwindcss-animations` 仅作动画模式参考，禁止直接贴 Tailwind 类）
- 只改 `detail/index.vue`，不扩 scope
