# 原始需求：教师画像画布尺寸与预览滚动

**日期：** 2026-07-31  
**类型：** fix  
**关联：** feature/驾驶舱教师画像组合组件（identifier `teacher-portrait-1`）  
**入口：** 组件编辑页  
`http://localhost:8100/data-cockpit-app/operational-cockpit/add-template?type=1&id=…`

## 问题描述

1. **编辑页拖入尺寸不对**  
   将「教师画像」组合件拖到画布后，外框留白过大、未按预期铺满一页。该组件特殊：应**自动铺满页面**，且与设计稿一致带**边距**，**正好占满一页**。

2. **预览页不应按「单页压扁全部内容」**  
   设计稿整页高于一屏（有纵向滚动）。预览应按**实际内容高度**展示，页面可滚动，而不是把 KPI + 中三栏 + 底热力全部硬塞进一屏高度。

## 用户附图

编辑画布上组件选中态四周有明显留白；内部内容被压缩在有限高度内。

## 期望

| 场景 | 期望 |
|------|------|
| 编辑页拖入默认尺寸 | 铺满一页（含设计稿同款边距），位置/宽高正确 |
| 预览/实际大屏 | 按内容真实高度布局，整页可纵向滚动 |

## 备注

- 现有默认：`canvas-editor` 中 `'teacher-portrait-1': { w: 0.969, h: 0.95 }`（相对画布比例）
- Figma 有数据整页约 `1920×1643`；范围 B 内容区约 `1860×1454`（KPI+中三栏+底热力）
- 组件根节点仍为 `100%` 填满 cmpnt 容器；尺寸策略在画布默认值与/或预览适配层调整
