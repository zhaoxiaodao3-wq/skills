# 热力科目政治映射 · 开发规格

**Requirement:** [../requirements/01-原始需求.md](../requirements/01-原始需求.md)
**版本：** V1.5.0
**类型：** fix
**实现仓：** `apps-development-platform/apps/data-cockpit`

## 1. 目标

热力组件固定科目表使用「政治」，与接口返回的科目名一致。

## 2. 方案

- `mock/heatmap.mock.ts`：`HEATMAP_SUBJECTS` 末项 `思想政治` → `政治`。
- 适配器按科目名匹配即可填充，无需额外映射。

## 3. 验收标准

- [x] 热力固定科目显示「政治」
- [x] 接口返回政治科目的数据能匹配填充
- [x] ESLint 通过

## 4. 一致性说明

| 检查项 | 约定 |
|--------|------|
| 空态 vs 有数据 | 固定 9 科目不变，仅名称修正 |
| 常量/mock/真数据 | 默认科目与接口科目名对齐 |
| 多入口 | 只影响热力 |
| 失败/缺省 | 其它科目匹配逻辑不变 |
