# 原始需求：教案图表高度自适应

**日期：** 2026-08-07
**分类：** fix
**实现仓：** `apps-development-platform/apps/data-cockpit`
**预览页：** `/data-cockpit-app/preview/teacher-portrait-detail`

## 用户原话

> 我的教案组件里面的图表改成高度自动撑开，现在容器有多的高度没撑开。

## 现状

- `detail/components/my-lesson-plan/my-lesson-plan.vue` 的图表容器 `.tp-my-lesson-plan__chart-wrap` 默认 `max-height: 230px`，1298px 断点还有固定 `300px` 高度。
- 面板更高时容器高度被封顶，图表下方出现空白。

## 目标

- 图表随面板可用高度自动撑开，不固定上限。
- 移动端固定图高保持不变。
