# 原始需求：教师画像看板列表无科目筛选空展示

**日期：** 2026-08-18
**分类：** fix
**实现仓：** `apps-development-platform/apps/data-cockpit`
**页面：** `/data-cockpit-app/restore-implement`（教师画像教师列表）

## 用户原话

> 教师列表组件，我传筛选项科目为无的时候传了空字符串没问题，返回来的 teachers 字段是有老师的，但是页面上什么也没展示，有问题。

## 根因

- 接口已按筛选条件（科目为空字符串）返回过滤后的 `teachers`。
- 前端在 `displayList` 里又用本地 `filterTeachers` 按 `subject === '无'` 二次过滤，而返回数据里无科目教师的 `subject` 是空/`--`，匹配不上 `'无'`，全部被丢弃。
