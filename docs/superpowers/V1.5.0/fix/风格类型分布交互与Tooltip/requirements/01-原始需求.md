# 原始需求：风格类型分布交互与 Tooltip

**分类：** fix  
**关联组件：** `mr-teacher-portrait-1` → `style-distribution-panel`  
**工作目录：** `E:\code\dataView\apps-development-platform\apps\data-cockpit`

## 问题

1. **交互不丝滑**：当前「风格类型分布」为自定义 DOM 横向堆叠条 + CSS `transition`，滚动/hover 手感差；需**恢复 ECharts 写法**（与组合件原 spec 一致：能用 echarts 就用 echarts）。
2. **Hover 弹层被截断**：列表容器 `overflow: auto`，自定义 tip 落在滚动容器内，超出区域被裁切并挤出滚动条；错误。要求 **hover 内容允许超出容器显示**（不被面板/列表裁切）。

## 验收期望

- 风格类型分布用 ECharts 横向堆叠条（男/女双色），含数据变更动画与丝滑 hover。
- Tooltip（男/女/合计/占比）可溢出面板外显示，不因 hover 额外出现列表滚动条。
- 排序、空态、截断一位占比等既有业务规则不变；仅本子组件，不影响其他图表。
