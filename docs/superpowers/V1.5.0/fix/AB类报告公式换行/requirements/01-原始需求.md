# 原始需求：AB 类报告计算过程公式换行

**版本说明：** 产品侧提及 1.4.9；文档落位当前 Harness 版本 V1.5.0。

## 问题

课堂教学内容分析页（`classroom-content-analysis`）下，AB 类报告的「计算过程」内容区中，公式 / 数学式子过长时可能不换行，导致横向溢出或撑破布局。

## 页面

- 路由：`/classroom-app/analysis-web/ai-teaching-diagnosis/classroom-diagnosis/classroom-content-analysis`
- 示例：`?id=2082727212558999554&resourceType=AI自主分析`

## 期望

给 AB 类报告中**所有计算过程公式的内容区域**增加样式：

```css
word-wrap: break-word;
```

使长公式 / 数学式子能够在容器内换行显示。

## 范围

- A 类与 B 类报告均需覆盖（共用计算过程展示组件）
- 仅样式修复，不改数据结构与业务逻辑
