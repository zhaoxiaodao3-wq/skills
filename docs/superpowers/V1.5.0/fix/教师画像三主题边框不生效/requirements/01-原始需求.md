# 原始需求：教师画像三主题边框不生效

## 现象

`teacher-portrait-1`（`mr-teacher-portrait-1`）应支持三种样式（`theme` / model-1、2、3，对应不同边框样式），但切换传入的 theme key 后**边框样式不生效**。

## 期望

参考 `apps/data-cockpit/src/views/preview/mr-negative-atmosphere-chart`：只需修改传入的 theme key，即可展示不同样式边框（及该参考组件同套的主题边框/装饰机制）。

## 代码位置

- 目标：`src/views/preview/mr-teacher-portrait-1/`
- 参考：`src/views/preview/mr-negative-atmosphere-chart/`
- 共用皮肤：`src/views/preview/chart-skins/board-chart.skin.ts`、`board-chart-theme.scss`

## 初判（调研）

根节点已有 `getBoardThemeClass` → `mr-teacher-portrait-1--model-*`，但：

- 未接 `getBoardChartCssVars` / `BOARD_CHART_DECORATION`
- `--model-2/3` SCSS 钩子为空
- 子组件边框色写死（KPI 金边、面板青边等），不读主题变量

## 已确认（brainstorming）

| 项 | 结论 |
|----|------|
| 方案 | **A**：对齐 `mr-negative-atmosphere-chart`（theme key → class + boardCssVars + CSS 变量） |
| 边框作用域 | **大组件内每一个小组件**（KPI、panel-chrome、教师卡、标签行、列表控件、风格分布等），不是只换最外层 |
| 布局 | 不整页套死 `board.root-layout`，以免破坏 KPI+三栏+热力 |
