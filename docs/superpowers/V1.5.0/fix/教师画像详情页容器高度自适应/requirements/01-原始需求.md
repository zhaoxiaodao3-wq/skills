# 原始需求：教师画像详情页容器高度自适应

**日期：** 2026-08-07
**分类：** fix
**实现仓：** `apps-development-platform/apps/data-cockpit`
**预览页：** `/data-cockpit-app/preview/teacher-portrait-detail`

## 用户原话

> 这个页面下的图表容器的高度是不是都没按内容来，我发现在某些屏幕宽度下，容器高度比内容小。

## 现状

- S1/S2/S3/S5 的 `panel-chrome__body` 使用固定 `height` + `max-height`（402/292/352/470），内容超高会被 `overflow: hidden` 裁掉。
- 部分窄屏过渡断点已使用 `height:auto + min-height + overflow:visible`（S4/S6），可随内容增高。

## 目标

- S1/S2/S3/S5 图表容器改为内容自适应：`height:auto + min-height`，内容超高时容器随内容增高，不再裁切。
- 保留设计稿最小高度，避免窄内容塌陷。
