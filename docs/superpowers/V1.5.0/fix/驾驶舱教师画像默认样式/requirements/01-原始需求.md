# 原始需求：驾驶舱教师画像默认样式

**日期：** 2026-08-06
**分类：** fix
**实现仓：** `apps-development-platform/apps/data-cockpit`
**预览页：** `/data-cockpit-app/preview/teacher-portrait-detail`

## 用户原话

> 这个页面目前有三套样式，先固定展示第一种，但是保留切换样式的功能

## 现状

- 教师画像详情页支持 `model-1 / model-2 / model-3` 三套皮肤，由 `route.query.theme` 驱动，缺省为 `model-1`。
- 教师列表打开详情时会把当前组件主题作为 `theme` 查询参数带过去，因此从样式二/样式三入口进入详情会显示对应皮肤。
- 详情页当前没有可见的“样式切换”按钮；切换能力即 `theme` 查询参数机制（组合件 `styleType` A/B/C → `-1/-2/-3` 亦映射到同一机制）。

## 目标

- 详情页默认固定展示第一种样式（`model-1`）。
- 保留切换样式的功能：`theme=model-1/2/3` 查询参数仍可显式切换皮肤，三套皮肤实现不删除。

## 约束

- 不改 `board-chart.skin`、`chart-theme.ts` 等三主题实现。
- 不改数据层与详情页布局。
