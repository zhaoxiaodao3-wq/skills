## 用户原话

> 你能调用前端的 ui 相关的 skill，能去保证不管在多大的屏幕或者多小的屏幕，展示的视觉效果都能像当前 1920 的设计稿吗

## 目标（待方案确认）

在任意容器尺寸（驾驶舱画布拖放后的宽高、不同分辨率预览）下，`mr-teacher-portrait-1`（教师画像组合组件）的**视觉比例与层次**尽量与 **1920 宽基准设计稿**一致，避免：

- 热力格子被拉扁/拉高变形
- 字号、间距、色阶滑块与内容重叠或错位
- 大屏「空」、小屏「挤」导致与稿面观感差过大

## 设计稿基准

- Figma：`vmbLwcwclGPoT3fWJWv7de` · 教师画像有数据 `8048:37563`（约 1920 宽体系；整页高度约 1643）
- 热力子块：`8048:38471`

## 约束（来自既有约定）

- 外层 `restore-datav` 负责拖放改 `width/height`；组件根填满容器
- **禁止**组件内再套一层整页 `transform: scale` / `vw`/`vh` 作为主适配策略（历史需求已确认）
- 可用：容器内等比布局、ECharts `resize` + 显式 plot 尺寸、字号/间距随统一 scale、flex 比例微调

## 成功标准（草案）

1. 以 1920 稿面为视觉基准，放大/缩小容器时整体观感「像同一张图在缩放」
2. 热力格子宽高同比；色阶滑块不与矩阵/列标重叠
3. 中三栏、KPI、标签等与稿面层级关系保持稳定
4. 极端过小尺寸可读性有下限（字号/可点区域），不追求像素级可读到不可用
