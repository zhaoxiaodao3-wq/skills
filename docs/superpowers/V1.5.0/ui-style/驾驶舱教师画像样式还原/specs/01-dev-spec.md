## 1. 目标与范围

在 **预览页 1920 宽** 下，对 `teacher-portrait-1`（`mr-teacher-portrait-1`）**整页**按 Figma 风格 1 做样式还原：字号/字重/色、间距、圆角边框、关键尺寸。

| 项 | 值 |
|----|-----|
| 应用 | `apps-development-platform/apps/data-cockpit` |
| 目录 | `src/views/preview/mr-teacher-portrait-1/` |
| 方案 | A：分区拉 Figma token → 改现有 Vue/SCSS，结构不动 |
| 主题 | 仅 model-1 |
| 有数据稿 | [8048-37563](https://www.figma.com/design/vmbLwcwclGPoT3fWJWv7de/?node-id=8048-37563&m=dev)（整页 1920×1643） |
| 空态稿 | [8048-36733](https://www.figma.com/design/vmbLwcwclGPoT3fWJWv7de/?node-id=8048-36733&m=dev)（壳/空态核对） |

### 包含

- KPI 五卡、面板标题壳、风格分布、教师列表/卡、标签面板、底热力图（含 ECharts 轴/标签字号与色阶观感）
- 壳层纵向间距与中三栏宽比
- 去掉会破坏 1920 对齐的响应式压缩（如 KPI `@media (max-width: 1400px)` 缩小字号）

### 不包含

- model-2 / model-3
- 恢复 `--tp-scale` 文字等比缩放
- 画布投放 / 预览滚动逻辑改动（除非样式强依赖且经确认）
- 接口与 mock 数据结构变更
- 顶栏 Tab、右上学年按钮（整页 Figma 有，组件范围外）

## 4. 实现原则

1. **只改样式与必要的图表 option 字号/颜色**；不改 props / mock 契约。
2. **固定 px**；不引入容器宽缩放变量。
3. 分区改、分区对照；优先修「与上表硬 token 不一致」项。
4. 资源（PNG/SVG）若与稿观感不符，可替换 asset，路径仍放在现有 `assets/images/teacher-portrait-1/`。

## 5. 验收

- [x] 1920 预览下 KPI 五卡字号/色/边框/内边距与 §3.2 一致，且无 1400 断点压缩字号
- [x] 面板标题条 32 / 16 字 / 角标 14 与 §3.3 一致
- [x] 风格分布 12 字、条高 20、轨底色与 §3.4 无明显偏差
- [x] 教师列表、标签、热力与 Figma 对应节点观感无明显偏差（还原自检列偏差清单）
- [x] 空态稿壳层不回归花屏；空态文案样式可接受
- [x] 未恢复 `--tp-scale`；未改投放/滚动逻辑（或已说明例外）

## 6. 风险

| 风险 | 缓解 |
|------|------|
| 预览缩放 ≠ 1 时视觉仍偏小 | 验收锁定 1920；大屏缩放另开需求 |
| ECharts 热力难 1:1 DOM 稿 | 轴/标签字号与色阶对齐；格子像素级可记「可接受偏差」 |
| 标题字 #FFF vs #DBFAFF | 以节点实测为准，archive 注明 |
