# 原始需求

## 背景

驾驶舱教师画像组合件底部「学科风格类型人次分布」热力图高度设计不合理：当前多为内容去适配容器高度，格子上下被挤压，可读性差。

## 目标

对照 Figma 有数据稿视觉，**只改该热力组件**，使高度随内容（行高 × 行数 + 底栏），格子不再被父级剩余高度压扁。

## 设计稿

- 整卡参考：[8048-37563](https://www.figma.com/design/vmbLwcwclGPoT3fWJWv7de/?node-id=8048-37563&m=dev)
- 热力节点（实现对照）：[8048-38471](https://www.figma.com/design/vmbLwcwclGPoT3fWJWv7de/?node-id=8048-38471&m=dev)

## 范围

| 包含 | 不包含 |
|------|--------|
| `subject-style-heatmap` 高度/布局/ECharts grid | KPI / 中三栏其它面板 |
| 组件内 panel-chrome 高度随内容 | 整卡跨屏等比 scale 方案重开 |
| 必要的外层预留高度常量（若热力变高导致裁切） | 改其它 `mr-*` 组件 |

## 验收期望

- 有数据/空态矩阵行高接近稿面（约 24px/行），数字与行标签可读
- 面板高度随行数与底栏（列标 + 色阶）变化，不均分填满剩余视口
- 色阶不与矩阵/科目文字重叠
