## 2. 业务流程

### 2.1 图1 · 分配岗位

- `*选择岗位` + `*数据权限`（必填、单选、默认请选择；按岗位枚举；**排除全量**）
- 选「校区+学段+科目」→【下一步】进本类型图2  
- **无** setupMode

### 2.2 图2 · 新增详情

- 标题：`【校区+学段+科目】权限`
- `*请添加校区学段科目`；默认 1 空行（不可删）；`+` 增行；每行必填
- 取消：关图2 + 图1  
- 上一步：回图1，保留岗位与数据权限  
- 确定：成功 → toast + 关窗 + 刷列表；失败 → toast 原因、不关窗  
- 岗位级重复：同校区型 `postId + dataPermissionEnum`（手动分配规则同校区型说明）

### 2.3 级联（图3）

- `校区 → 学段 → 科目`（叶子=科目；**单选**）
- 科目列表 = **该学段下科目并集**（非年级维度）
- 数据范围：当前学年  
- 样式参考：AI 物联「选择班级」类级联（实现复用 ElCascader，与前几型一致）

### 2.4 判重（图4 交互）

- 三段全同（campus + stage + subject）→ toast「**科目已存在**」
- 多行过多时区域滚动；`-` 删行（至少留 1 行）

### 2.5 列表（图5 / 产品图4）

| 列 | 规则 |
|----|------|
| 权限范围 | **学段**并集（跨校区去重）；limit=2 + hover 全量 |
| 所属校区 | 校区去重并集；limit=2 + hover |
| 任教科目 | **所选科目**并集；limit=2 + hover |
| 操作 | 「数据权限」+「删除」；点数据权限进编辑弹框 |

**学年升级：** 本类型权限范围是学段、科目不挂年级 → **升级时无需特殊处理**（与其它类型不同）。前端本期不实现升级逻辑本身。

### 2.6 编辑弹框

- 无「上一步」；取消关窗  
- 确定：成功关窗+刷列表；失败不关窗  
- 回填显示具体路径（如 `主校区/小学/语文`）
