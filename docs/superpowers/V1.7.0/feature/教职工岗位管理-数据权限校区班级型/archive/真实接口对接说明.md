## 4. 字段约定（本类型）

### 4.1 枚举

| 字段 | 值 |
|------|-----|
| `dataPermissionEnum` | `'campus_class'` |

无 `setupMode`（与 `campus_class_sub` 区分）。

### 4.2 路径

```ts
interface CampusClassPath {
  campusId: string
  campusName: string
  stageId: string
  stageName: string
  gradeId: string
  gradeName: string
  classId: string
  className: string
  gradeSubjects?: Array<{ id: string, name: string }>
}
```

判重键（四段全同）：`campusId + stageId + gradeId + classId`  
定义见：`src/utils/faculty-data-permission.ts`

### 4.3 列表行

| 列 | 规则 |
|----|------|
| 权限范围 | 班级并集，limit=2 |
| 所属校区 | 校区去重并集，limit=2 |
| 任教科目 | **年级科目并集**（非「全部」），limit=2 |

### 4.4 分配 / 编辑 body

```ts
{
  facultyId, postId, // 编辑改为 assignId
  dataPermissionEnum: 'campus_class',
  scopes: CampusClassPath[],
}
```

岗位级重复：`postId + dataPermissionEnum`。

### 4.5 四级树

`facultyCampusClassTree(schoolId)` → 校区 → 学段 → 年级 → **班级**（当前学年、行政班）。  
年级节点建议带 `subjects`，供列表任教科目派生。
