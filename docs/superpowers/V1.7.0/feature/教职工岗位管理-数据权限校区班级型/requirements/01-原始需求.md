## 1. 背景



在已有三种数据权限之上，扩展第四种：**校区+班级**（`campus_class`）。



与 `campus_class_sub` 差异：



| | 校区+班级（本期） | 校区+班级+科目（已交付） |

|--|------------------|------------------------|

| 枚举 | `campus_class` | `campus_class_sub` |

| 级联级数 | **四级** 到班级 | 五级 到科目 |

| 设置方式 | **无** | 有 1对1 / 多对多 |

| 判重文案 | 「班级已存在」 | 「科目已存在」 |

| 列表科目 | **年级科目并集**（班级科目=年级科目） | 路径上科目并集 |

## 2. 截图提炼（图 1～5）



### 2.1 图1 · 分配岗位



- 字段：`*选择岗位` + `*数据权限`（必填、单选、默认「请选择」）

- 选项来自岗位配置的数据权限枚举，**排除「全量」**

- 选「校区+班级」→【下一步】进图2



### 2.2 图2 · 【校区+班级】权限（新增路径）



- 标题：`【校区+班级】权限`

- `*请添加校区班级`；默认 **1** 个空选择框；首行不可删（至少保留 1 条）

- 【+】增空行；【-】删行（>1 时可删）

- 行多时区域内滚动

- 【取消】关图2+图1  

- 【上一步】回图1，保留已选岗位与数据权限  

- 【确定】成功：toast + 关窗 + 刷列表；失败：toast 原因 + **不关窗**  

- 手动分配岗位重复规则同「校区」型



### 2.3 级联选择（图2 展开）



- 点击下拉选**行政班**；**单选**；样式参考 AI 物联「学生人脸库」选班级条件

- 数据：**当前学年**

- 四级：`校区 → 学段 → 年级 → 班级`  

  例：主校区 / 小学 / 三年级 / 三年级(1)班



### 2.4 行内判重



- 同一【校区+班级】不可重复（校区与班级均相同）→ toast「**班级已存在**」



### 2.5 列表展示（选本枚举后的行）



| 列 | 规则 |

|----|------|

| 权限范围 | 各校区所选**班级**并集；最多展示 2，超出 `...`；hover 全量 |

| 所属校区 | 所选校区去重并集；最多 2 + hover |

| 任教科目 | 所选年级的科目并集（班级科目=年级科目）；去重；最多 2 + hover |

| 操作 | 【数据权限】+【删除】；点数据权限开编辑弹窗 |



> 需求图另有「学年升级后同步」——**本期前端不实现**（与前几型一致 OUT）。



### 2.6 图5 · 编辑路径



- 同图2 多行级联 UI；**无【上一步】**  

- 【取消】关弹窗  

- 【确定】成功关窗+刷列表；失败不关  

- 展示回填具体已选路径；列表侧科目按 §2.5 展示具体科目（非「全部」）
