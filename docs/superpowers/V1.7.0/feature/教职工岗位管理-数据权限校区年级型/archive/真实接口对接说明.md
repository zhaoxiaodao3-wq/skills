## 4. 契约要点

### 4.1 枚举

`dataPermissionEnum = 'campus_grade'`（label：校区+年级）

### 4.2 scopes（三段）

```ts
{
  campusId, campusName,
  stageId, stageName,
  gradeId, gradeName,
  gradeSubjects?: { id, name }[]  // 可选；列表科目派生
}
```

判重键：`campusId + stageId + gradeId`  
岗位级重复：`postId + dataPermissionEnum`（无 setupMode）

### 4.3 列表派生

| 列 | 规则 |
|----|------|
| 权限范围 | 年级并集 |
| 所属校区 | 校区去重并集 |
| 任教科目 | 年级科目并集；**非「全部」** |
