## 4. 字段约定（本类型 · 真接口需对齐）



### 4.1 枚举与设置方式



| 字段 | 值 |

|------|-----|

| `dataPermissionEnum` | `'campus_class_sub'` |

| `setupMode` | `'one_to_one'` \| `'many_to_many'` |



前端常量：`DataPermissionEnum.CAMPUS_CLASS_SUB`、`DataPermissionSetupMode`（`src/constants/faculty.ts`）



### 4.2 路径（仅 one_to_one）



```ts

interface CampusClassSubjectPath {

  campusId: string

  campusName: string

  stageId: string

  stageName: string

  gradeId: string

  gradeName: string

  classId: string

  className: string

  subjectId: string

  subjectName: string

}

```



判重键（五段全同才重复）：  

`[campusId, stageId, gradeId, classId, subjectId].join`



定义见：`src/utils/faculty-data-permission.ts`



### 4.3 列表行



| 字段 | one_to_one | many_to_many |

|------|------------|--------------|

| `dataPermissionEnum` | `campus_class_sub` | 同左 |

| `setupMode` | `one_to_one` | `many_to_many` |

| `scopePaths` | `CampusClassSubjectPath[]` | 可空 |

| 权限范围 | `classList` / 由 paths 聚合**班级** | 由班级权限接口维护 |

| 科目 | `subjectList` | 现网科目权限 |

| `campusName` | 校区并集展示 | 可空或后端维护 |



列表展示：`resolveListCells` → 权限范围=班级并集；科目 tags limit=2



### 4.4 分配 / 编辑 body



```ts

// 1对1 · 分配

{

  facultyId, postId,

  dataPermissionEnum: 'campus_class_sub',

  setupMode: 'one_to_one',

  scopes: CampusClassSubjectPath[],

}



// 1对1 · 编辑

{

  assignId,

  dataPermissionEnum: 'campus_class_sub',

  setupMode: 'one_to_one',

  scopes: CampusClassSubjectPath[],

}



// 多对多 · 静默占位（下一步时调用；确认班级权限前前端不刷新列表）

{

  facultyId, postId,

  dataPermissionEnum: 'campus_class_sub',

  setupMode: 'many_to_many',

  scopes: [],

}

```



### 4.5 岗位级重复



键：`postId + dataPermissionEnum + setupMode`  

→ 同岗可同时存在 1对1 与多对多两行。



### 4.6 五级树



`facultyCampusClassSubjectTree(schoolId)` →  

`Array<{ id, name, children? }>`  

五级：校区 → 学段 → 年级 → **班级** → 科目（当前学年语义）。



### 4.7 多对多交互约定（对接后仍须满足）



| 步骤 | 行为 |

|------|------|

| 图1 选多对多 → 下一步 | 先 `facultyAssignPost(many_to_many)` 拿 `id`，再开 `SelectClassListDialog` |

| 班级窗打开期间 | **不要**因占位 assign 刷新岗位列表（避免「未确认已新增」） |

| 班级权限确定 | 走现网 `updateFacultyPermission`；再刷新列表 |

| 班级窗取消/关闭且未确定 | 调用 `facultyRemoveAssign(assignId)` **回滚占位行** |

| 列表「数据权限」且 `setupMode===many_to_many` | 打开班级权限窗（不开五级弹框） |
