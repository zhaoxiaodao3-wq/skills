## 6. 风险与回滚

- **风险 1：接口路径/字段命名不一致**
  - 后端实际路径可能不是 `/backstage/...` 占位符，**对接前需后端确认最终 URL 与字段**
  - **缓解：** 本文 §3.1 重写模板留了占位符，对接时按真实值替换
- **风险 2：响应结构差异**
  - mock 返回 `{ code: 'OK' | 'ALREADY_EXISTS' | 'SERVER_ERROR', message?, data? }`
  - 真接口可能用 `{ code: 200 | 400, msg: ..., data: ... }`（HTTP 风格）
  - **缓解：** 调用点的 `if (res.code === 'OK')` 需按真接口 code 值调整
- **风险 3（mock 期内特有）："分配成功立即可见，刷新页面消失"是 mock 特性，不是 bug**
  - mock 数据存在 JS 模块级 `let list = [...]` 数组里，刷新页面即清空
  - **对接前需告知后端 / 测试人员**：真接口到位后此特性由后端持久化替代
  - **对接后此特性消失**：所有列表数据来自数据库，不再随页面刷新清空
- **回滚：** 误删可从 git reflog 找回 `src/mocks/faculty-position/` 整目录（90 天内有效）
