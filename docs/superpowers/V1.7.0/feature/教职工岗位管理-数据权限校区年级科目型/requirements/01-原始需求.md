## 3. 业务流程

### 3.1 图1 · 分配岗位（第一步 · 已有，沿用）

- 字段：`*选择岗位` + `*数据权限`（必填、单选、默认「请选择」）
- 选项 = 岗位配置枚举，**排除全量**；随岗位切换动态拉取
- 选中 `campus_grade_sub`（校区+年级+科目）→【下一步】→ 图2
- 【取消】→ 关闭图1

> 图1 本身本期无需大改；需保证 mock 岗位配置能下发 `campus_grade_sub`，且选该枚举时路由到本类型弹框（策略扩展）。

### 3.2 图2 · 【校区+年级+科目】权限（新增路径 · 第二步）

- 标题：`【校区+年级+科目】权限`
- 字段：`*请添加校区年级科目`（必填，多行）
- 默认 **1 条空选择框**
- 【+】：追加一条空选择框；每条提交前必须填满
- 【-】：删除对应行；**至少保留 1 条**（仅剩 1 条时隐藏/禁用删除）
- 行过多：固定区域纵向滚动
- 【取消】：关闭图1 + 图2（整次会话结束）
- 【上一步】：回图1，保留已选「数据权限」；成对来回时保留已选路径行（沿用校区型三层守门语义）
- 【确定】：
  - 成功：toast → 关弹框 → 刷新列表
  - 失败：toast 原因 → **不关**弹框
  - 手动分配重复规则：**沿用校区型**（同岗位 + 同 `dataPermissionEnum` → `该岗位已存在且数据权限相同`；同岗位 + 不同枚举 → 可各占一行）
  - 前端行内判重：四段全相同 → toast `科目已存在`，不提交

### 3.3 级联选择器

- 交互：点击行内选择框 → 四级面板：`校区 → 学段 → 年级 → 科目`
- 叶子：**单选科目**（每行最终一条完整路径）
- 展示文案示例：`主校区/小学/三年级/语文`（展示到具体科目）
- 数据范围：**仅当前学年**（mock 树即视为当前学年）
- 风格：对齐产品所述「AI物联-学生人脸库-选择班级」级联观感；本仓无该页，用 `ElCascader` 多列面板实现

### 3.4 图3 · 列表展示（该类型行）

| 列 | 规则 |
|----|------|
| 权限范围 | 所选**年级**并集（不按校区拆分）；≤2 直显，>2 则 2 + `...`；hover 全量 |
| 所属校区 | 所选**校区**去重并集；同上截断 |
| 任教科目 | 所选**科目**去重并集；同上截断 |
| 操作 | `数据权限` + `删除`（与带 `dataPermissionEnum` 的行一致）；点「数据权限」→ 图4 |

截断组件：复用 `AppTagClampTooltip :limit="2"`。

### 3.5 图4 · 列表「数据权限」编辑

- 标题同图2；回显已选路径（到科目）
- **无【上一步】**；仅【取消】【确定】
- 【取消】：只关本弹框
- 【确定】成功/失败行为同图2
- 至少保留 1 条、+/-、滚动、行内判重规则同图2

### 3.6 表单生命周期（沿用校区型，适配本类型状态）

- **保留**：仅发生在图1 ↔ 图2 成对来回
- **重置**：分配岗位按钮 / 列表「数据权限」入口 / 成功完成 / 主动取消
- 编辑上下文：`editingRow`；新增路径默认空行；编辑路径从行上 scope 回填
- **绝不缓存**「用户修改未保存」的值到下次打开
