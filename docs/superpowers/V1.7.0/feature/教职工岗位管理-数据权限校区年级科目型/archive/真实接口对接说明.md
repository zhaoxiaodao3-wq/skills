## 4. 字段约定（真接口需对齐）

### 4.1 列表行

| 字段 | campus | campus_grade_sub |
|------|--------|------------------|
| `dataPermissionEnum` | `'campus'` | `'campus_grade_sub'` |
| `scopeCampusIds` | `string[]` | 无 / 忽略 |
| `scopePaths` | 无 | `CampusGradeSubjectPath[]` |
| `campusName` / `gradeList` / `subjectList` | 展示用（后端可直接给或前端派生） | 同左；科目**不要**再强制「全部」 |

`CampusGradeSubjectPath` 定义见：`src/utils/faculty-data-permission.ts`

### 4.2 分配 / 编辑 body

```ts
// 校区
{ facultyId, postId, dataPermissionEnum: 'campus', campusIds: string[] }

// 校区+年级+科目
{ facultyId, postId, dataPermissionEnum: 'campus_grade_sub', scopes: CampusGradeSubjectPath[] }
```

编辑用 `assignId` 替换 `facultyId+postId` 即可。

### 4.3 四级树

`facultyCampusGradeSubjectTree(schoolId)` →  
`Array<{ id, name, children? }>`，四级：校区 → 学段 → 年级 → 科目（仅当前学年）。
