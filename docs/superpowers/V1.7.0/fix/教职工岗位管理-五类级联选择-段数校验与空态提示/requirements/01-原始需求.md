## 0. 问题

按用户截图与描述：

### 问题 1：父节点无 children 时仍可作为最后一级被选

> **用户描述**：「校区+年级最后选择出来的一定是要校区/学段/年级，这三个都要有，现在我发现，如果学段下面没有年级了，我居然还能只选中学段，如图1」

**截图佐证**：弹窗里 row 显示 `天河校区/学前`，**只有 2 段**（校区+学段），缺年级。

**业务影响**：
- 用户可提交「天河校区/学前」（缺 gradeId）作为合法数据
- 后端 `permissionScopeList` 收到不完整 DTO → 「权限范围」列显示缺失；学年升级 / 真接口对接时数据不完整报错
- **判重失效**：相同父级路径下，不同兄弟学段会被认为不同路径，重复检测失败

**根因**：
- Element Plus Cascader 在 lazy 模式下，父节点 `lazyLoad(node, resolve([]))` 时，ElCascader 把 parent 视为 leaf
- 默认 `checkStrictly: false`（非叶子不可选），但 parent 此时**被 ElCascader 视为 leaf**，允许被选
- `idsToDTO` 当前**不校验 ids 长度**——CG 链路必须 3 段，但 2 段 `[校区, 学段]` 也能转成 `{ campusId, stageId }`
- `validateScopes` 当前**只校验空行 + 全段重复**，不校验段数完整性
- 用户提交 → 通过 → 后端收到不完整数据

### 问题 2：父节点空时的级联面板「展开框」

> **用户描述**：「如果是校区+年级的选择，那么，年级应该就是最后一级了，现在我发现年级那个地方还有一个展开框，要点一下才消失，点两下才会选择年级」

**根因**（同问题 1）：
- ElCascader 在 lazy 模式下，resolve([]) 后父节点**无 children**，但仍展示一个空 panel
- 用户把空 panel 误以为是「展开框」
- Element Plus Cascader 默认 `empty-text="No Data"`——视觉提示不友好、不本地化

**业务影响**：
- 用户体验：找不到原因（"明明有年级，怎么没有？"），误以为是 bug
- dev 环境无法区分「该学段真没数据」 vs「接口报错」
