# 教职工岗位管理-五类级联选择-空数据纯文字提示

> 模块版本：V1.7.0 / fix
> 起源模块：fix/教职工岗位管理-五类级联选择-空数据父节点禁用（撤销）
> 修复日期：2026-09-23

## 1. 背景

上一轮（fix #5 空数据父节点禁用）为 5 个 cascader 在空数据 / 错误分支加入了 disabled 占位：

```js
resolve([{ id: '__empty__', name: '暂无数据', disabled: true }])
```

意图是"父节点不再被识别为 leaf，避免「学前」之类父级可被选中"。

## 2. 用户反馈（截图证明该方案错误）

用户在浏览器中实测后发现：

1. **"你改得不对，如图，没有内容就暂无数据展示，并且不能选中"**
   - 期望：暂无可选数据时，下拉面板**纯文字**显示"暂无数据"。
2. **"如图，暂无数据为什么还要有一个箭头，不能跟我之前发你的一样吗，就纯文字"**
   - 实测：disabled 占位虽然 `disabled=true`，但 Cascader 仍将其作为**节点对象**渲染，显示节点名称 + 右侧的展开箭头——这不是"纯文字"，是带节点的占位。
3. **"例子中的校区+年级，最深一层就是年级了，为什么年级点了还要去搜索，点击年级的层级应该直接选中了"**
   - 这是 cascader **预期行为**确认（最后一层 `isLeaf: true` 点击直接选中），与本次修复无关，保留不动。

## 3. 业务诉求

暂无可选数据时（如某校区下没有年级、某年级下没有学科），下拉面板**只显示一段纯文字**，不显示任何节点对象、不显示展开箭头。

## 4. 验收口径

- ✅ 5 个 cascader 全部回归为 `resolve([])`，Cascader 自动展示 `empty-text="暂无数据，请联系管理员"` 纯文字
- ✅ 不再有 `id: '__empty__'` 这种假节点对象
- ✅ 不再有 `disabled: true` 的占位对象
- ✅ 父节点被错误选中的风险由 util 层 `idsToDTO` 段数校验 + `validateScopes` 字段校验**双层兜底**（已在前一轮 fix 中实现，本轮不动）
- ✅ 5 个 cascader 行为一致
