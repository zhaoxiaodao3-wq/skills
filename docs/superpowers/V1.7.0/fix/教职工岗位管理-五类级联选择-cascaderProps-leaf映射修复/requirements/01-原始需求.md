# 教职工岗位管理-五类级联选择-cascaderProps-leaf映射修复

> 模块版本：V1.7.0 / fix
> 模式：hotfix（根因修复）
> 修复日期：2026-09-23

## 1. 背景

紧接 `fix/教职工岗位管理-五类级联选择-空数据纯文字提示` DELIVERED 之后，用户实测反馈"还是不对"。

## 2. 真实根因（Element Plus 源码确认）

Element Plus Cascader 的 `DefaultProps`：

```js
// node_modules/element-plus/es/components/cascader-panel/src/config.mjs.map
DefaultProps = {
  value: 'value',
  label: 'label',
  children: 'children',
  leaf: 'leaf',        // ← 默认从节点对象的 'leaf' 字段判断是否叶子
  disabled: 'disabled',
  ...
}
```

**Element Plus Cascader 默认找节点对象的 `leaf` 字段判断叶子节点，不是 `isLeaf`。**

我们的 5 个 cascader：
- cascaderProps **缺** `leaf: 'isLeaf'` 映射配置
- 节点对象用 `isLeaf: true/false` 字段
- Cascader 找不到 `leaf` 字段 → **全部节点都被识别为非叶子** → 用户点击"年级"时仍触发 lazyLoad 搜索第 4 级（班级） → 第 4 级空 → 第 4 列显示 empty-text → 第 3 列"年级"仍带箭头

## 3. 真实业务影响

| 用户操作 | 实际发生 | 用户期望 |
|---|---|---|

| 4 层 cascader 选到年级 | 同上 | 同上 |
| 5 层 cascader 选到班级 | 同上 | 同上 |

## 4. 前面 2 个 fix 为什么没修对

| 模块 | 方向 | 真实问题 |
|---|---|---|
| `fix/...-空数据父节点禁用` (fix #5) | disabled 占位 | **完全错**——disabled 占位不是"暂无数据 + 箭头"的根因 |
| `fix/...-空数据纯文字提示` (fix #6) | `resolve([])` + empty-text 兜底 | **机制对，但触发场景错**——empty-text 显示的场景是"年级层 Cascader 不认叶子"导致第 4 级空，而不是父节点误选 |

## 5. 验收口径

- ✅ 5 个 cascader 的 cascaderProps 都加 `leaf: 'isLeaf'`
- ✅ Cascader 正确识别叶子节点 → 最深一层 `isLeaf: true` → 点击直接选中
- ✅ 不再触发额外层级的 lazyLoad
- ✅ util 双层防御（idsToDTO 段数 + validateScopes 字段）保留
- ✅ empty-text 兜底保留
