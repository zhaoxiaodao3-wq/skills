## 0. 问题

`教职工岗位管理` 页：分配岗位 → 选数据权限后，第二步「**权限**」弹窗中：

| 类型 | 现状 | 期望（spec/原设计） |
|------|------|---------------------|
| 校区 | ✅ 多选 checkbox 校区 | 同（保留） |
| 校区+年级 | ❌ `ElTree` 复选多选树 | 多行行内级联 + +/- |
| 校区+年级+科目 | ❌ `ElTree` 复选多选树 | 多行行内级联 + +/- |
| 校区+班级 | ❌ `ElTree` 复选多选树 | 多行行内级联 + +/- |
| 校区+班级+科目 | ❌ `ElTree` 复选多选树 | 多行行内级联 + +/- |
| 校区+学段+科目 | ❌ `ElTree` 复选多选树 | 多行行内级联 + +/- |

**截图佐证：** 用户截图 1 = 期望弹窗标题+单条空选择框+「+」按钮；截图 2 = 点开一个选择框应弹出**多列级联面板**（校区→学段→年级→科目）。

## 1. 根因

5 个 `*-picker-dialog.vue`（`campus-grade / campus-grade-subject / campus-class / campus-class-subject / campus-stage-subject`）的 `<template>` 与 `<script>` 被改写成"懒加载 ElTree + show-checkbox"一次性勾选模式。

但：

- 各 `*-cascader.vue`（行内级联组件）—— **正确**，未动
- 各 `*-picker-dialog.model.ts`（Props/Emits 契约）—— **正确**，未动
- 各 `*-picker-dialog.util.ts`（`initScopes / cloneScopes / validateScopes / canRemoveRow / hasDuplicateScopes`）—— **正确**，未动
- 各 `*-picker-dialog.scss`（已预置 `__head/__list/__row/__add/__remove`）—— **正确**，未动
- `faculty-position.vue` 页面接入 5 个弹框的 props/emits —— **正确**，未动
- 注册表 / 列表聚合 / mocks —— 未动

**结论：** 改回 `.vue` 文件的 `<template>` 与 `<script>` 即可；其它层（现状）已是 spec 应有的样子。

## 2. P1 已确认结论（2026-09-23）

| # | 结论 |
|---|------|
| 1 | **建 1 个 fix 模块**，覆盖 5 个 picker-dialog 改造；不再拆 5 个 |

| 3 | 改造后保留：同一 `PageView` 标题、同一 props/emits 契约、同一行内级联骨架、同一 `validateScopes` 校验 |
| 4 | **校验沿用 util**：`initScopes(defaultScopes)` 默认 1 空行；`canRemoveRow(rows.length > 1)`；`validateScopes` 含空行/全段重复两类失败 |
| 5 | **每个 picker-dialog 自带级联树懒加载**：5 个 service 接口（`getSchoolCampusList / getSchoolStageList / getSchoolGradeListByCurrentYear / schoolGradeSubjectsList / getSchoolClassList`） |
| 6 | 学年升级前端 OUT（沿用原 spec） |
| 7 | 判重文案统一（按各自枚举）：CG「年级已存在」、CGS「科目已存在」、CC/CCS/CSS「班级/科目已存在」（沿用原 spec，未自创新文案） |
| 8 | 不跑完整 E2E；交付前 lint + 五个 datatype 的 picker-dialog 各被 `pageRule: visible` 截图（Vue 3 本地截图/手动均可） |
