## 0. 问题

5 个 `*-picker-dialog`（CG / CGS / CC / CCS / CSE）当前是**「打开弹窗就一次性把整棵树拉完」**的反模式：

```ts
// 当前 picker-dialog 的 watch modelValue
async (open) => {
  // 第 1 层：校区 1 次
  const campuses = await service.baseData.getSchoolCampusList(...)
  // 第 2 层：校区数并发
  const stages = await Promise.allSettled(campuses.map(...)) // = N 次
  // 第 3 层：学段数 × 校区数并发
  const grades = await Promise.all(...)  // = N×M 次
  // 第 4 层：年级数 × 学段数 × 校区数并发
  const subjects = await Promise.all(...)  // = N×M×K 次
}
```

按学校规模估算：
- 5 校区 × 5 学段 × 6 年级 × 10 科目 = **1 次 + 5 + 30 + 150 ≈ 186 次** HTTP 调用
- 实际学校 5~20 校区不等，调用次数会更多

**项目里其他地方的正确模式**——`src/components/AppCascaderArea/AppCascaderArea.vue`（项目里省市区级联的成熟实现）：

```ts
const cascaderProps = reactive({
  lazy: true,
  async lazyLoad(node, resolve) {
    // 用户点开某一级才触发这一级的查询
    const list = await service.getListByCode(...)
    resolve(list)
  }
})
```

**性能提升预估**：从 ~186 次降到 4~8 次（按用户实际操作）；用户感知「打开弹窗不卡」。

## 1. 偏离明细（按级别）

### 1.1 5 个 `*-cascader/*.vue`（组件层）

| 项 | 当前 | 应改为 |
|----|------|--------|
| props | `tree: CascaderNode[]`（接收外部完整树） | `schoolId: string`（学校 id） |
| ElCascader 模式 | `:options="tree"` 一次性 | `lazy: true` + `async lazyLoad(node, resolve)` 按需 |
| service 调用 | 无（dialog 内调） | cascader 内根据 `node.level` 调对应 service |
| v-model 适配 | 保持 `modelValue: SchoolFacultyPermissionScopeDTO | null` | 不变 |
| tree 数据 | cascader 接收 props 静态渲染 | cascader 内部 lazy 加载 |

### 1.2 5 个 `*-cascader/*.model.ts`（类型契约）

| 项 | 当前 | 应改为 |
|----|------|--------|
| Props 字段 | `tree: Array<{ id, name, children? }>` | `schoolId: string` |

### 1.3 5 个 `*-cascader/*.util.ts`（路径工具）

| 函数 | 当前 | 应改为 |
|------|------|--------|
| `pathToIds(dto)` | 从 dto 取 5 段 id 数组 | 不变 |
| `idsToPath(tree, ids)` | 在 tree 里 find 还原 DTO（依赖外部 tree） | `idsToDTO(ids)` 直接按位还原 DTO（不依赖 tree） |

> **理由：** 选完后 DTO 不需要 name 字段（DTO 只有 id 字段，`SchoolFacultyPermissionScopeVO` 才有 `scopeName`），所以还原 DTO 不需要 tree.find。

### 1.4 5 个 `*-picker-dialog.vue`（弹窗层）

| 项 | 当前 | 应改为 |
|----|------|--------|
| watch modelValue | 构造完整 tree | 删除构造 tree 段；只保留 `if (!props.skipResetOnOpen) rows.value = initScopes(...)` |
| 状态 | `tree / treeLoading / currentYearId` | 删除（cascader 自己 lazy 处理） |
| 给 cascader 的 props | `:tree="tree"` | `:school-id="dpSchoolId"` |
| template `<cascader>` | `<campus-grade-subject-cascader :tree="tree" ...>` | `<campus-grade-subject-cascader :school-id="dpSchoolId" ...>` |
| service 行（getSchoolCampusList / getSchoolStageList / ...） | 全部删除 | 由 cascader.vue 内部调 |
