### 上一轮 fix 的遗漏

`fix/教职工岗位管理-五类级联选择-段数校验与空态提示`（2026-09-23 DELIVERED）做了双层防御：
1. `cascader.util.idsToDTO` 加段数校验（长度不够 → null）
2. `picker-dialog.util.validateScopes` 加字段校验（onSubmit 兜底）
3. cascader.vue 加 `empty-text="暂无数据，请联系管理员"`

**遗漏**：没有阻止用户在 UI 上**选中父节点**。「学前」被 resolve([]) 后，Element Plus Cascader 把父节点识别为 leaf，**可以 click 选中**。

---

## 1. P1 方案（修复策略）

**核心思路**：lazyLoad `resolve([])` 时不再返回空数组，而是返回**一个 disabled 占位节点**：

```ts
{
  id: '__empty__',
  name: '暂无数据',
  disabled: true,
}
```

**机制**：
- Element Plus Cascader 节点对象支持 `disabled: true` 字段
- 当 resolve 返回非空 array（含 disabled 节点）时，**父节点不会被识别为 leaf**
- 父节点 click 行为：展开面板，让用户看到 disabled 占位（灰色不可点）
- 用户**无法选中父节点**——因为 `checkStrictly: false` 默认只允许选叶子节点，而 disabled 占位**本身不可点**

**业务影响**：
- ✅ 用户看到「暂无数据」+ 占位灰色不可点
- ✅ 用户无法选中不完整路径
- ✅ 与用户期望一致："没有内容就暂无数据展示，并且不能选中"
