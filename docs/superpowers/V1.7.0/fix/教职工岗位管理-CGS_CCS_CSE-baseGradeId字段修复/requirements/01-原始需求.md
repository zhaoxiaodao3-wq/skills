# 教职工岗位管理-CGS_CCS_CSE-baseGradeId字段修复

> 模块版本：V1.7.0 / fix
> 模式：hotfix
> 修复日期：2026-09-23

## 1. 背景

紧接 `fix/教职工岗位管理-五类级联选择-cascaderProps-leaf映射修复` DELIVERED 之后，用户实测反馈 CGS / CCS / CSE 弹窗选科目时仍报错。

## 2. 真实根因

后端接口 `schoolGradeSubjectsList({ baseGradeId, stageId })` 的 `baseGradeId` 参数是**基础年级 ID**（来自 `schoolBase` 字典），不是学校绑定年级 ID。

**CGS / CCS cascader 第 3 层（年级）** 调 `getSchoolGradeListByCurrentYear`（学校当前学年年级），每个 item 含 `baseGradeId` 字段（指向基础年级）—— **但前轮 cascader.vue 没有把 `baseGradeId` 写入节点的 `data`**，导致第 4/5 层科目取不到基础年级 ID。

**CSE cascader 无年级层**，**`baseGradeId` 在 CSE 场景下无来源**，前轮加的 `schoolGradeSubjectsList({ baseGradeId: '', stageId })` 回退路径**永远 412 失败**——属于 dead code。

## 3. 业务影响

| 模块 | 接口 | 现状 | 用户视角 |
|---|---|---|---|
| CGS 第 4 层（科目） | `schoolGradeSubjectsList({ baseGradeId: grade.id, ... })` | 412 基础年级不存在 | **CGS 弹窗科目选不中** |
| CCS 第 5 层（科目） | 同上 | 同上 | **CCS 弹窗科目选不中** |
| CSE 第 3 层（科目） | 主路径 `queryAllowSubjectsList({ stageId })` + 回退路径 `schoolGradeSubjectsList({ baseGradeId: '', ... })` | 主路径工作（按学校学段查），回退永远 412 | 主路径 OK，但回退路径污染 + 错误处理不可靠 |

## 4. 真实数据流（从 `pages/app/basic-data/school/school/subject/index.vue` 与 `department/index.vue` 确认）

```
grade item: { id, name, baseGradeId, level, ... }
            └─baseGradeId = 基础年级 ID（指向 schoolBase 字典）
```

```
CGS 第 4 层（科目）→ schoolGradeSubjectsList({ baseGradeId: 基础年级.id, stageId: 学校学段.id })
CCS 第 5 层（科目）→ 同上
CSE 第 3 层（科目）→ queryAllowSubjectsList({ stageId: 学校学段.id })  // 无 baseGradeId，按学校学段直查
```

## 5. 验收口径

- ✅ CGS 年级层（level=2）的 map 写入 `baseGradeId: String(g.baseGradeId ?? '')`
- ✅ CGS 科目层（level=3）改 `const baseGradeId = String(parentData?.baseGradeId ?? '')`
- ✅ CCS 年级层（level=2）的 map 写入 `baseGradeId: String(g.baseGradeId ?? '')`
- ✅ CCS 班级层（level=3）从父年级透传 `baseGradeId` 写入 data
- ✅ CCS 科目层（level=4）改 `const baseGradeId = String(parentData?.baseGradeId ?? '')`
- ✅ CSE 移除 `schoolGradeSubjectsList({ baseGradeId: '', stageId })` 回退路径（dead code）
- ✅ ESLint 0 error
