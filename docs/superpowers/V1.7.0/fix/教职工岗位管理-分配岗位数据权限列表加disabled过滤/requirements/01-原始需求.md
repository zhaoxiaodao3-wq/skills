# 教职工岗位管理-分配岗位数据权限列表加 disabled 过滤

> 模块版本：V1.7.0 / fix
> 模式：轻量（hotfix + 数据接口契约对齐）
> 修复日期：2026-09-24

## 1. 背景

分配岗位弹窗的「数据权限」下拉（`DataPermissionSelect.vue`）拉取接口：

```
GET /backstage/dataPermissionEnum/schoolList?postId=XXX
```

返回数组形如：

```json
[
  { "code": "campus",           "name": "校区型",                  "tenantType": "school", "description": "...", "disabled": true  },
  { "code": "campus_grade",     "name": "校区+年级",               "tenantType": "school", "description": "...", "disabled": true  },
  { "code": "campus_class",     "name": "校区+班级",               "tenantType": "school", "description": "...", "disabled": true  },
  { "code": "campus_class_subject", "name": "校区+班级+科目",       "tenantType": "school", "description": "...", "disabled": true  },
  { "code": "campus_grade_subject", "name": "校区+年级+科目",       "tenantType": "school", "description": "...", "disabled": true  },
  { "code": "campus_stage_subject","name": "校区+学段+科目",        "tenantType": "school", "description": "...", "disabled": true  },
  { "code": "full",             "name": "全量（never nullable）",  "tenantType": "school", "description": "...", "disabled": true  }
]
```

需要按后端约定只展示 `disabled === true` 的项（其余项视为「当前岗位不可用」，不下发到前端）。同时延续 V1.7.0 上线以来「自动排除 full 枚举」的兜底（与对接文档一致，never nullable）。

## 2. 真实根因

- `service.school.ts:479` 的 `getDataPermissionTypesByPost` 已经在返回类型中声明 `disabled: boolean`，说明接口本身就在下发该字段。
- `DataPermissionSelect.vue` 的本地 `OptionItem` 接口**漏掉了 `disabled` 字段**，且 `loadOptions` 的 filter 只排掉了 `code !== ALL`，**没有按 `disabled` 过滤**。
- 导致：即使后端在某些岗位返回了 `disabled: false`（表示该岗位不可用）的项，前端也会无脑展示，与对接文档冲突。

## 3. 业务影响

| 场景 | 修复前 | 修复后 |
|---|---|---|
| 后端下发 disabled:true 的项 | 显示 | 显示（保留） |
| 后端下发 disabled:false 的项 | 显示（错误：岗位不可用） | 不显示（按对接文档约定） |
| 后端下发 full 枚举 | 不显示（filter 已排除） | 不显示（filter 仍然排除） |
| 6 种业务枚举（campus / CGS / CCS / CG / CC / CSS 等） | 显示 | 显示（disabled:true 时） |

## 4. 修复方案

hotfix：仅修改 `DataPermissionSelect.vue`，对齐 `service.school.ts` 已声明的字段类型，加一行 filter。

```ts
interface OptionItem {
  code: string
  name: string
  tenantType: string
  description: string
  /** 后端约定：仅展示 disabled === true 的数据权限（与对接文档一致） */
  disabled: boolean
}

options.value = list.filter(o => o.disabled === true && o.code !== DataPermissionEnum.ALL)
```

## 5. 验收口径

- [x] `OptionItem` 包含 `disabled: boolean` 字段，与 `service.school.ts` 类型一致
- [x] filter 条件：`o.disabled === true && o.code !== DataPermissionEnum.ALL`
- [x] 仅修改 `DataPermissionSelect.vue`，零跨文件接口变更
- [x] `vue-tsc --noEmit` EXIT 0
