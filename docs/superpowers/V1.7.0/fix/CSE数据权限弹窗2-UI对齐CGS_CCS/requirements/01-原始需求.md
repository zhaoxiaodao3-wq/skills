## 0. 前置与背景

上一轮 `fix/教职工岗位管理-五类数据权限弹窗2-行内级联选择修复`（DELIVERED，2026-09-23）已把 5 个 picker-dialog 从 ElTree 复选模式改回「行内 cascader 多行 +/-」骨架。

但 **CSE（校区+学段+科目）** 这一份 picker-dialog 的实现与 CGS / CCS 相比有 **4 项明显偏离**，导致：

- 观感不一致（按钮位置 / 形态 / 隐藏 vs 禁用）
- **功能层 bug**：第 3 列（科目）实际显示「全校所有科目」，而不是「该学段下的科目」——因为 `schoolSubjectsList` 后端 `/backstage/schoolConfig/schoolSubjectsList` 是「学校绑定的科目」，**不分学段**

---

## 1. 偏离明细（4 项）

### 1.1 + 按钮位置

| | 标准（CGS / CCS） | CSE 当前（错） |
|--|-------------------|----------------|
| 位置 | `__head` 末尾（label 右侧） | `__list` 容器内底部 |
| 影响 | 头部右侧小圆 + 按钮 | 列表底部出现「+ 添加一行」文字按钮 |

### 1.2 + / - 按钮形态

| | 标准（CGS / CCS） | CSE 当前（错） |
|--|-------------------|----------------|
| + 按钮 | `round size="small"` + `<ElIcon><IconEpPlus /></ElIcon>` | 无 round/small，文字「+ 添加一行」 |
| - 按钮 | `round size="small"` + `<ElIcon><IconEpMinus /></ElIcon>` | 无 round/small，文字「删除」 |
| 影响 | 5 个 picker-dialog 观感统一 | 文字按钮，破坏统一 |

### 1.3 - 按钮行为

| | 标准（CGS / CCS） | CSE 当前（错） |
|--|-------------------|----------------|
| 行数 = 1 时 | `v-if="canRemoveRow(rows.length)"` → 隐藏 | `:disabled="!canRemoveRow(rows.length)"` → 仍可见但禁用 |
| 影响 | 「至少保留 1 行」隐藏语义 | 用户看到禁用按钮而非隐藏 |

### 1.4 service 接口（CSE 叶子加载）

| | 标准（CGS / CCS 思路） | CSE 当前（错） | 后端真相 |
|--|------------------------|-----------------|----------|
| 路径 1 | `queryAllowSubjectsList({ stageId })` ← **真正按 stageId 过滤** | `schoolSubjectsList({ schoolId, stageId })` | `/backstage/subject/queryAllowSubjectsList` — 按 stageId 返回允许关联的科目 |
| 路径 2 | fallback `schoolGradeSubjectsList({ baseGradeId: '', stageId })` | fallback 同样 | `/backstage/schoolConfig/schoolGradeSubjectsList` — 按年级（baseGradeId）+ stageId 返回 |

| 字段 | 影响 |
|------|------|
| `schoolSubjectsList` | 后端 `/backstage/schoolConfig/schoolSubjectsList` — 「学校绑定的科目」全集；**stageId 参数会被忽略** |
| CSE 当前行为 | 第 3 列展示**全校所有科目**，与第 2 列学段无对应关系（**业务 bug**） |

## 2. P1 已确认结论（2026-09-23）

| # | 结论 |
|---|------|
| 1 | **建 1 个独立 fix 模块**（不动上一轮 DELIVERED 模块的 archive；新建 `fix/CSE数据权限弹窗2-UI对齐CGS_CCS`） |
| 2 | **4 项一起修**（观感 3 项 + 功能 1 项） |
| 3 | service 接口统一为：`queryAllowSubjectsList({ stageId })`（按 stageId 过滤），catch fallback `schoolGradeSubjectsList({ baseGradeId: '', stageId })` |
| 4 | 按钮模板严格对齐 CGS / CCS：位置、形态、隐藏/显示 |
| 5 | 行内级联组件写法：保持 `<CampusStageSubjectCascader>`（与 cascader.vue 一致；template 已实测 PascalCase 不报——参考上一轮 Plan 的 kebab-case 偏离讨论） |
| 6 | `rows` 状态：直接 mutate（`rows.value[idx] = value` / `rows.value.push(null)` / `rows.value.splice(idx, 1)`），对齐 CGS |
| 7 | 不动 cascader.vue / model.ts / util.ts / scss / 校区型 / 其它 4 个 picker-dialog |
| 8 | lint 必须 0 error；与 CGS / CCS / CC / CG 5 个 picker-dialog 行为 / 观感统一 |

## 4. 验收标准（spec 展开）

- [ ] `+` 按钮位于 `__head` 末尾（label 右移），`round size="small"` + `<ElIcon><IconEpPlus /></ElIcon>`
- [ ] `-` 按钮在每行尾部，`round size="small"` + `<ElIcon><IconEpMinus /></ElIcon>`
- [ ] `-` 按钮用 `v-if="canRemoveRow(rows.length)"`，行数 = 1 时隐藏（非禁用）
- [ ] `__head` 容器用 `flex` + `space-between`，使 label 与 + 左右排列（沿用 CGS / CCS）
- [ ] service 接口主路径：`queryAllowSubjectsList({ stageId })`
- [ ] service 接口 fallback：`schoolGradeSubjectsList({ baseGradeId: '', stageId })`
- [ ] 行内级联组件：保持 `<CampusStageSubjectCascader>`（或 kebab，与 cascader 一致）
- [ ] rows 操作：mutate 风格（与 CGS 一致）
- [ ] lint 0 error
- [ ] 校区型 + 其它 4 个 picker-dialog 行为不变（回归门禁）
