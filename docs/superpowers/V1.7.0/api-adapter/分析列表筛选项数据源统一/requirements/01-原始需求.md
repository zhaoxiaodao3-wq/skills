# 分析列表筛选项数据源统一 · 原始需求

**日期：** 2026-10-08 ｜ **类型:** api-adapter

## 需求原文

> `ai-autonomous-analysis` 和 `ai-classroom-record-analysis` 这两个页面的筛选项中的年级和学科
> 接口需要调整一下，学科统一换成 `getSubjectsList` 这个接口，参数需要默认
> `{ "builtin": 1, "exclude": ["体育", "政治"] }`；
> 年级的数据接口改成 `getSchoolBaseGradeList`，入参是
> `/backstage/school/currentSchoolInfo` 这个页面已经调用的接口中的 `baseStageIds` 字段。
> 两个页面这两个筛选项的数据源统一处理。

## 现状

两个页面的筛选区代码**完全相同**：

| 筛选项 | 现状数据源 |
|---|---|
| 学科 | `service.classroom.getClassRoomDict({ dictCode: 'subject' })` |
| 年级 | `service.classroom.getClassRoomDict({ dictCode: 'grade' })` |

旧的字典映射为 `{ value: item.itemCode, label: item.itemName }`，
即**筛选提交的是字典编码而非名称**。

## 目标 service

| 用途 | service | 位置 |
|---|---|---|
| 学科 | `service.subject.getSubjectsList` | `src/service/subject.ts:5` |
| 年级 | `service.baseData.getSchoolBaseGradeList` | `src/service/baseData.ts:226` |

两个 service 均已存在，无需新增。
