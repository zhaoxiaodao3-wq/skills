# AI 课堂实录数据源统一 · 原始需求

**日期：** 2026-09-30
**类型：** api-adapter
**关联模块：**
[新增课堂数据源统一](../新增课堂数据源统一/specs/01-dev-spec.md) ·
[AI自主分析数据源统一](../AI自主分析数据源统一/specs/01-dev-spec.md)（同源改造的前两站）

## 1. 背景

前两页已完成同类改造：

- 课堂管理页（course-list）—— 数据源统一 + 提交三个 id + 列表校区列
- AI 自主分析页 —— 同上，且通过 `useEntityBasicData` prop 开关只对目标页面生效

**AI 课堂实录分析页**（`/classroom-app/school/analysis-management/ai-classroom-record-analysis`）
的「新增 AI 课堂实录分析」弹窗仍使用旧数据源，需做同样处理。

## 2. 目标

1. **年级移到班级前面**；年级改为校区 + 学段 + 年级三级级联；班级改为普通下拉；
   二者形成依赖关系（年级未选满则班级不可选）
2. **年级 / 班级 / 学科的接口与入参**，与 AI 自主分析页保持一致
3. **列表新增「校区」列**，位置在「学科」与「授课班级」之间

## 4. 现状

### 4.1 弹窗（`CreateAIClassroomRecordDialog.vue`）

| 位置 | 字段 | 现状数据源 |
|------|------|-----------|
| `:42` | 班级 `classId` | 5 级懒加载级联：校区 → 学段 → 学年(`currentAndNextYear`) → 年级(`getSchoolGradeList`) → 班级(`getSchoolClassList`，含 `yearId` + `classType`) |
| `:46` | 年级 `gradeName` | `getClassRoomDict({ dictCode: 'grade' })` 平铺，`:value="item.label"` |
| `:62` | 学科 `subjectName` | `getClassRoomDict({ dictCode: 'subject' })` 平铺 |

**没有教材版本 / 关联章节**（本弹窗只有三个表单字段）。
**无回显 / 编辑逻辑**，纯新增，提交走 `service.classroom.saveRecordingDiagnosis(form)`。
**只有一个 `visible` prop**，无其它 props。

### 4.2 关键差异：单页面使用

全仓 grep `CreateAIClassroomRecordDialog` 仅 2 处命中，**均在
`ai-classroom-record-analysis/index.vue`**（模板调用 + import）。

**因此不需要 prop 开关，也不需要新旧双路径并存**——与 AI 自主分析页不同。

### 4.3 列表

列序：年级(`:80`) → 学科(`:81`) → 授课班级(`:82`) → 视频名称(`:84`) → …

## 6. 与前两页的接口口径（完全一致）

| 用途 | 接口 | 入参 |
|------|------|------|
| 校区 | `/backstage/school/schoolCampusList` | `{ schoolId, state: 1 }` |
| 学段 | `/backstage/schoolConfig/schoolStageList` | `{ schoolId, campusId }` |
| 学年 | `/backstage/schoolConfig/currentYear` | `{ schoolId }`（弹窗打开取一次并缓存） |
| 年级 | `/backstage/schoolConfig/currentGradeList` | `{ schoolId, campusId, stageId, yearId }` |
| 学科 | `/backstage/schoolConfig/schoolGradeSubjectsList` | `{ baseGradeId, stageId }` |
| 班级 | `/backstage/schoolClass/schoolClassList` | `{ schoolId, campusId, stageId, gradeId }`（**不含** `yearId` / `classType`） |

**id 口径统一**：`currentGradeList[i].id` → 级联 value → `form.gradeId` → 班级入参 → 提交 `gradeId`。

**学科响应字段**：`name`（显示 / 提交 `subjectName`）、`id`（作 `baseSubjectId`），
**不加 `??` 兜底**（沿用前两页纪律）。

**提交字段**：`campusId` / `campusName` / `stageId` / `gradeId` 提交；
`stageType` / `gradeNumber` / `baseGradeId` 剔除（仅供前端调学科接口）。
