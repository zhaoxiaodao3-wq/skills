# AI 自主分析数据源统一 · 原始需求

**日期：** 2026-09-30
**类型：** api-adapter
**关联模块：** [新增课堂数据源统一](../新增课堂数据源统一/specs/01-dev-spec.md)（同类改造的第一站）

## 1. 背景

课堂管理页（`/classroom-app/course/course-management/course-list`）已完成一轮数据源统一：
年级 / 学科 / 班级改用学校实体接口，教材版本改用实体 ID 入参，并提交校区 / 学段 / 年级 id。

**AI 自主分析页**（`/classroom-app/school/analysis-management/ai-autonomous-analysis`）
的「新增 AI 教学诊断分析」弹窗仍使用旧数据源，需要做同样处理。

## 2. 目标

1. **年级 / 班级位置互换，年级在前**（当前是班级在前、年级在后）
2. **年级、班级、学科、教材版本、关联章节的接口与入参**，与课堂管理页保持一致
3. **列表新增「校区」列**，位置在「学科」与「授课班级」之间

**范围约束：不改动其它原有逻辑**，只做接口替换与参数调整。

## 4. 现状

### 4.1 弹窗（`CreateAITeachingDiagnosisDialog.vue`）

| 位置 | 字段 | 现状数据源 |
|------|------|-----------|
| `:79` | 班级 `classId` | 5 级懒加载级联：校区 → 学段 → 学年(`currentAndNextYear`) → 年级(`getSchoolGradeList`) → 班级(`getSchoolClassList`，含 `yearId` + `classType`) |
| `:87` | 年级 `gradeName` | `getClassRoomDict({ dictCode: 'grade' })` 平铺 ElSelect，**`:value="item.label"`** |
| `:96` | 学科 `subjectName` | `getClassRoomDict({ dictCode: 'subject' })` 平铺（**注意是 `subject`，不是 `teachingClassroomSubjectName`**） |
| `:105` | 教材版本 | `gradeToNumber(年级名)` + `getTextBookCourseMapping()` 反查 `courseId` → `getTextBookVersion({ gradeLevelCode, courseId })` |
| `:114` | 关联章节 | `getTextBookChapter({ textbookId })`（**保持不变**） |

提交：`:742` `emit('submit', submitForm)`，父页面调
`service.classroom.saveNewTeachingDiagnosis(form)`。
提交前剔除 `coreLessonPlan` / `textbookEdition` / `chapters`（`:739-741`）。

**该弹窗是纯新增，无编辑 / 回显逻辑**（无 `getById`、无 `getLatestRecord`、无 `opts`）。

## 5. P1 决策记录（2026-09-30，用户确认）

| 议题 | 决策 |
|------|------|
| 改动范围 | **只改自主分析页**——给公共组件加 prop 开关，新旧两套逻辑并存 |
| 提交字段 | 与课堂管理一致：提交 `campusId` / `campusName` / `stageId` / `gradeId` |
| 列表校区列 | 绑定 `campusName`，后端存什么显示什么（与课堂管理一致） |

> **范围决策的代价（已知并接受）：** 组件内将同时存在新旧两套
> 年级 / 班级 / 学科 / 教材版本逻辑，维护成本与出错面翻倍。
> 实现时须保证两套路径互不干扰（旧路径不得因新路径的字段清理而被破坏）。

同名概念、字段名不同，**不能直接复制粘贴**：

| 年级 id | `refGradeId` | `gradeId` |

## 7. 纯逻辑模块复用

课堂管理已产出 `src/pages/course/types/course-basic-data.ts`（`findNodeById` /
`buildTextbookQuery` / `resolveGradeEntities` / `GRADE_RESET_FIELDS` / `findClassLabel`）。
本弹窗的新路径**直接复用**，不新建模块。`resolveGradeEntities` 当前无调用方
（课堂管理在修订六中改为按路径重新查询），本弹窗可复用其纯取值逻辑。
