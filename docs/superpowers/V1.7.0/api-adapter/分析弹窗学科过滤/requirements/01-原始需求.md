# 原始需求

**来源：** 用户口头需求（2026-02-17）
**类型：** api-adapter
**档位：** 标准

## 需求描述

两个分析页中调用 `/backstage/schoolConfig/schoolGradeSubjectsList` 的地方，入参加固定参数 `subjectNames`，取值与课程列表页 `course-list` 保持一致：

1. `http://localhost:5174/classroom-app/school/analysis-management/ai-autonomous-analysis`
2. `http://localhost:5174/classroom-app/school/analysis-management/ai-classroom-record-analysis`

## 对齐基准

课程列表页 `src/pages/course/components/CreateCourseDialog.vue` 已有固定入参：

```ts
const SUBJECT_NAMES = [
  '语文', '数学', '英语', '物理', '化学', '生物', '地理', '历史', '道德与法治'
]
// schoolGradeSubjectsList({ baseGradeId, stageId, subjectNames: SUBJECT_NAMES })
```

## 范围（P1 已确认 · 方案 B）

- **不**在弹窗组件内无条件加 `subjectNames`
- 通过 prop 控制，仅自主分析 / 课堂实录两页传入
- `ai-csms-teaching-analysis`、`ai-teaching-diagnosis-analysis` 等其它复用入口保持现状（不传 `subjectNames`）

## 不改

- 接口 URL、响应结构
- 课程列表页已有行为
- `service/school.ts` 旧版 service（分析弹窗走 `service.schoolNew`）
