# 外网访问 — 阿里云安全组放行（88 / 8088）

实例：`i-uf67m15nq9r2fu1833wr`（华东 2 上海 `cn-shanghai`）  
公网 IP：`139.224.162.142`

服务器内 Nginx 已在 **88、8088** 反代到画板，本机 `curl 127.0.0.1:88/api/health` 正常。  
公网连不上是因为 **阿里云安全组未放行**（从服务器 curl 公网 IP:88 也会超时）。

## 控制台操作（约 2 分钟）

1. 登录 [阿里云 ECS 控制台](https://ecs.console.aliyun.com/)
2. 找到实例 `i-uf67m15nq9r2fu1833wr` → **安全组** → 点击安全组 ID
3. **入方向** → **手动添加**，添加两条：

| 协议 | 端口 | 授权对象 | 说明 |
|------|------|----------|------|
| TCP | 88/88 | 0.0.0.0/0 | Skill 路由画板 |
| TCP | 8088/8088 | 0.0.0.0/0 | Skill 路由画板备用 |

4. 保存后浏览器访问：
   - http://139.224.162.142:88/
   - 或 http://139.224.162.142:8088/

## 验证

```bash
curl http://139.224.162.142:88/api/health
# 应返回 {"ok":true,...}
```

## 备选：不改安全组（已配置，需 DNS）

已在 Nginx 增加 **`skill.mia-fly.cn`** → `127.0.0.1:5174`（走 **80 端口**，安全组已开）。

在域名 DNS 添加：

```
skill.mia-fly.cn  A  139.224.162.142
```

生效后访问：**http://skill.mia-fly.cn/**

（本地可先测：hosts 加一行 `139.224.162.142 skill.mia-fly.cn`）
